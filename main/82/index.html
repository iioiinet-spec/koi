정올 379 · 절점 찾기

DFS Low-Link로 절점을 찾는 과정을 직접 실행하는 인터랙티브 강의

1. 핵심 개념

1. 정점 하나를 제거했을 때 그래프가 분리되면 절점입니다.
2. disc[u]는 DFS 방문 순서입니다.
3. low[u]는 서브트리에서 도달 가능한 최소 방문 순서입니다.
4. 일반 정점은 low[child] ≥ disc[u]이면 절점입니다.
루트는 예외
DFS 루트의 자식 수가 2개 이상이면 절점입니다.

2. 예제 그래프 실행

5. 코드 작성 단계

disc[v] = ++order;
low[v] = disc[v];
parent[v] = u;
if (disc[v] < low[u]) {
    low[u] = disc[v];
}
if (parent[u] != 0 &&
    low[v] >= disc[u]) {
    isCut[u] = 1;
}
if (parent[root] == 0 &&
    childCount[root] >= 2) {
    isCut[root] = 1;
}
