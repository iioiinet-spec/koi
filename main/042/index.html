정올 #8609 로봇

Binary Lifting + 압축 이동 + 빠른 쿼리 처리 인터랙티브 강의자료

1. 문제 핵심

로봇은 수직선 위에서 움직입니다. 현재 위치에 점프대가 없으면 왼쪽으로 1칸 이동하고, 점프대가 있으면 오른쪽으로 점프한 뒤 그 점프대의 파워가 2배가 됩니다.

점프대가 없을 때: 위치 = 위치 - 1 시간 = 1 증가 점프대가 있을 때: 위치 = X[i] + 현재 파워 시간 = 1 증가 그 점프대의 파워 = 2배

T가 최대 10^17이므로 1초씩 직접 시뮬레이션하면 절대 통과할 수 없습니다. 움직임을 큰 단위로 압축해야 합니다.

2. 가장 중요한 관찰

로봇은 기본적으로 왼쪽으로 걸어갑니다. 하지만 점프대를 타면 오른쪽으로 갑니다.

한 번 오른쪽 점프대로 넘어가면, 다시 왼쪽 점프대로 돌아가지 않습니다.

따라서 로봇이 만나는 점프대 번호는 시간이 지나면서 감소하지 않고 증가합니다.

점프대 번호 흐름: 1번 → 2번 → 3번 → 5번 → ... 처럼 오른쪽으로만 이동한다.

3. 한 점프대에서 다음 점프대로 넘어가는 과정

현재 i번 점프대에 있다고 합시다.

위치 = X[i] 초기 파워 = P[i] 다음 점프대까지 거리 = X[i + 1] - X[i]

점프 파워는 사용할 때마다 2배가 됩니다.

P[i], 2P[i], 4P[i], 8P[i], ...

다음 점프대까지 닿지 못하는 점프는 다시 왼쪽으로 걸어서 같은 점프대로 돌아옵니다. 다음 점프대에 닿는 순간 오른쪽 점프대로 넘어갑니다.

4. 실패 점프와 성공 점프 공식

fail을 성공하기 전까지 실패한 점프 횟수라고 합시다.

P[i] × 2^fail >= X[i + 1] - X[i]

실패 점프 시간은 다음과 같습니다.

(1 + P[i]) + (1 + 2P[i]) + (1 + 4P[i]) + ... 실패 시간 = fail + P[i] × (2^fail - 1)

성공 점프 시간은 다음과 같습니다.

landing = X[i] + P[i] × 2^fail nxt = landing 이하의 가장 오른쪽 점프대 성공 시간 = 1 + landing - X[nxt]

5. 인터랙티브 시뮬레이터

작은 예제를 넣고 실제 로봇이 어떻게 움직이는지 확인할 수 있습니다. 이 시뮬레이터는 이해용이므로 T가 너무 큰 값은 넣지 않는 것이 좋습니다.

6. 압축 이동 계산기

선택한 점프대에서 다음 오른쪽 점프대로 넘어가기까지의 압축 이동 정보를 계산합니다.


7. 왜 Binary Lifting을 사용하는가?

쿼리가 많고 시간이 매우 크기 때문에 압축 이동도 여러 번 반복하면 느립니다. 그래서 압축 이동을 2배씩 묶습니다.

up[i][0] = i번 점프대에서 1번 압축 이동 후 도착 점프대 up[i][1] = i번 점프대에서 2번 압축 이동 후 도착 점프대 up[i][2] = i번 점프대에서 4번 압축 이동 후 도착 점프대 up[i][3] = i번 점프대에서 8번 압축 이동 후 도착 점프대

N ≤ 300000이고 2^19 = 524288이므로 LOG = 20이면 충분합니다.

LOG를 60으로 잡으면 메모리와 반복 횟수가 커져 #7에서 시간초과가 날 수 있습니다.

8. 코드 작성 단계

1단계. 상수와 자료형

#define MAXN 300000
#define LOG 20

typedef long long ll;
typedef __int128 i128;

위치, 파워, 시간은 10^17까지 가능하므로 long long을 사용합니다. 중간 곱셈은 더 커질 수 있어 __int128을 사용합니다.

2단계. 배열 선언

ll X[MAXN + 1];
ll P[MAXN + 1];

int up[MAXN + 1][LOG];
ll cost[MAXN + 1][LOG];

up[i][k]는 i번 점프대에서 2^k번 압축 이동했을 때 도착하는 점프대입니다. cost[i][k]는 그때 걸리는 시간입니다.

3단계. 현재 위치 이하의 가장 오른쪽 점프대 찾기

int upper_bound_x(ll value) {
    int left = 1;
    int right = N;
    int answer = 0;

    while (left <= right) {
        int mid = (left + right) >> 1;

        if (X[mid] <= value) {
            answer = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return answer;
}

4단계. 기본 압축 이동 만들기

while (power < gap) {
    power <<= 1;
    fail++;
}

다음 점프대까지 닿을 수 있을 때까지 파워를 2배로 키웁니다.

5단계. Binary Lifting 만들기

up[i][k] = up[mid][k - 1];
cost[i][k] = cost[i][k - 1] + cost[mid][k - 1];

6단계. 쿼리 처리

시작 위치에서 왼쪽으로 걸어가 처음 만나는 점프대를 찾고, 그 후에는 Binary Lifting으로 가능한 만큼 압축 이동합니다.

9. 정답 C 코드

#include <stdio.h>

#define MAXN 300000
#define LOG 20

typedef long long ll;
typedef __int128 i128;

const ll INF = 4000000000000000000LL;

int N, Q;
ll X[MAXN + 1];
ll P[MAXN + 1];

int up[MAXN + 1][LOG];
ll cost[MAXN + 1][LOG];

static inline ll read_ll() {
    ll x = 0;
    int sign = 1;
    int c = getchar_unlocked();

    while (c != '-' && (c < '0' || c > '9')) {
        c = getchar_unlocked();
    }

    if (c == '-') {
        sign = -1;
        c = getchar_unlocked();
    }

    while (c >= '0' && c <= '9') {
        x = x * 10 + (c - '0');
        c = getchar_unlocked();
    }

    return x * sign;
}

static inline void write_ll(ll x) {
    if (x == 0) {
        putchar_unlocked('0');
        putchar_unlocked('\n');
        return;
    }

    if (x < 0) {
        putchar_unlocked('-');
        x = -x;
    }

    char buf[30];
    int len = 0;

    while (x > 0) {
        buf[len++] = (char)('0' + x % 10);
        x /= 10;
    }

    for (int i = len - 1; i >= 0; i--) {
        putchar_unlocked(buf[i]);
    }

    putchar_unlocked('\n');
}

static inline ll cap(i128 v) {
    if (v > INF) return INF;
    return (ll)v;
}

int upper_bound_x(ll value) {
    int left = 1;
    int right = N;
    int answer = 0;

    while (left <= right) {
        int mid = (left + right) >> 1;

        if (X[mid] <= value) {
            answer = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return answer;
}

void build_base() {
    for (int i = 1; i <= N; i++) {
        if (i == N) {
            up[i][0] = i;
            cost[i][0] = INF;
            continue;
        }

        ll gap = X[i + 1] - X[i];

        ll power = P[i];
        int fail = 0;

        while (power < gap) {
            power <<= 1;
            fail++;
        }

        ll landing = X[i] + power;
        int nxt = upper_bound_x(landing);

        i128 failed_time = 0;

        if (fail > 0) {
            failed_time = (i128)fail + (i128)P[i] * (((i128)1 << fail) - 1);
        }

        i128 success_time = 1 + (i128)landing - X[nxt];

        up[i][0] = nxt;
        cost[i][0] = cap(failed_time + success_time);
    }
}

void build_lifting() {
    for (int k = 1; k < LOG; k++) {
        for (int i = 1; i <= N; i++) {
            int mid = up[i][k - 1];

            up[i][k] = up[mid][k - 1];
            cost[i][k] = cap((i128)cost[i][k - 1] + cost[mid][k - 1]);
        }
    }
}

ll finish_same_trampoline(int idx, ll T) {
    ll power = P[idx];

    while (1) {
        if (T == 0) {
            return X[idx];
        }

        ll landing = X[idx] + power;

        if (T == 1) {
            return landing;
        }

        if ((i128)T <= 1 + (i128)power) {
            return landing - (T - 1);
        }

        T -= 1 + power;
        power <<= 1;
    }
}

ll solve_query(ll S, ll T) {
    int idx = upper_bound_x(S);

    if (idx == 0) {
        return S - T;
    }

    ll walk = S - X[idx];

    if (T <= walk) {
        return S - T;
    }

    T -= walk;

    for (int k = LOG - 1; k >= 0; k--) {
        if (cost[idx][k] <= T) {
            T -= cost[idx][k];
            idx = up[idx][k];
        }
    }

    return finish_same_trampoline(idx, T);
}

int main() {
    N = (int)read_ll();

    for (int i = 1; i <= N; i++) {
        X[i] = read_ll();
        P[i] = read_ll();
    }

    build_base();
    build_lifting();

    Q = (int)read_ll();

    for (int i = 0; i < Q; i++) {
        ll S = read_ll();
        ll T = read_ll();

        write_ll(solve_query(S, T));
    }

    return 0;
}

10. 시간복잡도

작업복잡도
기본 압축 이동 계산O(N log N)
Binary Lifting 전처리O(N × LOG)
각 쿼리 처리O(LOG + log N)
LOG20

LOG를 20으로 줄인 것이 #7 통과의 핵심입니다. 점프대 번호는 오른쪽으로만 증가하므로 2^19번 압축 이동이면 충분합니다.
