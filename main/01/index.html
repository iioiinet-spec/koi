다익스트라(Dijkstra) 알고리즘

가장 가까운 정점부터 최단거리를 확정하는 알고리즘

1. 다익스트라란?

다익스트라는 한 출발점에서 모든 정점까지의 최단거리를 구하는 알고리즘입니다.

1. 출발점의 거리는 0입니다.

2. 나머지 정점의 거리는 처음에 무한대입니다.

3. 아직 확정하지 않은 정점 중 거리가 가장 작은 정점을 고릅니다.

4. 그 정점에서 갈 수 있는 곳의 거리를 갱신합니다.

5. 이 과정을 반복하면 최단거리가 완성됩니다.

if (dist[next] > dist[now] + cost) {
    dist[next] = dist[now] + cost;
}

5. 쉬운 배열 버전 C 코드

#include <stdio.h>

#define INF 1000000000

int main() {
    int graph[5][5] = {
        {0,0,0,0,0},
        {0,0,2,5,0},
        {0,2,0,0,4},
        {0,5,0,0,1},
        {0,0,4,1,0}
    };

    int dist[5];
    int visited[5];

    for (int i = 1; i <= 4; i++) {
        dist[i] = INF;
        visited[i] = 0;
    }

    dist[1] = 0;

    for (int k = 1; k <= 4; k++) {
        int now = -1;
        int minDist = INF;

        for (int i = 1; i <= 4; i++) {
            if (!visited[i] && dist[i] < minDist) {
                minDist = dist[i];
                now = i;
            }
        }

        if (now == -1) break;

        visited[now] = 1;

        for (int next = 1; next <= 4; next++) {
            if (graph[now][next] != 0) {
                if (dist[next] > dist[now] + graph[now][next]) {
                    dist[next] = dist[now] + graph[now][next];
                }
            }
        }
    }

    for (int i = 1; i <= 4; i++) {
        printf("%d : %d\n", i, dist[i]);
    }

    return 0;
}

7. 자주 하는 실수

실수 1. 음수 간선에 사용하는 경우

다익스트라는 간선 비용이 음수이면 사용할 수 없습니다.

음수 간선이 있으면 이미 확정한 거리가 나중에 더 작아질 수 있어 원리가 깨집니다.

실수 2. INF를 너무 작게 잡는 경우

경로 비용이 클 수 있으므로 충분히 큰 값이 필요합니다.

비용이 큰 문제에서는 long long과 1e18 수준의 INF를 사용하는 것이 안전합니다.

실수 3. 오래된 힙 정보를 처리하는 경우

우선순위 큐에는 같은 정점이 여러 번 들어갈 수 있습니다.

if (cur.dist != dist[now]) continue; 로 오래된 정보를 건너뜁니다.

8. 핵심 정리

1. 다익스트라는 한 출발점에서 모든 정점까지의 최단거리를 구합니다.

2. 아직 확정하지 않은 정점 중 가장 가까운 정점을 선택합니다.

3. 핵심 갱신식은 dist[next] > dist[now] + cost입니다.

4. 작은 그래프는 배열 버전으로 이해합니다.

5. 큰 그래프는 우선순위 큐 버전을 사용합니다.
