Lazy Segment Tree

구간 업데이트 + 최댓값 쿼리를 직접 실험하는 인터랙티브 강의자료

1. Lazy Segment Tree는 언제 쓰는가?

다음 두 작업을 빠르게 해야 할 때 사용합니다.

1. 구간 [L, R]에 값을 더하기 2. 전체 또는 특정 구간의 최댓값 구하기

예를 들어 배열이 다음과 같다고 합시다.

A = [0, 0, 0, 0, 0]

여기서 `[1, 3]에 +2`, `[2, 5]에 +1` 같은 작업이 많이 들어오면 직접 배열을 모두 수정하면 느립니다.

2. Lazy의 뜻

Lazy는 “게으르게 미룬다”는 뜻입니다. 구간 전체에 더할 값이 있을 때, 자식 노드까지 바로 내려가지 않고 표시만 해둡니다.

tree[node] = 현재 구간의 최댓값 lazy[node] = 자식에게 아직 내려보내지 않은 값

완전히 포함되는 구간을 만나면 자식으로 내려가지 않고, 현재 노드의 tree와 lazy에만 값을 더합니다.

3. 예제 문제

N = 5 초기 배열 = 0 0 0 0 0 작업 1: [1, 3]에 +2 작업 2: [2, 5]에 +1 작업 3: [3, 3]에 +5 각 작업 후 전체 최댓값 출력
작업배열 상태최댓값
[1,3]+22 2 2 0 02
[2,5]+12 3 3 1 13
[3,3]+52 3 8 1 18

5. 코드 작성 방법

1단계. 배열 선언

#define MAXN 100000

int tree[MAXN * 4];
int lazy[MAXN * 4];

세그먼트 트리는 보통 원소 개수의 4배 크기로 잡습니다.

2단계. 최댓값 함수

int max_int(int a, int b) {
    return a > b ? a : b;
}

3단계. push 함수

void push(int node) {
    if (lazy[node] != 0) {
        int value = lazy[node];

        tree[node * 2] += value;
        lazy[node * 2] += value;

        tree[node * 2 + 1] += value;
        lazy[node * 2 + 1] += value;

        lazy[node] = 0;
    }
}

현재 노드에 미뤄둔 lazy 값을 왼쪽 자식과 오른쪽 자식에게 전달합니다.

4단계. update 함수의 3가지 경우

1. 전혀 안 겹치면 return 2. 완전히 포함되면 tree와 lazy에 value를 더하고 return 3. 일부만 겹치면 push 후 자식으로 내려감
void update(int node, int start, int end, int left, int right, int value) {
    if (right < start || end < left) {
        return;
    }

    if (left <= start && end <= right) {
        tree[node] += value;
        lazy[node] += value;
        return;
    }

    push(node);

    int mid = (start + end) / 2;

    update(node * 2, start, mid, left, right, value);
    update(node * 2 + 1, mid + 1, end, left, right, value);

    tree[node] = max_int(tree[node * 2], tree[node * 2 + 1]);
}

5단계. 전체 최댓값 출력

int query_max() {
    return tree[1];
}

루트 노드인 tree[1]이 전체 구간의 최댓값입니다.

6. 완성 C 코드

#include <stdio.h>

#define MAXN 100000

int tree[MAXN * 4];
int lazy[MAXN * 4];

int max_int(int a, int b) {
    return a > b ? a : b;
}

void push(int node) {
    if (lazy[node] != 0) {
        int value = lazy[node];

        tree[node * 2] += value;
        lazy[node * 2] += value;

        tree[node * 2 + 1] += value;
        lazy[node * 2 + 1] += value;

        lazy[node] = 0;
    }
}

void update(int node, int start, int end, int left, int right, int value) {
    if (right < start || end < left) {
        return;
    }

    if (left <= start && end <= right) {
        tree[node] += value;
        lazy[node] += value;
        return;
    }

    push(node);

    int mid = (start + end) / 2;

    update(node * 2, start, mid, left, right, value);
    update(node * 2 + 1, mid + 1, end, left, right, value);

    tree[node] = max_int(tree[node * 2], tree[node * 2 + 1]);
}

int query_max() {
    return tree[1];
}

int main() {
    int N = 5;

    update(1, 1, N, 1, 3, 2);
    printf("%d\n", query_max());

    update(1, 1, N, 2, 5, 1);
    printf("%d\n", query_max());

    update(1, 1, N, 3, 3, 5);
    printf("%d\n", query_max());

    return 0;
}

7. 핵심 정리

tree[node] = 현재 구간의 최댓값 lazy[node] = 아직 자식에게 안 내려보낸 값 update 핵심: 1. 안 겹치면 return 2. 완전히 포함되면 tree와 lazy에 더하고 return 3. 일부만 겹치면 push 후 자식으로 내려감

Lazy Segment Tree는 구간 전체를 한 번에 수정하는 문제에서 매우 중요합니다. 정올 #8607 상자 보관처럼 구간에 1을 더하고 최대값을 구하는 문제에 바로 사용할 수 있습니다.
