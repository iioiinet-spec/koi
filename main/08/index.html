정올 1396 창고다각형

왼쪽 최대 높이 + 오른쪽 최대 높이로 최소 면적을 구하는 인터랙티브 강의자료

1. 문제 핵심

여러 기둥을 모두 포함하면서, 비가 고이지 않도록 오목하지 않은 지붕을 만들어야 합니다.

창고 다각형의 최소 면적 왼쪽 → 가장 높은 기둥까지: 현재까지 만난 최대 높이로 지붕을 만든다. 오른쪽 → 가장 높은 기둥까지: 현재까지 만난 최대 높이로 지붕을 만든다.

가장 높은 기둥을 기준으로 왼쪽과 오른쪽을 나누어 계산하면 됩니다.

2. 왜 가장 높은 기둥을 기준으로 나누는가?

왼쪽에서 최고 기둥으로 갈 때 지붕이 낮아졌다가 다시 높아지면 오목한 부분이 생깁니다.

왼쪽 부분의 지붕 높이 = 왼쪽에서 현재까지의 최대 높이 오른쪽 부분의 지붕 높이 = 오른쪽에서 현재까지의 최대 높이

이렇게 해야 모든 기둥을 포함하면서 면적이 가장 작습니다.

3. 인터랙티브 계산기

기둥 정보를 입력하면 가장 높은 기둥, 왼쪽 면적, 오른쪽 면적, 전체 면적을 계산하고 그림으로 보여줍니다.


기둥 정보: L H 형식으로 한 줄에 하나씩 입력

파란 막대: 실제 기둥연한 파랑: 창고 다각형 면적주황색: 가장 높은 기둥

4. 코드 작성 방법

1단계. 위치별 높이 배열 만들기

#define MAXL 1000

int height[MAXL + 1];

기둥 위치 L이 1 이상 1000 이하이므로 배열로 관리할 수 있습니다.

2단계. 입력 받으면서 필요한 값 찾기

if (L < left) left = L;
if (L > right) right = L;

if (H > maxHeight) {
    maxHeight = H;
    maxPos = L;
}

3단계. 왼쪽에서 최고 기둥까지 계산

int current = 0;

for (int i = left; i <= maxPos; i++) {
    if (height[i] > current) {
        current = height[i];
    }

    area += current;
}

4단계. 오른쪽에서 최고 기둥 다음 위치까지 계산

current = 0;

for (int i = right; i > maxPos; i--) {
    if (height[i] > current) {
        current = height[i];
    }

    area += current;
}

최고 기둥 위치는 왼쪽 계산에서 이미 포함했으므로 오른쪽에서는 제외합니다.

5. 정답 C 코드

#include <stdio.h>

#define MAXL 1000

int height[MAXL + 1];

int main() {
    int N;
    int L, H;
    int left = 1001;
    int right = 0;
    int maxHeight = 0;
    int maxPos = 0;
    int area = 0;

    scanf("%d", &N);

    for (int i = 0; i < N; i++) {
        scanf("%d %d", &L, &H);
        height[L] = H;
        if (L < left) left = L;
        if (L > right) right = L;
        if (H > maxHeight) {
            maxHeight = H;
            maxPos = L;
        }
    }

    int current = 0;

    for (int i = left; i <= maxPos; i++) {
        if (height[i] > current) current = height[i];
        area += current;
    }

    current = 0;

    for (int i = right; i > maxPos; i--) {
        if (height[i] > current) current = height[i];
        area += current;
    }

    printf("%d\n", area);
    return 0;
}

6. 시간복잡도

입력 처리: O(N) 왼쪽 계산: O(1000) 오른쪽 계산: O(1000) 전체 시간복잡도 = O(N + 1000)

위치가 1000 이하이므로 배열을 이용한 풀이가 가장 쉽고 빠릅니다.
