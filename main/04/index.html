Binary Lifting

2의 거듭제곱 점프로 k번째 조상과 LCA를 빠르게 찾는 기법

1. Binary Lifting이란?

Binary Lifting은 트리에서 부모를 한 칸씩 올라가는 대신, 1칸, 2칸, 4칸, 8칸처럼 2의 거듭제곱 단위로 점프하는 기법입니다.

1. parent[0][v] = v의 1번째 조상입니다.

2. parent[1][v] = v의 2번째 조상입니다.

3. parent[2][v] = v의 4번째 조상입니다.

4. parent[k][v] = v의 2^k번째 조상입니다.

parent[k][v] = parent[k - 1][ parent[k - 1][v] ];

5. k번째 조상 코드

int getKthAncestor(int v, int k) {
    for (int i = 0; i <= LOG; i++) {
        if (k & (1 << i)) {
            v = parent[i][v];
        }
    }

    return v;
}

예를 들어 k=13이면 13=8+4+1이므로 8칸, 4칸, 1칸 점프합니다.

6. LCA 계산 과정

1. 두 정점 중 더 깊은 정점을 위로 올려 깊이를 맞춥니다.

2. 두 정점이 같아졌으면 그 정점이 LCA입니다.

3. 같지 않으면 큰 점프부터 동시에 올립니다.

4. 마지막에 parent[0][a]가 LCA입니다.

for (int i = LOG; i >= 0; i--) {
    if (parent[i][a] != parent[i][b]) {
        a = parent[i][a];
        b = parent[i][b];
    }
}

return parent[0][a];

7. 전체 C 코드

#include <stdio.h>

#define MAXN 100005
#define LOG 17

typedef struct {
    int to;
    int next;
} Edge;

Edge edges[MAXN * 2];
int head[MAXN];
int edgeCount = 0;

int parent[LOG + 1][MAXN];
int depth[MAXN];

void addEdge(int a, int b) {
    edges[edgeCount].to = b;
    edges[edgeCount].next = head[a];
    head[a] = edgeCount++;
}

void dfs(int now, int par) {
    parent[0][now] = par;

    for (int e = head[now]; e != -1; e = edges[e].next) {
        int next = edges[e].to;

        if (next == par) continue;

        depth[next] = depth[now] + 1;
        dfs(next, now);
    }
}

void buildTable(int N) {
    for (int k = 1; k <= LOG; k++) {
        for (int v = 1; v <= N; v++) {
            parent[k][v] = parent[k - 1][ parent[k - 1][v] ];
        }
    }
}

int lca(int a, int b) {
    if (depth[a] < depth[b]) {
        int temp = a;
        a = b;
        b = temp;
    }

    int diff = depth[a] - depth[b];

    for (int i = 0; i <= LOG; i++) {
        if (diff & (1 << i)) {
            a = parent[i][a];
        }
    }

    if (a == b) return a;

    for (int i = LOG; i >= 0; i--) {
        if (parent[i][a] != parent[i][b]) {
            a = parent[i][a];
            b = parent[i][b];
        }
    }

    return parent[0][a];
}

8. 자주 하는 실수

실수 1. parent[0]을 채우기 전에 buildTable을 하는 경우

parent[k]는 parent[k-1]을 이용해서 만들기 때문에 parent[0]이 먼저 완성되어야 합니다.

실수 2. 깊이를 맞추지 않고 동시에 올리는 경우

깊이가 다르면 같은 높이의 조상을 비교할 수 없으므로 더 깊은 정점을 먼저 올려야 합니다.

실수 3. LOG를 너무 작게 잡는 경우

100000보다 큰 2의 거듭제곱은 131072=2^17입니다. LOG는 17 이상이어야 합니다.

9. 핵심 정리

1. Binary Lifting은 2의 거듭제곱 점프로 조상을 빠르게 찾습니다.

2. parent[k][v]는 v의 2^k번째 조상입니다.

3. parent[k][v] = parent[k-1][parent[k-1][v]]입니다.

4. k번째 조상은 k의 이진수 비트를 보고 점프합니다.

5. LCA는 깊이를 맞춘 뒤 동시에 위로 올려 찾습니다.
