정올 #8605 거울

C언어 정답 코드 + 자세한 해설 + 단계별 코드 작성법 + 인터랙티브 실험

1. 문제 핵심 이해

캐릭터가 현재 위치 a에 있고, 거울이 위치 b에 있을 때, 거울을 사용하면 캐릭터는 거울을 기준으로 대칭 이동합니다.

새 위치 = 2 × b - a

예를 들어 현재 위치가 0이고, 거울 위치가 2라면

새 위치 = 2 × 2 - 0 = 4

즉, 2를 기준으로 0의 반대편인 4로 이동합니다.

문제의 중요한 조건은 N개의 거울을 모두 정확히 한 번씩 사용해야 한다는 것입니다. 사용하지 않을 수 없고, 두 번 사용할 수도 없습니다.

2. 거울 2개부터 직접 전개하기

처음 위치를 s, 첫 번째로 쓰는 거울을 b1, 두 번째로 쓰는 거울을 b2라고 해봅시다.

처음 위치 = s 1번째 거울 b1 사용: 2b1 - s 2번째 거울 b2 사용: 2b2 - (2b1 - s) = s + 2b2 - 2b1 = s + 2(b2 - b1)

여기서 중요한 사실이 나옵니다.

나중에 사용한 거울은 + 역할을 하고, 먼저 사용한 거울은 - 역할을 합니다.

예제 1

N = 2, s = 0 거울: -1, 2 순서: -1 → 2 최종 위치 = 0 + 2 × (2 - (-1)) = 6

3. 거울 3개, 4개일 때 규칙 찾기

거울 3개

처음 위치 = s b1 사용: 2b1 - s b2 사용: 2b2 - (2b1 - s) = s - 2b1 + 2b2 b3 사용: 2b3 - (s - 2b1 + 2b2) = -s + 2b1 - 2b2 + 2b3

부호만 보면 다음과 같습니다.

b1 : + b2 : - b3 : +

거울 4개

최종 위치 = s - 2b1 + 2b2 - 2b3 + 2b4
b1 : - b2 : + b3 : - b4 : +

정리하면 최종 위치는 거울들의 합으로 결정됩니다.

최댓값을 만들려면 +가 붙는 자리에는 큰 거울, -가 붙는 자리에는 작은 거울을 넣어야 합니다.

4. 왜 작은 값은 빼고 큰 값은 더해야 할까?

최종 위치에는 어떤 거울은 +2 × 거울 위치로 들어가고, 어떤 거울은 -2 × 거울 위치로 들어갑니다.

역할 어떤 값을 넣어야 유리한가? 이유
+ 역할 큰 값 더하는 값은 클수록 최종 위치가 커짐
- 역할 작은 값 빼는 값은 작을수록 최종 위치가 커짐

입력에서 거울 위치는 이미 오름차순으로 주어집니다. 따라서 정렬을 다시 할 필요가 없습니다.

5. 짝수 N과 홀수 N 공식

1. N이 짝수일 때

예를 들어 N = 6이면, + 역할 3개, - 역할 3개가 생깁니다.

작은 절반 3개 → - 역할 큰 절반 3개 → + 역할 answer = s + 2 × (큰 절반의 합 - 작은 절반의 합)

2. N이 홀수일 때

예를 들어 N = 9이면, + 역할 5개, - 역할 4개가 생깁니다. 그리고 처음 위치 s에는 음수 부호가 붙습니다.

작은 4개 → - 역할 큰 5개 → + 역할 answer = -s + 2 × (큰 쪽 합 - 작은 쪽 합)

따라서 공통적으로 다음처럼 생각할 수 있습니다.

minusCount = N / 2 plusCount = N - minusCount

작은 값 minusCount개는 빼고, 큰 값 plusCount개는 더합니다.

7. 코드 작성 방법을 단계적으로 배우기

1단계. 입력 받기

N은 int, s와 거울 위치는 범위가 크므로 long long을 사용합니다.

int N;
long long s;
long long A[200000];

scanf("%d %lld", &N, &s);

for (int i = 0; i < N; i++) {
    scanf("%lld", &A[i]);
}

2단계. 몇 개를 빼고 몇 개를 더할지 정하기

작은 값은 빼는 역할, 큰 값은 더하는 역할입니다. 

int minusCount = N / 2;
int plusCount = N - minusCount;

3단계. 작은 쪽 합 구하기

배열은 이미 오름차순입니다. 앞에서부터 minusCount개가 작은 값입니다. 

long long minusSum = 0;

for (int i = 0; i < minusCount; i++) {
    minusSum += A[i];
}

4단계. 큰 쪽 합 구하기

뒤에서 plusCount개가 큰 값입니다. 

long long plusSum = 0;

for (int i = N - plusCount; i < N; i++) {
    plusSum += A[i];
}

5단계. N의 홀짝에 따라 정답 계산하기

N이 짝수면 s가 그대로 들어가고, N이 홀수면 -s가 들어갑니다. 

long long answer;

if (N % 2 == 0) {
    answer = s + 2 * (plusSum - minusSum);
} else {
    answer = -s + 2 * (plusSum - minusSum);
}

6단계. 출력하기

printf("%lld\n", answer);

8. 정답 코드

#include <stdio.h>

#define MAXN 200000

long long A[MAXN];

int main() {
    int N;
    long long s;

    scanf("%d %lld", &N, &s);

    for (int i = 0; i < N; i++) {
        scanf("%lld", &A[i]);
    }

    long long plusSum = 0;
    long long minusSum = 0;

    int minusCount = N / 2;
    int plusCount = N - minusCount;

    for (int i = 0; i < minusCount; i++) {
        minusSum += A[i];
    }

    for (int i = N - plusCount; i < N; i++) {
        plusSum += A[i];
    }

    long long answer;

    if (N % 2 == 0) {
        answer = s + 2 * (plusSum - minusSum);
    } else {
        answer = -s + 2 * (plusSum - minusSum);
    }

    printf("%lld\n", answer);

    return 0;
}

9. 정답 코드 한 줄씩 해설

1. 배열과 변수 선언 
#define MAXN 200000

long long A[MAXN];

N의 최대가 200000이므로 배열 크기를 200000으로 잡습니다. 거울 위치는 -10억부터 10억까지 가능하고 합은 더 커질 수 있으므로 long long을 사용합니다.

2. 입력 받기 
scanf("%d %lld", &N, &s);

for (int i = 0; i < N; i++) {
    scanf("%lld", &A[i]);
}

첫 줄에서 N과 s를 입력받고, 둘째 줄에서 거울 위치들을 입력받습니다. 문제에서 이미 A1 ≤ A2 ≤ ... ≤ AN이라고 했기 때문에 정렬하지 않습니다.

3. 더할 개수와 뺄 개수 구하기 
int minusCount = N / 2;
int plusCount = N - minusCount;

N이 짝수면 plusCount와 minusCount가 같습니다. N이 홀수면 plusCount가 하나 더 많습니다.

4. 작은 쪽 합과 큰 쪽 합 구하기 
for (int i = 0; i < minusCount; i++) {
    minusSum += A[i];
}

for (int i = N - plusCount; i < N; i++) {
    plusSum += A[i];
}

작은 값들은 빼는 역할을 하므로 minusSum에 넣습니다. 큰 값들은 더하는 역할을 하므로 plusSum에 넣습니다.

5. 최종 답 계산 
if (N % 2 == 0) {
    answer = s + 2 * (plusSum - minusSum);
} else {
    answer = -s + 2 * (plusSum - minusSum);
}

거울을 사용할 때마다 현재 위치 앞에 붙은 부호가 바뀝니다. 그래서 N이 짝수면 처음 위치 s는 +s로 남고, N이 홀수면 처음 위치 s는 -s가 됩니다.

10. 시간복잡도와 자료형

항목 내용
시간복잡도 O(N)
공간복잡도 O(N)
필수 자료형 long long
정렬 여부 입력이 이미 정렬되어 있으므로 정렬 불필요

답은 int 범위를 넘을 수 있습니다. 예제 4의 출력도 -2999999998로 int 범위를 벗어납니다. 반드시 long long을 사용해야 합니다.

11. 연습 문제

아래 문제를 직접 풀어보고 답을 확인해 보세요.

문제 1

N = 2, s = 5 A = 1 10
정답: 23 N이 짝수입니다. 작은 절반 = 1 큰 절반 = 10 answer = 5 + 2 × (10 - 1) = 5 + 18 = 23

문제 2

N = 3, s = 4 A = 1 5 7
정답: 18 N이 홀수입니다. 작은 1개 = 1 큰 2개 = 5 + 7 = 12 answer = -4 + 2 × (12 - 1) = -4 + 22 = 18 주의: 정답은 18입니다.
