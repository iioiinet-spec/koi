주사위 탑 쌓기

서로 마주 보는 면의 합이 7이라는 성질을 이용해, 최소 탑 수를 단순한 개수 계산으로 바꾸는 과정을 직접 실험하며 이해합니다.

쌓기 조건 숫자쌍 핵심 공식 탑 시뮬레이터 예제 증명 C 코드 확인 문제

1두 주사위를 언제 쌓을 수 있을까요?

주사위의 윗면이 x라면 아랫면은 반드시 7-x입니다.

아래 주사위

윗면 숫자가 x입니다.

위 주사위

윗면 숫자가 y이므로 아랫면은 7-y입니다.

맞닿는 두 면이 같아야 하므로:

x = 7-y
따라서 x+y=7
즉, 서로 쌓을 수 있는 윗면 숫자는 반드시 합이 7이어야 합니다.

2가능한 숫자쌍은 세 종류뿐입니다

1과 6

1 → 6 → 1 → 6처럼 번갈아 쌓습니다.

2와 5

2 → 5 → 2 → 5처럼 번갈아 쌓습니다.

3과 4

3 → 4 → 3 → 4처럼 번갈아 쌓습니다.

1과 6으로 만든 탑에 2나 5를 넣을 수 없습니다. 따라서 세 숫자쌍은 서로 독립적으로 계산한 뒤 더하면 됩니다.

3한 숫자쌍의 최소 탑 수

한 쌍의 두 숫자 개수를 각각 a, b라고 합시다.

a=b=0 → 0개
a=b>0 → 1개
a≠b → |a-b|개

개수가 같은 경우

모두 번갈아 쌓아 하나의 긴 탑으로 만들 수 있습니다.

3,3 → 탑 1개

개수가 다른 경우

많은 쪽의 남는 주사위는 각각 다른 탑의 끝이 되어야 합니다.

4,1 → |4-1|=3개

4직접 탑을 만들어 보기

숫자쌍과 각 개수를 입력하면 실제로 가능한 최소 탑 구성을 보여줍니다.

값을 입력하고 최소 탑 구성을 눌러 보세요.

7왜 개수 차이가 정답일까요?

1. 한 탑에서 두 숫자의 개수 차이는 최대 1

숫자는 반드시 x, y, x, y처럼 번갈아 나옵니다. 따라서 한 탑에서는 두 숫자의 개수 차이가 0 또는 1입니다.

2. 전체 개수 차이가 d라면 최소 d개의 탑 필요

한 탑이 많은 쪽의 초과분을 최대 1개만 담당할 수 있으므로, 전체 초과분이 d개라면 적어도 d개의 탑이 필요합니다.

3. 실제로 d개의 탑으로 만들 수 있음

적은 쪽 주사위를 많은 쪽 주사위 사이에 번갈아 배치하면, 남는 많은 쪽 주사위들이 각각 탑 하나의 시작 또는 끝이 됩니다. 따라서 정확히 d개의 탑으로 모두 사용할 수 있습니다.

8코드 작성 단계

1단계

count[1]부터 count[6]까지 숫자별 개수를 셉니다.

2단계

(1,6), (2,5), (3,4)를 각각 계산합니다.

3단계

둘 다 0이면 0, 같으면 1, 다르면 절댓값 차이를 더합니다.

4단계

세 쌍의 결과를 모두 더해 출력합니다.

시간 복잡도는 O(N), 공간 복잡도는 O(1)입니다.

9C 정답 코드

전체 코드 펼치기 / 접기 
#include <stdio.h>

long long minimum_towers(long long a, long long b)
{
    long long difference;

    /*
        두 숫자의 주사위가 모두 없다면
        해당 숫자쌍의 탑은 필요 없다.
    */
    if (a == 0 && b == 0) {
        return 0;
    }

    /*
        두 개수가 같고 하나 이상 있다면
        모두 번갈아 쌓아 하나의 탑으로 만들 수 있다.
    */
    if (a == b) {
        return 1;
    }

    /*
        개수가 다르면 두 개수의 차이만큼
        최소 탑이 필요하다.
    */
    difference = a - b;

    if (difference < 0) {
        difference = -difference;
    }

    return difference;
}

int main(void)
{
    int N;
    long long count[7] = {0};
    long long answer = 0;

    scanf("%d", &N);

    /*
        각 윗면 숫자의 개수를 센다.
    */
    for (int i = 0; i < N; i++) {
        int value;

        scanf("%d", &value);
        count[value]++;
    }

    /*
        서로 쌓을 수 있는 세 숫자쌍을
        각각 독립적으로 계산한다.
    */
    answer += minimum_towers(count[1], count[6]);
    answer += minimum_towers(count[2], count[5]);
    answer += minimum_towers(count[3], count[4]);

    printf("%lld\n", answer);

    return 0;
}

11최종 핵심 정리

1. 서로 쌓을 수 있는 윗면 숫자의 합은 7입니다.

2. 가능한 숫자쌍은 (1,6), (2,5), (3,4)입니다.

3. 한 탑에서는 두 숫자가 번갈아 나옵니다.

4. 개수가 다르면 개수 차이만큼 탑이 필요합니다.

5. 개수가 같고 하나 이상 있으면 탑 1개입니다.
