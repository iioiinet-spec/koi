허용된 교환과 합치기만 사용하여 순열 A를 목표 수열 B로 바꾸는 방법을, 그룹 배정 관점에서 단계별로 이해하는 인터랙티브 강의자료입니다.

2그룹 번호로 바꾸기

group[x] = j 는 값 x가 최종적으로 B[j]와 합쳐진다는 뜻입니다.

조건 A

B에 직접 들어 있는 값은 자기 위치가 고정됩니다.

group[B[j]] = j

조건 B

x가 B[j]와 합쳐져 B[j]가 남으려면 B[j]가 더 작거나 같아야 합니다.

B[j] ≤ x

조건 C

A에서 큰 값 x가 작은 값 y보다 앞에 있으면 두 값의 상대 순서를 뒤집을 수 없습니다.

x>y, pos[x]<pos[y] ⇒ group[x]≤group[y]

왜 큰 값이 앞에 있으면 순서를 뒤집을 수 없을까요?

예를 들어 A 안에 8이 3보다 앞에 있다고 하겠습니다. 둘의 순서를 뒤집으려면 언젠가 인접한 상태에서 [8,3] → [3,8] 교환이 필요합니다. 하지만 교환 조건은 왼쪽 값이 더 작아야 하므로 8과 3은 바꿀 수 없습니다.

3큰 값부터 그룹을 정하는 그리디

값을 N, N-1, …, 1 순서로 처리합니다.

현재 값 x가 들어가야 하는 최소 그룹

x보다 큰 값 u 중에서 A에서 u가 x보다 앞에 있으면, u의 그룹은 x의 그룹보다 뒤로 갈 수 없습니다.

need[x] = max(group[u])

단, u > x 이고 pos[u] < pos[x]인 u만 고려합니다.

x가 B에 있는 값

그룹은 이미 고정되어 있습니다.

group[x] = fixedGroup[x]

고정 그룹이 need보다 작으면 불가능합니다.

x가 B에 없는 값

다음 두 조건을 만족하는 가장 작은 j를 선택합니다.

j ≥ need[x]


B[j] ≤ x

왜 가장 작은 그룹을 선택할까요? 앞쪽 그룹을 사용할 수 있으면 먼저 사용해야 뒤에서 처리할 더 작은 값들이 선택할 수 있는 그룹을 최대한 남길 수 있습니다.

5그룹끼리 모으는 실제 교환

그룹 번호가 감소하는 인접한 두 원소를 버블 정렬처럼 바꿉니다.

중요: group[left] > group[right]라면 반드시 left < right입니다. 그래서 문제에서 허용하는 교환 조건을 자동으로 만족합니다.
1group 2
4group 1
2group 2
3group 1

그룹 번호 순서가 2,1,2,1이므로 잘못된 인접 쌍을 바꾸면 1,1,2,2가 됩니다.

7정당성 증명

1. 그룹 조건이 왜 필요한가?

합치면 최솟값만 남으므로 그룹 j에 들어가는 모든 값 x는 B[j] 이상이어야 합니다. 또한 초기 A에서 큰 값이 작은 값보다 앞에 있으면 둘의 상대 순서를 뒤집을 수 없으므로 큰 값의 그룹 번호가 더 뒤가 될 수 없습니다.

2. 그리디가 왜 안전한가?

현재 가능한 그룹 중 가장 작은 번호를 선택하면, 어떤 가능한 해보다 그룹 번호를 더 크게 만들지 않습니다. 따라서 뒤에서 처리할 더 작은 값의 선택 가능성을 줄이지 않습니다.

3. 그룹 정렬의 모든 교환이 왜 허용되는가?

group[x] > group[y]인 인접 쌍을 바꿀 때 x > y라면 초기 순서 불변 조건에 위배됩니다. 따라서 반드시 x < y이고 교환 연산이 허용됩니다.

4. 합친 결과가 왜 정확히 B인가?

각 그룹에는 B[j]가 반드시 포함되고, 그 외 모든 값은 B[j] 이상입니다. 따라서 그룹 전체의 최솟값은 B[j]입니다.

9C 정답 코드

아래 코드는 그룹을 결정한 뒤, 실제 교환과 합치기 연산을 생성합니다.

전체 코드 펼치기 / 접기 
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int type;
    int index;
} Operation;

int main(void)
{
    int N, M;
    scanf("%d %d", &N, &M);

    int *A = (int *)malloc(sizeof(int) * (N + 1));
    int *B = (int *)malloc(sizeof(int) * (M + 1));
    int *pos = (int *)malloc(sizeof(int) * (N + 1));
    int *group = (int *)calloc(N + 1, sizeof(int));
    int *fixed = (int *)calloc(N + 1, sizeof(int));

    Operation *op =
        (Operation *)malloc(sizeof(Operation) * (size_t)N * N);
    int q = 0;

    for (int i = 1; i <= N; i++) {
        scanf("%d", &A[i]);
        pos[A[i]] = i;
    }

    for (int j = 1; j <= M; j++) {
        scanf("%d", &B[j]);
        fixed[B[j]] = j;
    }

    /* 1. 큰 값부터 그룹 결정 */
    for (int x = N; x >= 1; x--) {
        int need = 1;

        for (int u = x + 1; u <= N; u++) {
            if (pos[u] < pos[x] && group[u] > need) {
                need = group[u];
            }
        }

        if (fixed[x] != 0) {
            if (fixed[x] < need) {
                printf("NO\n");
                return 0;
            }
            group[x] = fixed[x];
        }
        else {
            int selected = 0;

            for (int j = need; j <= M; j++) {
                if (B[j] <= x) {
                    selected = j;
                    break;
                }
            }

            if (selected == 0) {
                printf("NO\n");
                return 0;
            }

            group[x] = selected;
        }
    }

    /* 2. 그룹 번호 기준 버블 정렬 */
    for (int pass = 1; pass <= N; pass++) {
        for (int i = 1; i < N; i++) {
            if (group[A[i]] > group[A[i + 1]]) {
                int temp;

                if (A[i] >= A[i + 1]) {
                    printf("NO\n");
                    return 0;
                }

                op[q].type = 1;
                op[q].index = i;
                q++;

                temp = A[i];
                A[i] = A[i + 1];
                A[i + 1] = temp;
            }
        }
    }

    /* 3. 같은 그룹 합치기 */
    int len = N;
    int start = 1;

    for (int j = 1; j <= M; j++) {
        int size = 0;

        for (int i = 1; i <= len; i++) {
            if (group[A[i]] == j) {
                size++;
            }
        }

        for (int cnt = 1; cnt < size; cnt++) {
            op[q].type = 2;
            op[q].index = start;
            q++;

            if (A[start + 1] < A[start]) {
                A[start] = A[start + 1];
            }

            for (int i = start + 1; i < len; i++) {
                A[i] = A[i + 1];
            }

            len--;
        }

        if (A[start] != B[j]) {
            printf("NO\n");
            return 0;
        }

        start++;
    }

    printf("YES\n");
    printf("%d\n", q);

    for (int i = 0; i < q; i++) {
        printf("%d %d\n", op[i].type, op[i].index);
    }

    free(A);
    free(B);
    free(pos);
    free(group);
    free(fixed);
    free(op);

    return 0;
}
