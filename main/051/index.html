정올 #8607 상자 보관

구간 [c, s) 변환 + 좌표 압축 + Lazy Segment Tree 인터랙티브 강의자료

1. 문제 핵심 이해

상자 A를 상자 B 안에 넣으려면 A의 크기가 B의 보관 용량보다 작거나 같아야 합니다.

상자 A가 상자 B 안에 들어갈 조건 s_A ≤ c_B

한 상자 안에는 직접적으로 최대 한 개의 상자만 넣을 수 있으므로, 상자들은 여러 개의 체인으로 나누어집니다.

작은 상자 → 더 큰 상자 → 더 큰 상자 → ... 보관 비용 = 다른 상자에 들어가지 않은 상자의 개수 = 필요한 체인 개수

2. 상자를 구간으로 바꾸기

i번 상자의 크기가 s_i, 보관 용량이 c_i라면 이 상자를 다음 구간으로 바꿉니다.

상자 i → 구간 [c_i, s_i)

1번부터 i번 상자까지의 최소 보관 비용은 지금까지 나온 구간들의 최대 겹침 개수와 같습니다.

따라서 문제는 다음처럼 바뀝니다.

상자가 하나씩 추가된다. 각 상자마다 구간 [c_i, s_i)에 1을 더한다. 매번 전체 구간의 최댓값을 출력한다.

3. 예제 1 이해하기

4 6 4 5 1 9 8 2 1
상자 크기 s 용량 c 구간 [c, s)
164[4, 6)
251[1, 5)
398[8, 9)
421[1, 2)

1번과 2번 구간은 [4, 5)에서 겹치므로 최대 겹침이 2가 됩니다. 그래서 2번 상자까지의 답은 2입니다.

4. 인터랙티브 계산기

상자 정보를 입력하면 각 단계마다 구간 최대 겹침 개수와 정답을 보여줍니다.


상자 정보: s c 형식으로 한 줄에 하나씩 입력

5. 좌표 압축이 필요한 이유

s_i와 c_i는 최대 10억입니다. 따라서 실제 좌표를 배열 인덱스로 쓰면 메모리가 너무 커집니다.

등장하는 c_i와 s_i만 모아서 정렬한 뒤 작은 번호로 바꾸면 됩니다.

예: 좌표가 1, 2, 4, 5, 6, 8, 9라면 1 → 0 2 → 1 4 → 2 5 → 3 6 → 4 8 → 5 9 → 6

6. 코드 작성 단계

1단계. 배열 선언

#define MAXN 200000
#define MAXC 400005

int s[MAXN + 1];
int c[MAXN + 1];

int coord[MAXC];
int tree[MAXC * 4];
int lazy[MAXC * 4];

각 상자마다 c와 s를 좌표 압축에 넣으므로 좌표는 최대 2N개입니다.

2단계. 좌표 압축

coord[idx++] = c[i];
coord[idx++] = s[i];

qsort(coord, idx, sizeof(int), compare_int);

int M = 0;

for (int i = 0; i < idx; i++) {
    if (i == 0 || coord[i] != coord[i - 1]) {
        coord[M++] = coord[i];
    }
}

3단계. 구간 [c, s)를 세그먼트 트리 인덱스로 바꾸기

int left = lower_bound_coord(c[i], M);
int right = lower_bound_coord(s[i], M) - 1;

구간은 [c, s)이므로 s는 포함하지 않습니다. 그래서 오른쪽 끝은 s의 위치에서 1을 뺍니다.

4단계. 구간에 1 더하기

update(1, 0, M - 2, left, right, 1);

좌표가 M개라면 실제 관리할 구간 칸은 M-1개입니다. 그래서 세그먼트 트리는 0부터 M-2까지 관리합니다.

5단계. 정답 출력

printf("%d\n", tree[1]);

tree[1]은 전체 구간의 최댓값입니다. 이것이 현재까지 상자들의 최소 보관 비용입니다.

7. 정답 C 코드

#include <stdio.h>
#include <stdlib.h>

#define MAXN 200000
#define MAXC 400005

int N;
int s[MAXN + 1];
int c[MAXN + 1];

int coord[MAXC];
int tree[MAXC * 4];
int lazy[MAXC * 4];

int compare_int(const void *a, const void *b) {
    int x = *(int *)a;
    int y = *(int *)b;

    if (x < y) return -1;
    if (x > y) return 1;
    return 0;
}

int lower_bound_coord(int value, int M) {
    int left = 0;
    int right = M - 1;
    int answer = M;

    while (left <= right) {
        int mid = (left + right) / 2;

        if (coord[mid] >= value) {
            answer = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }

    return answer;
}

void push(int node) {
    if (lazy[node] != 0) {
        int value = lazy[node];

        tree[node * 2] += value;
        lazy[node * 2] += value;

        tree[node * 2 + 1] += value;
        lazy[node * 2 + 1] += value;

        lazy[node] = 0;
    }
}

void update(int node, int start, int end, int left, int right, int value) {
    if (right < start || end < left) {
        return;
    }

    if (left <= start && end <= right) {
        tree[node] += value;
        lazy[node] += value;
        return;
    }

    push(node);

    int mid = (start + end) / 2;

    update(node * 2, start, mid, left, right, value);
    update(node * 2 + 1, mid + 1, end, left, right, value);

    if (tree[node * 2] > tree[node * 2 + 1]) {
        tree[node] = tree[node * 2];
    } else {
        tree[node] = tree[node * 2 + 1];
    }
}

int main() {
    scanf("%d", &N);

    int idx = 0;

    for (int i = 1; i <= N; i++) {
        scanf("%d %d", &s[i], &c[i]);

        coord[idx++] = c[i];
        coord[idx++] = s[i];
    }

    qsort(coord, idx, sizeof(int), compare_int);

    int M = 0;

    for (int i = 0; i < idx; i++) {
        if (i == 0 || coord[i] != coord[i - 1]) {
            coord[M++] = coord[i];
        }
    }

    for (int i = 1; i <= N; i++) {
        int left = lower_bound_coord(c[i], M);
        int right = lower_bound_coord(s[i], M) - 1;

        if (left <= right) {
            update(1, 0, M - 2, left, right, 1);
        }

        printf("%d\n", tree[1]);
    }

    return 0;
}

8. 정답 코드 해설

1. 구간 [c, s)를 사용하는 이유

상자의 용량 c와 크기 s 사이의 구간이 이 상자가 체인을 하나 필요로 하는 영역입니다. 여러 상자의 구간이 같은 위치에서 겹치면, 그만큼 동시에 다른 체인이 필요합니다.

2. M - 2까지 업데이트하는 이유

좌표가 M개라면 실제 구간은 좌표와 좌표 사이이므로 M-1개입니다. 인덱스는 0부터 M-2까지입니다.

3. lazy 배열의 역할

넓은 구간에 1을 더할 때 모든 칸을 직접 바꾸면 느립니다. lazy 배열은 나중에 필요할 때 자식에게 값을 전달하기 위한 배열입니다.

4. tree[1]이 답인 이유

tree[1]은 세그먼트 트리 전체 구간의 최댓값입니다. 즉, 현재까지 추가한 모든 [c, s) 구간의 최대 겹침 개수입니다. 이것이 최소 보관 비용입니다.

9. 시간복잡도

작업복잡도
좌표 압축 정렬O(N log N)
각 상자 구간 업데이트O(log N)
전체O(N log N)

N ≤ 200000이므로 Lazy Segment Tree를 사용하면 충분히 통과할 수 있습니다.
