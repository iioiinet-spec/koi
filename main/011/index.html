정올 3163 정기권

다익스트라 4번 + S-T 최단경로 DAG + 양방향 무료 DP

1. 문제 핵심

조이는 S에서 T까지 가는 최단경로 하나를 정기권 경로로 선택합니다. 이 경로에 포함된 간선은 양방향 무료가 됩니다. 목표는 정기권 경로를 잘 선택해서 U에서 V로 가는 비용을 최소화하는 것입니다.

1. 정기권 경로는 반드시 S-T 최단경로여야 합니다.

2. S-T 최단경로가 여러 개면 U-V에 가장 유리한 경로를 고릅니다.

3. 정기권 간선은 양방향 무료입니다.

4. 답은 정기권 선택 후 U-V 최소 비용입니다.

2. 작은 그래프 인터렉티브 시뮬레이터

기본 정보


간선 입력

한 줄에 a b cost

최단거리 4종류

S-T 최단경로 위 정점

S→T 방향 DP

T→S 방향 DP

3. 필요한 최단거리

이 문제는 다익스트라를 4번 실행합니다.

distS[x] = S에서 x까지 최단거리
distT[x] = T에서 x까지 최단거리
distU[x] = U에서 x까지 최단거리
distV[x] = V에서 x까지 최단거리

4. S-T 최단경로 위 정점과 간선

정점 x가 S-T 최단경로 위에 있으려면 다음 조건을 만족합니다.

distS[x] + distT[x] == distS[T]

간선 now → next가 A→B 방향의 최단경로 위에 있으려면 다음 조건을 만족합니다.

distA[now] + cost + distB[next] == shortest

5. DP의 의미

1. bestU[x] : 무료 구간을 타고 x까지 올 수 있을 때, U에서 무료 구간 시작점까지 가는 비용의 최솟값입니다.

2. bestV[x] : 무료 구간을 타고 x까지 올 수 있을 때, V에서 무료 구간 시작점까지 가는 비용의 최솟값입니다.

answer = min(answer, bestU[x] + distV[x]);
answer = min(answer, bestV[x] + distU[x]);

6. 양방향 무료 처리

정기권에 포함된 간선은 양방향 무료입니다. 그래서 S→T 방향과 T→S 방향을 모두 처리해야 합니다.

answer = min(answer, solveDirection(distS, distT, shortestST));
answer = min(answer, solveDirection(distT, distS, shortestST));

7. 코드 작성 순서

1. 그래프를 인접 리스트로 저장합니다.

2. long long으로 거리 배열을 만듭니다.

3. S, T, U, V에서 다익스트라를 실행합니다.

4. S-T 최단경로 위 정점과 간선을 판정합니다.

5. dist 기준 정렬로 최단경로 DAG를 앞에서부터 처리합니다.

6. bestU, bestV를 전파합니다.

7. 두 방향의 결과와 distU[V] 중 최솟값을 출력합니다.

8. 정답 C 코드

#include <stdio.h>
#include <stdlib.h>

#define MAXN 100005
#define MAXE 400005
#define INF 4000000000000000000LL

typedef long long ll;

typedef struct {
    int to;
    int next;
    ll cost;
} Edge;

typedef struct {
    int node;
    ll dist;
} HeapNode;

int N, M;
int S, T, U, V;

Edge edges[MAXE];
int head[MAXN];
int edgeCount = 0;

ll distS[MAXN], distT[MAXN], distU[MAXN], distV[MAXN];
ll bestU[MAXN], bestV[MAXN];

int order[MAXN];

HeapNode heap[MAXE];
int heapSize;

ll *sortDist;

void addEdge(int a, int b, ll c) {
    edges[edgeCount].to = b;
    edges[edgeCount].cost = c;
    edges[edgeCount].next = head[a];
    head[a] = edgeCount++;
}

void heapPush(int node, ll dist) {
    int idx = ++heapSize;

    while (idx > 1) {
        int parent = idx / 2;

        if (heap[parent].dist <= dist) break;

        heap[idx] = heap[parent];
        idx = parent;
    }

    heap[idx].node = node;
    heap[idx].dist = dist;
}

HeapNode heapPop() {
    HeapNode ret = heap[1];
    HeapNode last = heap[heapSize--];

    int parent = 1;
    int child = 2;

    while (child <= heapSize) {
        if (child + 1 <= heapSize && heap[child + 1].dist < heap[child].dist) {
            child++;
        }

        if (heap[child].dist >= last.dist) break;

        heap[parent] = heap[child];
        parent = child;
        child *= 2;
    }

    heap[parent] = last;

    return ret;
}

void dijkstra(int start, ll dist[]) {
    for (int i = 1; i <= N; i++) {
        dist[i] = INF;
    }

    heapSize = 0;
    dist[start] = 0;
    heapPush(start, 0);

    while (heapSize > 0) {
        HeapNode cur = heapPop();
        int now = cur.node;

        if (cur.dist != dist[now]) continue;

        for (int e = head[now]; e != -1; e = edges[e].next) {
            int next = edges[e].to;
            ll cost = edges[e].cost;

            if (dist[next] > dist[now] + cost) {
                dist[next] = dist[now] + cost;
                heapPush(next, dist[next]);
            }
        }
    }
}

int cmpOrder(const void *a, const void *b) {
    int x = *(int *)a;
    int y = *(int *)b;

    if (sortDist[x] < sortDist[y]) return -1;
    if (sortDist[x] > sortDist[y]) return 1;
    return x - y;
}

ll min(ll a, ll b) {
    return a < b ? a : b;
}

ll solveDirection(ll distA[], ll distB[], ll shortest) {
    for (int i = 1; i <= N; i++) {
        order[i] = i;
        bestU[i] = INF;
        bestV[i] = INF;
    }

    sortDist = distA;
    qsort(order + 1, N, sizeof(int), cmpOrder);

    for (int i = 1; i <= N; i++) {
        int x = order[i];

        if (distA[x] + distB[x] == shortest) {
            bestU[x] = distU[x];
            bestV[x] = distV[x];
        }
    }

    ll answer = INF;

    for (int idx = 1; idx <= N; idx++) {
        int now = order[idx];

        if (distA[now] + distB[now] != shortest) continue;

        answer = min(answer, bestU[now] + distV[now]);
        answer = min(answer, bestV[now] + distU[now]);

        for (int e = head[now]; e != -1; e = edges[e].next) {
            int next = edges[e].to;
            ll cost = edges[e].cost;

            if (distA[now] + cost + distB[next] == shortest) {
                if (bestU[next] > bestU[now]) bestU[next] = bestU[now];
                if (bestV[next] > bestV[now]) bestV[next] = bestV[now];
            }
        }
    }

    return answer;
}

int main() {
    scanf("%d %d", &N, &M);
    scanf("%d %d", &S, &T);
    scanf("%d %d", &U, &V);

    for (int i = 1; i <= N; i++) {
        head[i] = -1;
    }

    for (int i = 0; i < M; i++) {
        int a, b;
        ll c;

        scanf("%d %d %lld", &a, &b, &c);

        addEdge(a, b, c);
        addEdge(b, a, c);
    }

    dijkstra(S, distS);
    dijkstra(T, distT);
    dijkstra(U, distU);
    dijkstra(V, distV);

    ll shortestST = distS[T];

    ll answer = distU[V];

    answer = min(answer, solveDirection(distS, distT, shortestST));
    answer = min(answer, solveDirection(distT, distS, shortestST));

    printf("%lld\n", answer);

    return 0;
}

9. 자주 하는 실수

실수 1. S→T 방향만 처리하는 경우

정기권 간선은 양방향 무료이므로 T→S 방향도 처리해야 합니다.

solveDirection(distT, distS, shortestST)를 추가해야 무료 구간을 반대로 타는 경우를 잡을 수 있습니다.

실수 2. int 사용

비용이 매우 커서 int 범위를 넘습니다.

예제 2의 답이 3000000000입니다. 반드시 long long을 사용해야 합니다.

실수 3. 최단경로 위가 아닌 간선으로 DP 전파

정기권 경로는 S-T 최단경로여야 합니다.

distA[now] + cost + distB[next] == shortest 조건을 만족하는 간선만 전파해야 합니다.

10. 핵심 정리

1. 다익스트라를 S, T, U, V에서 총 4번 실행합니다.

2. S-T 최단경로 위 정점은 distS[x] + distT[x] == distS[T]입니다.

3. 최단경로 위 간선으로만 DP를 전파합니다.

4. bestU와 bestV로 무료 구간 진입 비용의 최솟값을 관리합니다.

5. 양방향 무료이므로 S→T, T→S 두 방향을 모두 처리합니다.

6. 모든 거리와 답은 long long을 사용합니다.
