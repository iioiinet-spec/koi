앨리스의 선택

현재 방에 연결된 서로 다른 통로 중 정확히 k개를 고릅니다.

같은 이웃 방으로 가는 통로가 여러 개라면 여러 개를 동시에 고를 수 있습니다.

밥의 선택

앨리스가 고른 k개의 통로 중 하나를 골라 실제 이동 방향을 결정합니다.

따라서 앨리스는 밥이 어느 통로를 골라도 이길 수 있도록 골라야 합니다.

핵심: 현재 방에서 이기려면, 이미 이길 수 있는 방으로 가는 “안전한 통로”를 최소 k개 확보해야 합니다.

2k가 하나로 고정되었다면

고정된 k에 대해 다음 과정을 반복할 수 있습니다.

1단계

출구가 있는 방은 이동하지 않고 즉시 승리합니다.

2단계

승리 가능한 방으로 연결되는 통로가 k개 이상인 방을 새로 승리 가능하게 만듭니다.

3단계

더 이상 추가할 방이 없을 때까지 반복합니다.

이 과정은 여러 출구에서 동시에 시작하는 BFS와 비슷하지만, 간선 개수를 누적해 임계값 k를 넘는 순간 방이 활성화된다는 점이 다릅니다.

3각 방의 최대 승리 가능 k

질의마다 게임을 다시 계산하지 않고, 각 방 x에 대해 다음 값을 미리 구합니다.

F[x] = x번 방에서 승리할 수 있는 최대 k

출구가 있는 방

이동하지 않아도 되므로 모든 k에서 승리합니다.

F[x] = ∞

출구가 없는 방

k에서도 이기는 방으로 연결되는 통로가 k개 이상 필요합니다.

Σ c(x,y) ≥ k

합은 F[y] ≥ k인 이웃 y만 포함합니다.

질의 (s,k)는 전처리 후 k ≤ F[s]인지 한 번만 비교하면 됩니다.

4왜 최대 힙을 사용할까요?

다익스트라가 가장 짧은 거리부터 확정하는 것처럼, 이 문제는 승리 가능한 k가 가장 큰 방부터 확정합니다.

새 후보 계산

현재 확정한 방의 값이 currentValue이고, 어떤 이웃 방 u가 확보한 안전한 통로 수가 sum[u]라면:

candidate = min(currentValue, sum[u])

왜 currentValue 이하인가?

연결된 안전 방이 k=currentValue까지만 승리한다면, 그보다 큰 k에서는 안전하다고 보장할 수 없습니다.

왜 sum[u] 이하인가?

통로를 sum[u]개만 확보했다면 그보다 많은 통로를 고를 수 없습니다.

7정당성 증명

1. 알고리즘이 만든 값은 실제로 가능한가?

candidate=t라면 sum[u]≥t이고, 누적된 통로들의 반대쪽 방은 모두 t에서도 승리 가능합니다. 앨리스가 그 통로 중 t개를 고르면 밥이 어느 통로를 선택해도 승리 가능한 방으로 갑니다.

2. 실제 가능한 값을 빠뜨리지 않는가?

어떤 방이 k에서 승리 가능해지는 순간, k에서도 승리 가능한 이웃으로 가는 통로가 k개 이상 존재합니다. 그 이웃들이 모두 확정되면 sum[u]≥k가 되고 candidate도 k 이상이므로 반드시 힙에 들어갑니다.

3. 왜 가장 큰 후보부터 확정해도 되는가?

현재 최대 후보보다 더 큰 값이 나중에 생기려면, 더 큰 값을 가진 이웃이 아직 처리되지 않아야 합니다. 하지만 최대 힙은 그런 더 큰 이웃을 먼저 꺼내므로 현재 최대 후보는 안전하게 확정할 수 있습니다.

8시간 복잡도

단계복잡도설명
그래프 저장O(N+M)각 통로 종류를 양방향 간선으로 저장
최대 힙 전처리O((N+M) log N)방 확정과 간선 갱신
질의 처리O(Q)k ≤ F[s] 비교
전체O((N+M) log N + Q)대규모 입력에 적합
자료형 주의: c, k, sum[], best[]는 반드시 long long을 사용해야 합니다.

9C 정답 코드

전체 코드 펼치기 / 접기 
#include <stdio.h>
#include <stdlib.h>

#define INF 4000000000000000000LL

typedef struct {
    int to;
    int next;
    long long weight;
} Edge;

typedef struct {
    int vertex;
    long long value;
} HeapNode;

typedef struct {
    HeapNode *data;
    int size;
} MaxHeap;

long long min_ll(long long a, long long b)
{
    return a < b ? a : b;
}

void heap_push(MaxHeap *heap, int vertex, long long value)
{
    int idx = ++heap->size;

    while (idx > 1) {
        int parent = idx / 2;

        if (heap->data[parent].value >= value) {
            break;
        }

        heap->data[idx] = heap->data[parent];
        idx = parent;
    }

    heap->data[idx].vertex = vertex;
    heap->data[idx].value = value;
}

HeapNode heap_pop(MaxHeap *heap)
{
    HeapNode result = heap->data[1];
    HeapNode last = heap->data[heap->size--];

    int parent = 1;

    while (parent * 2 <= heap->size) {
        int child = parent * 2;

        if (child + 1 <= heap->size &&
            heap->data[child + 1].value >
            heap->data[child].value) {
            child++;
        }

        if (heap->data[child].value <= last.value) {
            break;
        }

        heap->data[parent] = heap->data[child];
        parent = child;
    }

    if (heap->size >= 1) {
        heap->data[parent] = last;
    }

    return result;
}

void add_edge(
    Edge *edges,
    int *head,
    int *edgeCount,
    int from,
    int to,
    long long weight
)
{
    edges[*edgeCount].to = to;
    edges[*edgeCount].weight = weight;
    edges[*edgeCount].next = head[from];
    head[from] = *edgeCount;
    (*edgeCount)++;
}

int main(void)
{
    int N, M, Q;
    scanf("%d %d %d", &N, &M, &Q);

    int *exitRoom = malloc(sizeof(int) * (N + 1));
    int *head = malloc(sizeof(int) * (N + 1));
    Edge *edges = malloc(sizeof(Edge) * (2 * M + 5));

    long long *best = calloc(N + 1, sizeof(long long));
    long long *sum = calloc(N + 1, sizeof(long long));
    char *finished = calloc(N + 1, sizeof(char));

    MaxHeap heap;
    heap.data = malloc(
        sizeof(HeapNode) * (2 * M + N + 5)
    );
    heap.size = 0;

    for (int i = 1; i <= N; i++) {
        head[i] = -1;
        scanf("%d", &exitRoom[i]);
    }

    int edgeCount = 0;

    for (int i = 0; i < M; i++) {
        int a, b;
        long long c;

        scanf("%d %d %lld", &a, &b, &c);

        add_edge(edges, head, &edgeCount, a, b, c);
        add_edge(edges, head, &edgeCount, b, a, c);
    }

    for (int i = 1; i <= N; i++) {
        if (exitRoom[i]) {
            best[i] = INF;
            heap_push(&heap, i, INF);
        }
    }

    while (heap.size > 0) {
        HeapNode cur = heap_pop(&heap);
        int room = cur.vertex;

        if (finished[room]) {
            continue;
        }

        if (cur.value != best[room]) {
            continue;
        }

        finished[room] = 1;

        for (int e = head[room]; e != -1; e = edges[e].next) {
            int next = edges[e].to;

            if (finished[next]) {
                continue;
            }

            sum[next] += edges[e].weight;

            long long candidate =
                min_ll(cur.value, sum[next]);

            if (candidate > best[next]) {
                best[next] = candidate;
                heap_push(&heap, next, candidate);
            }
        }
    }

    while (Q--) {
        int s;
        long long k;

        scanf("%d %lld", &s, &k);

        if (k <= best[s]) {
            printf("YES\n");
        }
        else {
            printf("NO\n");
        }
    }

    free(exitRoom);
    free(head);
    free(edges);
    free(best);
    free(sum);
    free(finished);
    free(heap.data);

    return 0;
}
