정올 4947 트리의 지름

BFS 두 번으로 가장 먼 두 노드 사이의 거리 찾기

1. 문제 핵심

트리의 지름은 트리에서 가장 멀리 떨어진 두 노드 사이의 거리입니다. 이 문제는 간선 가중치가 없으므로 거리는 간선의 개수입니다.

1. 아무 노드에서 BFS를 합니다.

2. 가장 먼 노드 A를 찾습니다.

3. A에서 다시 BFS를 합니다.

4. A에서 가장 먼 거리 = 트리의 지름입니다.

4. 왜 BFS 두 번이면 되는가?

1. 트리에서 아무 노드에서 가장 먼 노드는 지름의 한쪽 끝점이 됩니다.

2. 그 끝점에서 다시 가장 먼 노드를 찾으면 지름의 반대쪽 끝점을 찾을 수 있습니다.

3. 따라서 BFS를 두 번 하면 가장 긴 거리, 즉 지름을 구할 수 있습니다.

1번 노드
↓ BFS
가장 먼 노드 A
↓ BFS
A에서 가장 먼 거리 = 트리의 지름

6. 정답 C 코드

#include <stdio.h>

#define MAXN 100005
#define MAXE 200005

typedef struct {
    int to;
    int next;
} Edge;

Edge edges[MAXE];
int head[MAXN];
int edgeCount = 0;

int dist[MAXN];
int queue[MAXN];

int N;

void addEdge(int a, int b) {
    edges[edgeCount].to = b;
    edges[edgeCount].next = head[a];
    head[a] = edgeCount++;
}

int bfs(int start, int *maxDistance) {
    int front = 0;
    int rear = 0;

    for (int i = 1; i <= N; i++) {
        dist[i] = -1;
    }

    dist[start] = 0;
    queue[rear++] = start;

    while (front < rear) {
        int now = queue[front++];

        for (int e = head[now]; e != -1; e = edges[e].next) {
            int next = edges[e].to;

            if (dist[next] == -1) {
                dist[next] = dist[now] + 1;
                queue[rear++] = next;
            }
        }
    }

    int farNode = start;
    *maxDistance = 0;

    for (int i = 1; i <= N; i++) {
        if (dist[i] > *maxDistance) {
            *maxDistance = dist[i];
            farNode = i;
        }
    }

    return farNode;
}

int main() {
    scanf("%d", &N);

    for (int i = 1; i <= N; i++) {
        head[i] = -1;
    }

    for (int i = 0; i < N - 1; i++) {
        int a, b;
        scanf("%d %d", &a, &b);
        addEdge(a, b);
        addEdge(b, a);
    }

    int maxDistance = 0;
    int A = bfs(1, &maxDistance);
    bfs(A, &maxDistance);

    printf("%d\n", maxDistance);

    return 0;
}

7. 자주 하는 실수

실수 1. 간선을 단방향으로만 저장

입력은 부모-자식이지만 지름은 양방향으로 계산해야 합니다.

addEdge(a,b)와 addEdge(b,a)를 모두 해야 합니다.

실수 2. 재귀 DFS 사용

N이 100,000이므로 일자 트리에서 스택 오버플로우가 날 수 있습니다.

큐를 이용한 BFS가 C에서는 더 안전합니다.

실수 3. 거리 기준을 노드 개수로 세는 경우

이 문제의 거리는 간선 개수입니다.

8→4→2→1→3→7→9는 노드 7개지만 간선은 6개이므로 지름은 6입니다.

8. 핵심 정리

1. 트리의 지름은 가장 먼 두 노드 사이의 거리입니다.

2. BFS(1)로 가장 먼 노드 A를 찾습니다.

3. BFS(A)로 가장 먼 거리를 찾습니다.

4. 그 거리가 트리의 지름입니다.

5. 간선은 반드시 양방향으로 저장합니다.
