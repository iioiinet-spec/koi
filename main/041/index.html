트리의 공통 조상 LCA

Binary Lifting으로 두 노드의 가장 가까운 공통 조상 찾기

1. 문제 핵심

루트가 1번인 트리에서 두 노드 A, B가 주어질 때 두 노드의 가장 가까운 공통 조상, 즉 LCA를 출력하는 문제입니다.

1. LCA는 Lowest Common Ancestor의 약자입니다.

2. 두 노드가 공통으로 가지는 조상 중 가장 아래쪽 조상입니다.

3. N과 Q가 최대 300,000이므로 한 칸씩 올라가면 시간초과가 납니다.

4. Binary Lifting으로 O(log N)에 질의를 처리합니다.

3. depth와 parent 테이블

BFS로 depth와 parent[0]을 만들고, 이후 parent[k] 테이블을 완성합니다.

4. 직접 트리 입력해서 실행하기

작은 트리를 입력하면 LCA 테이블을 만들어 확인할 수 있습니다.

5. LCA 계산 방법

1. 더 깊은 노드를 위로 올려 두 노드의 깊이를 맞춥니다.

2. 두 노드가 같아지면 그 노드가 LCA입니다.

3. 다르면 큰 점프부터 동시에 위로 올립니다.

4. 두 노드가 LCA 바로 아래에 도착하면 parent[0][a]가 답입니다.

if (depth[a] < depth[b]) swap(a, b);

diff = depth[a] - depth[b];

for (k = 0; k < LOG; k++) {
    if (diff & (1 << k)) {
        a = parent[k][a];
    }
}

if (a == b) return a;

for (k = LOG - 1; k >= 0; k--) {
    if (parent[k][a] != parent[k][b]) {
        a = parent[k][a];
        b = parent[k][b];
    }
}

return parent[0][a];

6. 정답 C 코드

#include <stdio.h>

#define MAXN 300005
#define MAXE 600005
#define LOG 20

typedef struct {
    int to;
    int next;
} Edge;

Edge edges[MAXE];
int head[MAXN];
int edgeCount = 0;

int parent[LOG][MAXN];
int depth[MAXN];
int visited[MAXN];
int queue[MAXN];

void addEdge(int a, int b) {
    edges[edgeCount].to = b;
    edges[edgeCount].next = head[a];
    head[a] = edgeCount++;
}

void bfs(int root) {
    int front = 0;
    int rear = 0;

    visited[root] = 1;
    depth[root] = 0;
    parent[0][root] = 0;
    queue[rear++] = root;

    while (front < rear) {
        int now = queue[front++];

        for (int e = head[now]; e != -1; e = edges[e].next) {
            int next = edges[e].to;

            if (visited[next]) continue;

            visited[next] = 1;
            depth[next] = depth[now] + 1;
            parent[0][next] = now;
            queue[rear++] = next;
        }
    }
}

void buildTable(int N) {
    for (int k = 1; k < LOG; k++) {
        for (int v = 1; v <= N; v++) {
            parent[k][v] = parent[k - 1][ parent[k - 1][v] ];
        }
    }
}

int lca(int a, int b) {
    if (depth[a] < depth[b]) {
        int temp = a;
        a = b;
        b = temp;
    }

    int diff = depth[a] - depth[b];

    for (int k = 0; k < LOG; k++) {
        if (diff & (1 << k)) {
            a = parent[k][a];
        }
    }

    if (a == b) return a;

    for (int k = LOG - 1; k >= 0; k--) {
        if (parent[k][a] != parent[k][b]) {
            a = parent[k][a];
            b = parent[k][b];
        }
    }

    return parent[0][a];
}

int main() {
    int N, Q;

    scanf("%d", &N);

    for (int i = 1; i <= N; i++) {
        head[i] = -1;
    }

    for (int i = 0; i < N - 1; i++) {
        int a, b;
        scanf("%d %d", &a, &b);
        addEdge(a, b);
        addEdge(b, a);
    }

    bfs(1);
    buildTable(N);

    scanf("%d", &Q);

    for (int i = 0; i < Q; i++) {
        int a, b;
        scanf("%d %d", &a, &b);
        printf("%d\n", lca(a, b));
    }

    return 0;
}

7. 왜 BFS를 사용하는가?

N이 최대 300,000이므로 재귀 DFS를 사용하면 트리가 일자로 긴 경우 C에서 스택 오버플로우가 날 수 있습니다. 그래서 큐를 이용한 BFS가 안전합니다.

8. 자주 하는 실수

실수 1. LOG를 너무 작게 잡는 경우

N이 300,000이므로 2^19=524,288까지 필요합니다. LOG는 20으로 잡으면 안전합니다.

실수 2. 깊이를 맞추지 않고 동시에 올리는 경우

두 노드의 깊이가 다르면 같은 높이의 조상을 비교할 수 없으므로 먼저 깊이를 맞춰야 합니다.

실수 3. parent[0]을 만들기 전에 테이블을 만드는 경우

parent[k]는 parent[k-1]로 만들기 때문에 BFS로 parent[0]을 먼저 완성해야 합니다.

9. 핵심 정리

1. LCA는 두 노드의 가장 가까운 공통 조상입니다.

2. parent[k][v]는 v의 2^k번째 조상입니다.

3. BFS로 depth와 parent[0]을 만듭니다.

4. Binary Lifting 테이블을 만듭니다.

5. 질의마다 깊이를 맞춘 뒤 동시에 위로 올립니다.

6. 전처리 O(N log N), 질의 O(log N)입니다.
