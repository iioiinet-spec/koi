정올 5758 배수가 되는 두 수의 합

나머지 개수 세기 + 조합 계산을 직접 확인하는 인터랙티브 강의자료

1. 문제 핵심

두 수의 합이 X의 배수가 되려면 다음 조건을 만족해야 합니다.

(a + b) % X == 0

실제 숫자 전체보다 X로 나눈 나머지가 중요합니다.

a % X = r1 b % X = r2 (r1 + r2) % X == 0 이면 (a + b)는 X의 배수

2. 예제 이해

N = 4 A = 1 4 2 1 X = 2
수2로 나눈 나머지
11
40
20
11
나머지 0: 2개 → 4, 2 나머지 1: 2개 → 1, 1 가능한 쌍: 0 + 0 = 0 1 + 1 = 2 정답 = 2

4. 코드 작성 방법

1단계. 배열과 cnt 만들기

#define MAXN 200000

long long A[MAXN];
long long cnt[10];

X는 최대 10이므로 나머지는 0부터 9까지만 필요합니다.

2단계. 입력받기

scanf("%d", &N);

for (int i = 0; i < N; i++) {
    scanf("%lld", &A[i]);
}

scanf("%d", &X);

X가 세 번째 줄에 나오므로, 먼저 A 배열을 저장한 뒤 X를 입력받습니다.

3단계. 나머지 개수 세기

for (int i = 0; i < N; i++) {
    int r = A[i] % X;
    cnt[r]++;
}

4단계. 나머지 쌍 확인하기

for (int i = 0; i < X; i++) {
    for (int j = i; j < X; j++) {
        if ((i + j) % X == 0) {
            ...
        }
    }
}

j를 i부터 시작하면 (i, j)와 (j, i)를 중복해서 세지 않습니다.

5단계. 같은 나머지와 다른 나머지 구분

if (i == j) {
    answer += cnt[i] * (cnt[i] - 1) / 2;
} else {
    answer += cnt[i] * cnt[j];
}

5. 최종 정답 C 코드

#include <stdio.h>

#define MAXN 200000

long long A[MAXN];
long long cnt[10];

int main() {
    int N;
    int X;
    long long answer = 0;

    scanf("%d", &N);

    for (int i = 0; i < N; i++) {
        scanf("%lld", &A[i]);
    }

    scanf("%d", &X);

    for (int i = 0; i < N; i++) {
        int r = A[i] % X;
        cnt[r]++;
    }

    for (int i = 0; i < X; i++) {
        for (int j = i; j < X; j++) {
            if ((i + j) % X == 0) {
                if (i == j) {
                    answer += cnt[i] * (cnt[i] - 1) / 2;
                } else {
                    answer += cnt[i] * cnt[j];
                }
            }
        }
    }

    printf("%lld\n", answer);

    return 0;
}

6. 코드 해설

1. 왜 long long을 쓰는가?

N이 최대 200000입니다. 가능한 쌍의 개수는 최대 N × (N - 1) / 2가 될 수 있어 int 범위를 넘을 수 있습니다.

2. cnt[r]의 의미

cnt[r]은 X로 나누었을 때 나머지가 r인 수의 개수입니다.

3. 같은 나머지끼리 고를 때
cnt[i] C 2 = cnt[i] × (cnt[i] - 1) / 2
4. 다른 나머지끼리 고를 때
경우의 수 = cnt[i] × cnt[j]

7. 시간복잡도

수열 저장: O(N) 나머지 개수 세기: O(N) 나머지 쌍 확인: O(X²) X ≤ 10 이므로 전체 시간복잡도는 O(N)

모든 두 수를 직접 비교하지 않고, 나머지 개수만 세면 빠르게 해결됩니다.
