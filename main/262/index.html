간식 분배

현재 남아 있는 좋아하는 간식이 정확히 하나인 학생부터 처리하는 ‘차수 1 제거’ 알고리즘을 시각적으로 이해하는 인터랙티브 강의자료입니다.

문제 핵심 그래프 표현 알고리즘 단계 시뮬레이터 직접 입력 정당성 C 코드 확인 문제

1학생이 정확히 하나를 가져가려면

학생은 방에 남아 있는 좋아하는 간식을 모두 가져갑니다.

0개 남음

아무것도 가져가지 못하므로 실패합니다.

1개 남음

정확히 하나를 가져가므로 성공합니다.

2개 이상 남음

여러 개를 가져가므로 실패합니다.

따라서 매 순간 선택할 수 있는 학생은 오직 현재 남은 좋아하는 간식 수 = 1 인 학생입니다.

2학생과 간식을 이분 그래프로 보기

학생과 간식을 서로 다른 두 종류의 정점으로 생각합니다.

학생 i가 간식 x를 좋아한다 → 학생 i와 간식 x 사이에 간선 하나

학생의 현재 차수

아직 방에 남아 있는 좋아하는 간식의 수입니다.

간식 제거

간식 x가 사라지면 x를 좋아하던 모든 미처리 학생의 차수가 1 감소합니다.

이 문제는 차수 1인 학생을 계속 제거하는 ‘껍질 벗기기’ 과정으로 해결할 수 있습니다.

3핵심 알고리즘

1단계

초기 차수가 1인 학생을 모두 큐에 넣습니다.

2단계

큐에서 학생 한 명을 꺼냅니다.

3단계

그 학생의 유일하게 남은 간식을 찾고 제거합니다.

4단계

그 간식을 좋아하는 다른 학생들의 차수를 1 감소시킵니다.

차수가 새롭게 1이 된 학생을 다시 큐에 넣습니다. 모든 학생을 처리하면 성공, 중간에 큐가 비면 불가능합니다.

4예제 1 단계 시뮬레이터

학생 1:{1,2}, 학생 2:{2,3}, 학생 3:{2}를 사용합니다.

5직접 입력하여 실행하기

첫 줄에는 N, 다음 N줄에는 각 학생의 좋아하는 간식 번호를 공백으로 입력합니다.

위 입력은 각 줄에 간식 목록만 적습니다. 개수 C는 자동으로 계산됩니다.

입력을 불러오면 상태가 표시됩니다.

로그

6필요한 자료구조

배열의미
studentHead[i]학생 i가 좋아하는 간식 목록의 시작
snackHead[x]간식 x를 좋아하는 학생 목록의 시작
degree[i]현재 남아 있는 좋아하는 간식의 수
removedSnack[x]간식 x가 이미 제거되었는지 여부
processedStudent[i]학생 i가 이미 처리되었는지 여부
전체 선호 관계 수를 S라고 하면 시간 복잡도와 공간 복잡도는 모두 O(N+S)입니다.

7정당성 증명

1. 알고리즘이 출력한 순서는 왜 올바른가?

학생을 처리할 때 현재 차수가 정확히 1인지 확인하므로, 그 학생은 좋아하는 간식을 정확히 하나만 가져갑니다.

2. 차수 1인 학생이 없으면 왜 불가능한가?

남은 학생의 차수가 모두 0 또는 2 이상이면 누구를 보내도 0개 또는 여러 개를 가져갑니다. 따라서 다음 학생을 선택할 수 없습니다.

3. 차수 1인 학생을 먼저 보내도 안전한가?

그 학생은 현재 유일한 간식 하나만 가져가므로 조건을 정확히 만족합니다. 이후에는 해당 학생과 간식을 제거한 더 작은 같은 문제만 남습니다.

8코드 작성 단계

1단계

학생→간식, 간식→학생 인접 리스트를 동시에 만듭니다.

2단계

각 학생의 초기 차수를 C_i로 저장합니다.

3단계

차수가 1인 학생을 큐에 넣습니다.

4단계

유일한 간식을 제거하고 관련 학생 차수를 줄입니다.

5단계

차수가 새로 1이 되면 큐에 삽입합니다.

6단계

처리한 학생 수가 N인지 확인합니다.

9C 정답 코드

전체 코드 펼치기 / 접기 
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int student;
    int snack;
    int nextStudent;
    int nextSnack;
} Edge;

int main(void)
{
    int N;
    int edgeCount = 0;
    int front = 0;
    int rear = 0;
    int answerCount = 0;

    scanf("%d", &N);

    int *studentHead =
        (int *)malloc(sizeof(int) * (N + 1));

    int *snackHead =
        (int *)malloc(sizeof(int) * (N + 1));

    int *degree =
        (int *)malloc(sizeof(int) * (N + 1));

    int *queue =
        (int *)malloc(sizeof(int) * (N + 1));

    int *answer =
        (int *)malloc(sizeof(int) * (N + 1));

    char *processedStudent =
        (char *)calloc(N + 1, sizeof(char));

    char *removedSnack =
        (char *)calloc(N + 1, sizeof(char));

    Edge *edges =
        (Edge *)malloc(sizeof(Edge) * 500005);

    for (int i = 1; i <= N; i++) {
        studentHead[i] = -1;
        snackHead[i] = -1;
    }

    for (int student = 1; student <= N; student++) {
        int C;
        scanf("%d", &C);

        degree[student] = C;

        for (int j = 0; j < C; j++) {
            int snack;
            scanf("%d", &snack);

            edges[edgeCount].student = student;
            edges[edgeCount].snack = snack;

            edges[edgeCount].nextStudent =
                studentHead[student];
            studentHead[student] = edgeCount;

            edges[edgeCount].nextSnack =
                snackHead[snack];
            snackHead[snack] = edgeCount;

            edgeCount++;
        }
    }

    for (int student = 1; student <= N; student++) {
        if (degree[student] == 1) {
            queue[rear++] = student;
        }
    }

    while (front < rear) {
        int student = queue[front++];
        int selectedSnack = -1;

        if (processedStudent[student]) {
            continue;
        }

        if (degree[student] != 1) {
            continue;
        }

        for (
            int e = studentHead[student];
            e != -1;
            e = edges[e].nextStudent
        ) {
            int snack = edges[e].snack;

            if (!removedSnack[snack]) {
                selectedSnack = snack;
                break;
            }
        }

        if (selectedSnack == -1) {
            continue;
        }

        processedStudent[student] = 1;
        answer[answerCount++] = student;
        removedSnack[selectedSnack] = 1;

        for (
            int e = snackHead[selectedSnack];
            e != -1;
            e = edges[e].nextSnack
        ) {
            int otherStudent = edges[e].student;

            if (processedStudent[otherStudent]) {
                continue;
            }

            degree[otherStudent]--;

            if (degree[otherStudent] == 1) {
                queue[rear++] = otherStudent;
            }
        }
    }

    if (answerCount != N) {
        printf("-1\n");
    }
    else {
        for (int i = 0; i < N; i++) {
            if (i > 0) {
                printf(" ");
            }

            printf("%d", answer[i]);
        }

        printf("\n");
    }

    free(studentHead);
    free(snackHead);
    free(degree);
    free(queue);
    free(answer);
    free(processedStudent);
    free(removedSnack);
    free(edges);

    return 0;
}
