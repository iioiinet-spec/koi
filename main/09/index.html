정올 8140 에너지 교환

같은 방향 구간 분석으로 M분 후 남은 에너지 합을 구하는 인터랙티브 강의자료

1. 문제 핵심

거북이는 매 분 자신의 방향에 따라 에너지를 1씩 보냅니다.

'L' : 왼쪽 거북이에게 1 전달 'R' : 오른쪽 거북이에게 1 전달 에너지가 용량 a_i를 넘으면 초과분은 사라진다.

N은 최대 200000, M은 최대 10억입니다. 1분씩 시뮬레이션하면 시간초과가 납니다.

2. 핵심 관찰

방향이 모두 같으면 에너지는 원형으로 계속 돌기만 하므로 사라지지 않습니다.

LLLLL 또는 RRRRR 모든 거북이가 동시에 1을 주고 1을 받는다. 전체 에너지 합은 그대로 유지된다.

에너지가 사라지는 곳은 방향이 바뀌는 주변입니다.

같은 방향으로 연속된 구간을 찾아서, 각 구간에서 사라질 수 있는 에너지를 계산하면 됩니다.

3. R 구간과 L 구간의 손실 공식

1. R 구간

R R R R 에너지는 오른쪽으로 흐른다. 마지막 R은 경계 역할을 하므로 제외한다. canLose = 구간 전체 에너지 합 - 마지막 R의 에너지 loss = min(M, canLose)

2. L 구간

L L L L 에너지는 왼쪽으로 흐른다. 첫 번째 L은 경계 역할을 하므로 제외한다. canLose = 구간 전체 에너지 합 - 첫 번째 L의 에너지 loss = min(M, canLose)

4. 인터랙티브 계산기

방향 문자열과 에너지 배열을 입력하면 같은 방향 구간, 구간별 손실, 최종 정답을 계산합니다.

원형을 구간 처리 순서로 펼친 모습

1단계. 입력 저장

M과 전체 에너지 합은 클 수 있으므로 long long을 사용합니다.

2단계. 모든 방향이 같은지 확인

3단계. 원형을 선형처럼 처리할 시작점 찾기

for (int i = 0; i < N; i++) {
    int prev = (i - 1 + N) % N;

    if (s[i] != s[prev]) {
        start = i;
        break;
    }
}

방향이 바뀌는 곳을 시작점으로 잡으면 같은 방향 구간을 순서대로 처리할 수 있습니다.

4단계. 같은 방향 구간 찾기

while (idx < N) {
    char dir = s[(start + idx) % N];

    int begin = idx;
    long long sum = 0;

    while (idx < N && s[(start + idx) % N] == dir) {
        int real = (start + idx) % N;
        sum += a[real];
        idx++;
    }

    int end = idx - 1;
}

5단계. 구간별 손실 계산

if (dir == 'R') {
    int last = (start + end) % N;
    canLose = sum - a[last];
} else {
    int first = (start + begin) % N;
    canLose = sum - a[first];

6. 정답 C 코드

#include <stdio.h>

#define MAXN 200000

int N;
long long M;
char s[MAXN + 5];
long long a[MAXN + 5];

long long min_ll(long long x, long long y) {
    return x < y ? x : y;
}

int main() {
    scanf("%d %lld", &N, &M);
    scanf("%s", s);

    long long total = 0;

    for (int i = 0; i < N; i++) {
        scanf("%lld", &a[i]);
        total += a[i];
    }

    int same = 1;

    for (int i = 1; i < N; i++) {
        if (s[i] != s[0]) {
            same = 0;
            break;
        }
    }

    if (same) {
        printf("%lld\n", total);
        return 0;
    }

    int start = 0;

    for (int i = 0; i < N; i++) {
        int prev = (i - 1 + N) % N;

        if (s[i] != s[prev]) {
            start = i;
            break;
        }
    }

    long long loss = 0;
    int idx = 0;

    while (idx < N) {
        char dir = s[(start + idx) % N];

        int begin = idx;
        long long sum = 0;

        while (idx < N && s[(start + idx) % N] == dir) {
            int real = (start + idx) % N;
            sum += a[real];
            idx++;
        }

        int end = idx - 1;
        long long canLose = 0;

        if (dir == 'R') {
            int last = (start + end) % N;
            canLose = sum - a[last];
        } else {
            int first = (start + begin) % N;
            canLose = sum - a[first];
        }

        loss += min_ll(M, canLose);
    }

    printf("%lld\n", total - loss);

    return 0;
}

7. 시간복잡도

각 거북이는 같은 방향 구간 처리에서 정확히 한 번만 포함된다. 전체 시간복잡도 = O(N)
