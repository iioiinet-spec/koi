정올 #8608 가방

정렬 + 누적합 + 용량별 최댓값 계산을 직접 확인하는 인터랙티브 강의자료

1. 문제를 쉽게 이해하기

상훈이는 도둑이 오기 전에 몇 개의 물건을 가방에 담아 가져갈 수 있습니다. 이후 도둑은 남아 있는 물건 중에서 무게 합이 가장 작게 되도록 K개를 훔칩니다.

도둑이 훔치는 K개의 무게 합을 크게 만들려면 어떻게 해야 할까요?

정답은 가벼운 물건을 먼저 치우는 것입니다.

가벼운 물건을 가방에 담는다 → 남은 물건 중 가장 가벼운 K개가 더 무거워진다 → 도둑이 훔치는 무게 합이 커진다

2. 왜 정렬이 필요한가?

도둑은 항상 남은 물건 중 가장 가벼운 K개를 훔칩니다. 그래서 물건을 무게 오름차순으로 정렬하면 생각이 쉬워집니다.

예: 2 3 5 7 11, K = 2 제거 없음: 도둑 = 2 + 3 = 5 2 제거: 남은 물건 = 3 5 7 11 도둑 = 3 + 5 = 8 2, 3 제거: 남은 물건 = 5 7 11 도둑 = 5 + 7 = 12

앞에서 r개의 가벼운 물건을 치우면, 도둑은 그 다음 K개의 물건을 훔칩니다.

3. 공식 만들기

정렬된 배열을 다음처럼 둡니다.

A[0], A[1], A[2], ..., A[N-1]

앞에서 r개를 가방에 담아 치웠다고 합시다.

가방에 담은 무게 = A[0] + A[1] + ... + A[r-1] 도둑이 훔치는 무게 = A[r] + A[r+1] + ... + A[r+K-1]

누적합 prefix를 쓰면 빠르게 구할 수 있습니다.

prefix[i] = A[0] + A[1] + ... + A[i-1] 제거 비용 = prefix[r] 도둑이 훔치는 합 = prefix[r + K] - prefix[r]

4. 인터랙티브 계산기

N, K, C와 물건 무게를 입력하면 x = 1부터 C까지의 답을 계산합니다. 각 용량에서 몇 개의 가벼운 물건을 제거하는지도 보여줍니다.




물건 무게

5. 코드 작성 방법 단계별 설명

1단계. 필요한 배열 만들기

N은 최대 5000이므로 배열은 5000보다 조금 크게 잡으면 됩니다.

#define MAXN 5000

long long A[MAXN + 1];
long long prefix[MAXN + 1];

2단계. 입력 받기

scanf("%d %d %d", &N, &K, &C);

for (int i = 0; i < N; i++) {
    scanf("%lld", &A[i]);
}

3단계. 오름차순 정렬하기

도둑은 가벼운 물건부터 훔치므로, 정렬이 필요합니다.

qsort(A, N, sizeof(long long), compare_ll);

4단계. 누적합 만들기

구간 합을 빠르게 구하기 위해 prefix 배열을 만듭니다.

prefix[0] = 0;

for (int i = 0; i < N; i++) {
    prefix[i + 1] = prefix[i] + A[i];
}

5단계. 용량 x마다 가능한 제거 개수 r 찾기

x가 1, 2, 3, ... 으로 증가하므로 r도 줄어들지 않습니다. 따라서 while문으로 계속 증가시키면 전체적으로 빠르게 처리됩니다. 

int r = 0;

for (int x = 1; x <= C; x++) {
    while (r + 1 <= N - K && prefix[r + 1] <= x) {
        r++;
    }

    long long answer = prefix[r + K] - prefix[r];

    printf("%lld\n", answer);
}

6. 정답 C 코드

#include <stdio.h>
#include <stdlib.h>

#define MAXN 5000

long long A[MAXN + 1];
long long prefix[MAXN + 1];

int compare_ll(const void *a, const void *b) {
    long long x = *(long long *)a;
    long long y = *(long long *)b;

    if (x < y) return -1;
    if (x > y) return 1;
    return 0;
}

int main() {
    int N, K;
    int C;

    scanf("%d %d %d", &N, &K, &C);

    for (int i = 0; i < N; i++) {
        scanf("%lld", &A[i]);
    }

    qsort(A, N, sizeof(long long), compare_ll);

    prefix[0] = 0;

    for (int i = 0; i < N; i++) {
        prefix[i + 1] = prefix[i] + A[i];
    }

    int r = 0;

    for (int x = 1; x <= C; x++) {
        while (r + 1 <= N - K && prefix[r + 1] <= x) {
            r++;
        }

        long long answer = prefix[r + K] - prefix[r];

        printf("%lld\n", answer);
    }

    return 0;
}

7. 정답 코드 해설

1. compare_ll 함수 
int compare_ll(const void *a, const void *b) {
    long long x = *(long long *)a;
    long long y = *(long long *)b;

    if (x < y) return -1;
    if (x > y) return 1;
    return 0;
}

C언어의 qsort에서 사용하는 비교 함수입니다. x가 y보다 작으면 앞에 오도록 -1을 반환합니다.

2. 정렬 
qsort(A, N, sizeof(long long), compare_ll);

물건을 가벼운 순서대로 정렬합니다. 이 문제의 핵심은 앞쪽 가벼운 물건을 제거하는 것입니다.

3. 누적합 
prefix[0] = 0;

for (int i = 0; i < N; i++) {
    prefix[i + 1] = prefix[i] + A[i];
}

prefix[i]는 앞에서 i개의 물건 무게 합입니다. 예를 들어 A = 2, 3, 5라면 prefix는 0, 2, 5, 10입니다.

4. 제거 개수 r 
while (r + 1 <= N - K && prefix[r + 1] <= x) {
    r++;
}

r은 가방에 담아서 제거할 수 있는 앞쪽 물건의 개수입니다. 단, 도둑이 훔칠 K개는 남아 있어야 하므로 r은 N-K를 넘을 수 없습니다.

5. 정답 계산 
long long answer = prefix[r + K] - prefix[r];

앞에서 r개를 제거하면 도둑은 A[r]부터 A[r+K-1]까지 훔칩니다. 이 합은 prefix[r+K] - prefix[r]입니다.

8. 시간복잡도

작업 복잡도
정렬 O(N log N)
누적합 O(N)
x = 1부터 C까지 출력 O(C)
전체 O(N log N + C)

C는 최대 1,000,000입니다. 각 x마다 처음부터 다시 찾으면 느릴 수 있습니다. 하지만 r은 계속 증가만 하므로 전체 계산은 빠르게 끝납니다.
