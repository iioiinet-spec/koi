그래프를 인접행렬로 저장하기

정점과 간선을 2차원 배열에 저장하는 방법을 그림, 행렬, C 코드로 단계별 학습합니다.

1. 개념2. 행렬 표현3. 간선 추가4. 방향 그래프5. C 코드6. 특징7. 문제
1

인접행렬이란?

정점 수가 N개이면
graph[N][N]
간선이 있으면
graph[u][v] = 1
간선이 없으면
graph[u][v] = 0

인접행렬은 정점끼리 연결되어 있는지를 행과 열로 표현한 2차원 배열입니다.

행 u, 열 v의 값은 “정점 u에서 정점 v로 갈 수 있는가?”를 뜻합니다.
2

그래프를 행렬로 바꾸기

예제 간선

(1,2), (1,3), (2,4), (3,5), (4,5)

무방향 그래프에서는 (1,2)가 있으면 (2,1)도 함께 존재합니다.
3

간선 추가 시각화

간선을 선택하면 그래프의 간선과 행렬의 두 칸이 함께 강조됩니다.
4

무방향 그래프와 방향 그래프

양쪽 방향을 모두 저장

graph[u][v] = 1;
graph[v][u] = 1;
행렬이 주대각선을 기준으로 대칭입니다.

화살표 방향만 저장

graph[u][v] = 1;
u → v만 존재하고 v → u는 없을 수 있으므로 행렬이 대칭이 아닐 수 있습니다.
5

C언어 구현

무방향 그래프 입력
#include <stdio.h>

#define MAX 100

int graph[MAX + 1][MAX + 1];

int main(void)
{
    int n, m;
    int u, v;

    scanf("%d %d", &n, &m);

    for (int i = 0; i < m; i++)
    {
        scanf("%d %d", &u, &v);

        graph[u][v] = 1;
        graph[v][u] = 1;
    }

    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
            printf("%d ", graph[i][j]);

        printf("\n");
    }

    return 0;
}

코드 읽기

1. graph[MAX+1][MAX+1] 선언
2. 정점 수 n, 간선 수 m 입력
3. 간선 u, v를 반복 입력
4. 무방향이므로 양쪽 칸을 1로 저장
5. 이중 반복문으로 행렬 출력
가중치 그래프 저장
// 정점 u와 v를 비용 w로 연결
graph[u][v] = w;
graph[v][u] = w;
가중치 그래프에서는 1 대신 거리, 비용, 시간과 같은 값을 저장합니다.
6

인접행렬의 특징

항목특징
메모리정점 N개이면 O(N²)
간선 확인graph[u][v]를 바로 확인하므로 O(1)
모든 이웃 탐색한 행을 모두 확인하므로 O(N)
적합한 경우정점 수가 작거나 간선이 많은 그래프
단점간선이 적어도 N²개의 공간이 필요
