01

트리란 무엇인가

트리(Tree)는 노드(Node)들이 부모-자식 관계로 연결된, 사이클이 없는 계층 구조입니다. 컴퓨터의 폴더 구조, 회사 조직도, 토너먼트 대진표가 모두 트리의 예입니다. 자식이 최대 2개까지만 허용되는 트리를 특별히 이진 트리(Binary Tree)라고 부릅니다.

노드를 클릭하면 깊이(depth)·자식 수·부모 정보가 표시됩니다. 위 버튼으로 일반 트리와 이진 트리를 비교해보세요.
루트 Root
부모가 없는 맨 위의 노드. 트리는 하나의 루트에서 시작합니다.
부모 / 자식
직접 연결된 위/아래 노드 관계.
리프 Leaf
자식이 하나도 없는 노드. 단말 노드라고도 합니다.
형제 Sibling
같은 부모를 공유하는 노드들.
깊이 Depth
루트에서 해당 노드까지의 간선 수.
높이 Height
해당 노드에서 가장 먼 리프까지의 간선 수.
서브트리 Subtree
어떤 노드와 그 아래 자손들로만 이루어진 트리.
02

트리를 어떻게 저장할까

트리를 메모리에 저장하는 두 가지 방법을 같은 이진 트리로 비교해봅니다: 배열 기반과 연결 리스트(포인터) 기반. 배열에서는 노드 i의 왼쪽 자식이 2i+1, 오른쪽 자식이 2i+2 위치에 저장됩니다.

자식 찾기O(1) — 인덱스 계산 (2i+1, 2i+2)O(1) — left, right 포인터 바로 접근
