최솟값 스택 (Min Stack)

세영코딩연구소 · 정올 자료구조 심화 | push, pop, peek, getMin 모두 O(1)!

문제 정의
일반 스택의 push / pop / peek 기능에 더해,
현재 스택에 들어있는 원소 중 최솟값을 O(1)에 반환하는 getMin()을 지원하는 스택을 구현하라.

왜 어려울까? — 순진한 시도의 문제점

❌ 매번 전체 탐색? → O(n)
getMin() 호출 때마다 스택 전체를 뒤져서 최솟값을 찾으면 O(n)이야.
push/pop이 자주 일어나면 너무 느려!
스택: [5, 3, 8, 1, 6]
getMin() → 1~5 전부 탐색 → O(n) ❌
✅ 보조 스택으로 추적 → O(1)
메인 스택과 같이 최솟값을 추적하는
보조 min 스택을 관리하면 O(1)로 해결!
메인: [5, 3, 8, 1, 6]
min: [5, 3, 3, 1, 1]
getMin() → min.top() = 1 ✅

연산 복잡도 목표

연산목표의미
push(x) O(1)원소 삽입
pop() O(1)top 원소 제거
peek() O(1)top 원소 확인
getMin() O(1)현재 최솟값 반환

정올 출제 유형

  • 스택 연산 중 최솟값 실시간 추적
  • 슬라이딩 윈도우 최솟값 (덱 응용)
  • 구간 최솟값 쿼리 (세그먼트 트리 응용)
  • 히스토그램 최대 직사각형
  • 수열 최솟값 유지 문제

동작 예시 추적 — push(5,3,8,1,6) → pop() → getMin()

연산 메인 스택 (↑top) min 스택 (↑top) getMin() 설명
push(5)[5][5]5첫 원소 → 둘 다 5
push(3)[5, 3][5, 3]33 < 5 → min에도 push(3)
push(8)[5, 3, 8][5, 3, 3]38 > 현재min(3) → min에 3 다시
push(1)[5, 3, 8, 1][5, 3, 3, 1]11 < 3 → min에 push(1)
push(6)[5, 3, 8, 1, 6][5, 3, 3, 1, 1]16 > 1 → min에 1 다시
pop()[5, 3, 8, 1][5, 3, 3, 1]16 제거. min도 같이 pop(1→남은건 1)
pop()[5, 3, 8][5, 3, 3]31 제거. min의 1도 pop → 다음 min=3!
pop()의 핵심: 메인 스택과 min 스택을 항상 같이 pop해야 해. min 스택의 top이 항상 "현재 스택 상태에서의 최솟값"을 나타내거든!

구현 방법 3가지

보조 min 스택 · 차이값 저장 · 쌍 저장 — 장단점을 비교해봐!

방법 1 — 보조 min 스택
방법 2 — 쌍으로 저장
방법 3 — 차이값 저장
★ 정올 추천 방법! 두 번째 스택(min 스택)이 각 단계의 최솟값을 기억해.
메인 스택과 min 스택의 크기가 항상 같아서 코드가 직관적이야.

push(x) 로직

① 메인 스택에 x push
main[++mTop] = x
② min 스택에 push
if (x <= minTop의 값)
  min[++minTop] = x
else
  min[++minTop] = min[minTop-1]
pop() 로직
① 메인 스택 pop
② min 스택 pop (동시에!)
getMin() 로직
return min[minTop]
(min 스택 top이 항상 현재 최솟값)

장점

  • 코드가 직관적이고 이해하기 쉬움
  • 음수, 중복 값 모두 정확하게 처리
  • pop할 때 실수 없음
  • 정올 시험장에서 안전한 선택

단점

  • 메모리 2배 사용 (min 스택 추가)
  • push마다 min 스택도 갱신해야 함
구조체(struct)에 값과 최솟값을 쌍으로 저장하는 방법이야.
각 원소마다 그 시점의 최솟값을 함께 저장해서 getMin()이 O(1)이야.
method2_pair.c
typedef struct {
    int val;     // 실제 값
    int curMin;  // 이 원소가 push될 때의 스택 최솟값
} Node;

Node stk[MAX];
int top = -1;

void push(int x) {
    int newMin = (top == -1) ? x :
                 (x < stk[top].curMin ? x : stk[top].curMin);
    stk[++top] = (Node){x, newMin};
}

int getMin() { return stk[top].curMin; } // O(1)!
int pop()    { return stk[top--].val; }
int peek()   { return stk[top].val; }

장점

  • 스택 하나로 구현 (구조체 활용)
  • 코드 흐름이 단순함
  • C언어 struct 학습에 좋음

단점

  • 메모리 2배 (val + curMin 쌍)
  • C언어에서 구조체 문법 필요
차이값(diff)을 저장해서 메모리를 절약하는 고급 방법이야.
실제 값 대신 x - currentMin을 저장해서 min 변화를 추적해. 정올 고급 문제용이야.
method3_diff.c — 차이값 기법 (고급)
// 핵심: stk에 (x - 이전최솟값)을 저장
// min 변수 하나만 따로 관리
long long stk[MAX];  // 차이값 저장 (long long 필요!)
int top = -1;
int curMin;

void push(int x) {
    if (top == -1) { curMin = x; stk[++top] = 0; return; }
    long long diff = (long long)x - curMin; // 차이 저장
    stk[++top] = diff;
    if (x < curMin) curMin = x;              // min 갱신
}

int pop() {
    long long diff = stk[top--];
    int val;
    if (diff < 0) {                          // diff<0이면 이 원소가 그때 min이었음
        val = curMin;
        curMin -= diff;  // 이전 min 복원: curMin = curMin - diff = 이전min
    } else {
        val = curMin + diff;
    }
    return val;
}

int getMin() { return curMin; }
주의: 이 방법은 오버플로우 방지를 위해 long long이 필요하고, 복원 로직이 복잡해.
정올 시험장에서는 방법 1(보조 min 스택)을 쓰는 게 안전해!
