스택(Stack)이란?

세영코딩연구소 | 정올 준비 · 중급 · 자료구조 2단원

핵심 비유
프링글스 과자통을 떠올려봐. 먼저 넣은 과자는 맨 아래 있고, 마지막에 넣은 과자를 먼저 꺼내야 해.
이걸 LIFO — Last In, First Out (마지막에 들어온 것이 먼저 나간다) 라고 해.

스택이 쓰이는 곳

괄호 검사 함수 호출 스택 브라우저 뒤로가기 재귀 알고리즘 DFS 구현 식 계산기

정올에서는 괄호 검사, DFS, 모노토닉 스택 문제에 자주 등장해!

스택 연산 4가지

push(x)맨 위에 x를 넣는다
pop()맨 위 원소를 꺼낸다
peek()맨 위 원소를 확인만 한다
isEmpty()스택이 비었는지 확인

정올 시험에서는? 직접 배열로 구현하는 연습이 중요해. 나중에 변형 스택을 만들 때도 기본 구조를 알아야 하거든.
stack_array.c — 배열 기반 스택 
// 배열로 스택 직접 구현하기
#include <stdio.h>

#define MAX 1000        // 스택 최대 크기

int stack[MAX];       // 스택 배열
int top = -1;        // top: 마지막 원소의 인덱스 (-1이면 빈 스택)

// 원소 넣기
void push(int x) {
    if (top == MAX - 1) {   // 스택이 꽉 찼으면 오버플로우
        printf("Stack Overflow!\n");
        return;
    }
    stack[++top] = x;     // top을 먼저 올리고 값 저장
}

// 원소 꺼내기
int pop() {
    if (top == -1) {       // 빈 스택이면 언더플로우
        printf("Stack Underflow!\n");
        return -1;
    }
    return stack[top--];  // 값을 반환하고 top을 내림
}

// 맨 위 확인 (꺼내지 않음)
int peek() {
    if (top == -1) return -1;
    return stack[top];
}

// 비었는지 확인
int isEmpty() {
    return top == -1;
}

int main() {
    push(10); push(20); push(30);
    printf("peek: %d\n", peek()); // 30
    printf("pop: %d\n",  pop());  // 30
    printf("pop: %d\n",  pop());  // 20
    return 0;
}
STL stack은 이미 구현된 스택 라이브러리야. 빠르게 쓸 때 편리하고, C++ 코딩 테스트에서 많이 활용돼.
stack_stl.cpp — C++ STL stack 
#include <iostream>
#include <stack>        // STL stack 헤더
using namespace std;

int main() {
    stack<int> s;       // int형 스택 선언

    s.push(10);         // 넣기
    s.push(20);
    s.push(30);

    cout << s.top() << endl;    // 30  ← peek과 같음
    s.pop();                   // 30 제거 (반환값 없음!)
    cout << s.top() << endl;    // 20
    cout << s.size() << endl;   // 2
    cout << s.empty() << endl;  // 0 (false)

    return 0;
}
주의! STL pop()은 값을 반환하지 않아. 꺼낼 때는 top()으로 먼저 읽고 → pop()으로 제거해야 해.

top 포인터의 움직임

초기 상태   top = -1   [ _, _, _, _, _ ]
push(10)  top =  0   [10, _, _, _, _ ]
push(20)  top =  1   [ 10, 20, _, _, _ ]
push(30)  top =  2   [ 10, 20, 30, _, _ ]
pop() → 30  top =  1   [ 10, 20, 30, _, _ ] ← 30은 덮어쓰기 대기
peek() → 20  top =  1   변화 없음
핵심: 실제로 배열에서 값을 지우지 않아! top 포인터만 옮겨서 "없는 것처럼" 처리하는 거야. 다음 push 때 덮어쓰면 돼.
