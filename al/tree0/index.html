브론즈 트리 문제

기초 개념 확립 · 배열 표현 · 3가지 순회

📐 배열로 이진 트리 표현하기

완전 이진 트리가 아니더라도 노드 수가 적을 때는 배열만으로 쉽게 자식을 참조할 수 있습니다.

부모 노드 인덱스
i
왼쪽 자식
2 × i
오른쪽 자식
2 × i + 1
부모 노드
i / 2
C++ 예시 
// 1차원 배열로 트리 표현 (1-based index)
int tree[MAX];

// 노드 i의 부모/자식 접근
int parent = i / 2;
int left_child = 2 * i;
int right_child = 2 * i + 1;

// 주의: 완전 이진 트리가 아닐 때는 
//       유효한 인덱스 범위 체크 필요!

🔄 재귀 함수를 이용한 3가지 순회

전위 (Preorder)
Root → Left → Right
루트를 먼저 방문
중위 (Inorder)
Left → Root → Right
BST에서 정렬된 순서
후위 (Postorder)
Left → Right → Root
서브트리 크기 계산에 필수
💡 브론즈 꿀팁
  • 노드 수가 적을 때(약 1000개 이하)는 배열 표현이 가장 간단합니다
  • 순회 방식은 문제의 "방문 시점"을 기준으로 선택하세요
  • 전위: 복사/출력, 중위: BST 성질, 후위: 서브트리 결과 합산

실버 트리 문제

그래프 탐색 · 인접 리스트 · 트리 특성 활용

🚫 절대 쓰지 마세요: 인접 행렬

❌ 인접 행렬
int adj[N][N]
메모리 O(N²) → 초과!
✅ 인접 리스트
vector<int> adj[N]
메모리 O(N) → 안전!

실버급 문제는 N이 10,000~100,000개입니다. 간선은 항상 N-1개이므로 인접 리스트가 필수입니다.

🔍 DFS 패턴: 부모만 체크하면 visited 불필요

C++ 예시 
void dfs(int current, int parent) {
    for (int next : adj[current]) {
        if (next != parent) {  // ⭐ 핵심: 부모만 제외
            parent_array[next] = current;
            dfs(next, current);
        }
    }
}

// BFS 버전도 동일한 원리
void bfs(int start) {
    queue<int> q;
    q.push(start);
    while (!q.empty()) {
        int cur = q.front(); q.pop();
        for (int next : adj[cur]) {
            if (next != parent_array[cur]) {
                parent_array[next] = cur;
                q.push(next);
            }
        }
    }
}

📋 자주 나오는 실버 유형 체크리스트

⚠️ 주의사항
  • 편향 트리가 될 수 있으므로 Python은 sys.setrecursionlimit(10**6) 필수
  • C/C++에서는 재귀 깊이가 클 때 BFS(큐)로 전환하세요
  • 트리는 사이클이 없으므로 parent만 제외하면 visited 배열 불필요

골드 트리 문제

Tree DP · LCA · 오일러 경로 · 오프라인 쿼리

🧮 Tree DP 핵심 패턴

골드의 절반 이상은 DP와 결합됩니다. dp[node][state] 형태로 정의하고 Postorder(Bottom-up)로 계산합니다.

C++ 예시 - 트리의 독립집합 
// dp[node][0]: 미선택, dp[node][1]: 선택
void solve_dp(int cur, int parent) {
    dp[cur][0] = 0;
    dp[cur][1] = weight[cur];

    for (int next : adj[cur]) {
        if (next == parent) continue;
        solve_dp(next, cur);  // 자식 먼저!

        dp[cur][0] += max(dp[next][0], dp[next][1]);
        dp[cur][1] += dp[next][0];  // 내가 뽑히면 자식은 X
    }
}

🔝 LCA (최소 공통 조상) - 희소 배열

❌ O(N) LCA
매 쿼리마다 부모를 한 칸씩 올라가면 시간 초과
✅ O(log N) 희소 배열
parent[k][node] = node의 2^k번째 부모로 점프
dist(u, v) = depth[u] + depth[v] - 2 × depth[lca(u, v)]

📊 알고리즘 선택 가이드

문제 유형 핵심 기법 복잡도
정점 선택/미선택 최적화 Tree DP O(N)
두 노드 간 경로/공통 조상 LCA + Sparse Table O(log N)
서브트리 구간 합/갱신 Euler Tour + Segment Tree O(log N)
트리의 최장 거리 트리의 지름 (DFS 2회) O(N)
간선 파괴/동적 연결성 Offline Query + Union-Find O(α(N))
🎯 골드 핵심 전략
  • 오일러 경로: in[node] ~ out[node]가 서브트리의 연속 구간 → 세그먼트 트리로 구간 처리
  • 오프라인 쿼리: 쿼리를 거꾸로(역순) 처리하면 간선 "제거"를 "추가"로 변환
  • 트리의 지름은 임의 노드 A에서 가장 먼 B, B에서 가장 먼 C로 구성됨

플래티넘 트리 문제

Centroid Decomposition · HLD · Small to Large · CHT

1

Centroid Decomposition (점분할)

"모든 정점 쌍의 경로"를 O(N²)에서 O(N log N)으로 줄이는 분할 정복. 센트로이드를 찾아 해당 정점을 지나는 경로를 계산 후 재귀 분할.

💡 적용: 정점 간 거리가 K 이하인 쌍의 개수, 경로 조건 카운팅
2

Heavy-Light Decomposition (HLD)

Heavy Edge와 Light Edge로 분할하여 트리 경로를 최대 O(log N)개의 연속 구간으로 변환. 세그먼트 트리와 결합하여 경로 쿼리를 O(log² N)에 처리.

💡 적용: 경로 상 구간 갱신/구간 합/최댓값 쿼리
3

Small to Large (dsu on tree)

서브트리 정보를 합칠 때 작은 쪽을 큰 쪽(Heavy)으로 옮기는 방식. O(N²)를 O(N log N)으로 단축. Map/Set 병합 시 필수 테크닉.

💡 적용: 서브트리 내 서로 다른 색깔 개수, 집합 정보 통합
4

Tree DP + Convex Hull Trick (CHT)

점화식이 dp[i] = min(dp[j] + A[i]·B[j]) 꼴일 때 1차 함수 최적화. 트리에서는 Li Chao Tree나 상태 복원(Rollback)이 필요.

💡 적용: 기울기가 단조가 아닌 트리 DP 최적화
5

Parallel Binary Search + 트리

수만 개 쿼리의 이분 탐색을 동시에 진행. 조건이 모노톤하고 오프라인 처리 가능할 때, Fenwick/세그먼트 트리와 결합.

💡 적용: 여러 쿼리의 최댓값/최소값 이분 탐색
🧠 플래티넘 마인드셋
  • "모든 경로"를 다뤄야 한다면 → Centroid Decomposition을 먼저 떠올리자
  • "경로상 구간" 쿼리가 들어오면 → HLD + Segment Tree가 정답일 가능성이 높음
  • "서브트리 집합"을 합쳐야 하면 → Small to Large가 거의 정석
  • 트리 DP에서 1차 함수 꼴이 보이면 → Li Chao Tree를 고려하자
