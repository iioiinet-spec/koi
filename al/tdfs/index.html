트리 DFS를 코드와 함께 이해하기

깊이 우선 탐색(DFS)이 실제로 트리를 어떻게 내려가고 되돌아오는지, 트리·방문 순서·재귀 호출 스택·C 코드를 동시에 보면서 이해하는 강의자료입니다.

1. DFS란?

DFS(Depth First Search, 깊이 우선 탐색)는 한 방향으로 갈 수 있는 곳까지 깊게 내려간 뒤, 더 이상 갈 곳이 없으면 이전 노드로 되돌아와 다른 길을 탐색하는 방법입니다.

① 현재 노드 방문노드에 도착하면 먼저 방문 처리합니다.
② 자식으로 깊게 이동왼쪽 자식부터 가능한 곳까지 계속 내려갑니다.
③ 막히면 되돌아오기자식이 없으면 부모로 돌아와 다음 자식을 탐색합니다.
쉽게 기억: DFS는 “한 길을 끝까지 가 본 다음, 돌아와서 다른 길을 간다.”

2. 트리에서 DFS 실행

방문 전 방문 완료 현재 방문 되돌아오는 중
DFS 방문 순서:
루트 A에서 DFS를 시작합니다. A를 방문한 뒤 왼쪽 자식 B로 내려갑니다.

3. C 코드와 호출 스택

아래 코드는 재귀 함수를 이용한 가장 기본적인 트리 DFS입니다.

void dfs(Node *root) { if (root == NULL) return; printf("%c ", root->data); dfs(root->left); dfs(root->right); }

현재 재귀 호출 스택

아직 호출된 함수가 없습니다.
중요: 함수가 자식으로 내려갈 때마다 호출 스택에 새로운 함수가 쌓이고, 자식 탐색이 끝나면 그 함수가 빠지면서 부모 함수로 돌아옵니다.

4. DFS의 실제 진행 흐름

1. A 방문
2. B로 이동
3. D까지 깊게 이동
4. D에서 되돌아옴
5. E 방문
6. A까지 복귀
7. C → F → G
8. 탐색 종료
단계현재 노드설명
1A루트 방문
2BA의 왼쪽 자식으로 이동
3DB의 왼쪽 끝까지 이동
4ED에서 돌아와 B의 오른쪽 자식 방문
5CB의 탐색 종료 후 A의 오른쪽으로 이동
6FC의 왼쪽 자식 방문
7GC의 오른쪽 자식 방문

5. DFS와 전위 순회의 관계

현재 코드처럼 printf()를 자식 호출보다 먼저 실행하면 DFS 방문 순서는 전위 순회와 같습니다.

결과: A → B → D → E → C → F → G

즉, 트리에서 DFS는 “어떤 시점에 노드를 처리하느냐”에 따라 전위·중위·후위 순회와 연결해서 이해할 수 있습니다.
