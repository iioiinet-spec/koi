완전이진트리를 배열에 저장하기

루트 노드를 1번 인덱스에 저장하면 부모와 자식의 위치를 계산할 수 있습니다.

부모
i / 2
왼쪽 자식
i * 2
오른쪽 자식
i * 2 + 1
예를 들어 B가 2번 인덱스라면 왼쪽 자식은 4번 D, 오른쪽 자식은 5번 E입니다.
index 1A
index 2B
index 3C
index 4D
index 5E
index 6F
index 7G
C언어 기본 코드
#include <stdio.h>

char tree[100];

int main(void)
{
    tree[1] = 'A';
    tree[2] = 'B';
    tree[3] = 'C';
    tree[4] = 'D';
    tree[5] = 'E';
    tree[6] = 'F';
    tree[7] = 'G';

    int i = 2;  // B의 인덱스

    printf("현재 노드: %c\n", tree[i]);
    printf("부모: %c\n", tree[i / 2]);
    printf("왼쪽 자식: %c\n", tree[i * 2]);
    printf("오른쪽 자식: %c\n", tree[i * 2 + 1]);

    return 0;
}

인덱스 관계 탐색기

인덱스를 입력하고 버튼을 누르면 부모와 자식 위치가 강조됩니다.

2를 입력하면 B의 부모 A, 왼쪽 자식 D, 오른쪽 자식 E를 확인할 수 있습니다.

각 노드의 부모 번호만 저장합니다.

parent[4] = 2;
4번 노드의 부모는 2번

LCA, 조상 찾기, 깊이 계산 문제에서 자주 사용합니다.

구조체 배열 C 코드
#include <stdio.h>

typedef struct
{
    char data;  // 노드에 저장할 값
    int left;   // 왼쪽 자식의 배열 번호
    int right;  // 오른쪽 자식의 배열 번호
} Node;

Node tree[100];

void preorder(int now)
{
    if (now == -1)
        return;

    printf("%c ", tree[now].data);
    preorder(tree[now].left);
    preorder(tree[now].right);
}

int main(void)
{
    tree[0] = (Node){'A', 1, 2};
    tree[1] = (Node){'B', 3, -1};
    tree[2] = (Node){'C', -1, -1};
    tree[3] = (Node){'D', -1, -1};

    preorder(0);

    return 0;
}
