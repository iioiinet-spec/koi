연결 리스트(Linked List)란?

세영코딩연구소 | 정올 준비 · 자료구조 4단원

핵심 아이디어
데이터를 메모리에 연속으로 저장하는 배열과 달리, 연결 리스트는 각 데이터가 다음 데이터의 주소(포인터)를 함께 들고 있어.
마치 보물찾기처럼 — 현재 노드가 다음 노드의 위치를 알려줘!

각 노드(Node)는 두 칸으로 구성돼:
■ data — 실제 저장값    ■ next — 다음 노드를 가리키는 포인터 (마지막은 NULL)

배열 vs 연결 리스트

배열연결 리스트
저장 방식연속 메모리포인터로 연결
접근 속도O(1) 빠름O(n) 느림
삽입·삭제O(n) 느림O(1) 빠름*
크기 변경고정 (정적)유연 (동적)
메모리효율적포인터 추가

* 삽입·삭제 위치를 이미 알고 있을 때

연결 리스트 종류

단순 연결 리스트 (Singly)
next 포인터만 → 한 방향으로만 이동
이중 연결 리스트 (Doubly)
prev + next 포인터 → 양방향 이동
원형 연결 리스트 (Circular)
마지막 노드의 next가 head를 가리킴

C에서 구현하는 방법 — 두 가지

방법개념장점단점정올 추천
포인터 방식 malloc으로 노드 동적 생성 교과서적, 진짜 연결리스트 포인터 개념 필요 중학교 심화
배열 시뮬레이션 배열로 data[], next[] 흉내 포인터 없이 구현 가능 크기 미리 정해야 함 ★ 정올 핵심
정올 시험 팁! 실제 정올에서는 배열 시뮬레이션 방식이 훨씬 실용적이야. 포인터 개념 없이도 연결 리스트의 삽입·삭제를 구현할 수 있어서 실수도 적어. 두 방법 모두 배워두되 시험장에서는 배열 시뮬이 안전해!

단순 연결 리스트 (Singly Linked List)
