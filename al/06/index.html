두 개의 스택

세영코딩연구소 · 정올 자료구조 심화 | 스택 2개를 활용하는 핵심 기법 2가지

왜 두 개의 스택을 배워야 할까?
스택 하나로 해결할 수 없는 문제들을 두 개를 조합하면 풀 수 있어.
정올·코딩 테스트에서 자주 나오는 두 가지 핵심 기법을 배워보자!

기법 ① — 하나의 배열에 두 스택

배열 하나를 왼쪽·오른쪽으로 나눠 두 스택이 서로 반대 방향으로 성장해.
공간을 최대로 효율적으로 쓸 수 있어!

[A→ A→ A→       ←B ←B]
Stack A: 인덱스 0에서 오른쪽으로
Stack B: 인덱스 MAX-1에서 왼쪽으로

기법 ② — 두 스택으로 큐 구현

스택 2개를 조합해서 큐(FIFO)를 만들어.
각 연산의 분할 상환 복잡도가 O(1)이야!

inbox 스택: enqueue 시 push
outbox 스택: dequeue 시 pop
outbox 비면 → inbox 전부 이동!

두 기법 한눈에 비교

하나의 배열에 두 스택두 스택으로 큐 구현
목적공간 효율 극대화큐 기능을 스택으로 흉내
자료구조배열 1개를 공유스택 2개 (inbox + outbox)
push/enqueueO(1)O(1)
pop/dequeueO(1)분할상환 O(1)
오버플로우 조건top1 + 1 == top2inbox가 가득 찰 때
정올 출제중급실버~골드
분할 상환(Amortized) O(1)이란?
두 스택으로 큐를 구현할 때, 개별 dequeue는 O(n)이 걸릴 수 있어 (inbox → outbox 이동).
하지만 n번의 연산 총합은 O(n)이야. 평균하면 각 연산이 O(1)이란 뜻!
각 원소는 inbox push 1번 → outbox push 1번 → outbox pop 1번 = 최대 3번만 처리돼.
