트리 순회 쉽게 이해하기

전위(Preorder), 중위(Inorder), 후위(Postorder)를 같은 트리에서 직접 실행하며 순서를 확인하는 인터랙티브 강의자료입니다.

1. 트리 순회란?

트리 순회(Tree Traversal)는 트리의 모든 노드를 어떤 규칙에 따라 한 번씩 방문하는 방법입니다. 핵심은 부모 노드를 언제 방문하느냐입니다.

전위 순회부모 → 왼쪽 → 오른쪽
부모를 가장 먼저 방문합니다.
중위 순회왼쪽 → 부모 → 오른쪽
부모를 가운데에서 방문합니다.
후위 순회왼쪽 → 오른쪽 → 부모
부모를 가장 마지막에 방문합니다.
기억법: “전·중·후”는 부모(루트)가 앞/중간/뒤 중 어디에 오는지만 보면 됩니다.

2. 순회 시각화

방문 전 방문 완료 현재 방문
현재 방식: 전위 순회
방문 순서:
전위 순회는 부모 노드 A부터 방문합니다.

3. C 재귀 코드와 실행 위치

세 순회는 코드가 거의 같습니다. printf의 위치만 달라지는 것이 핵심입니다.

전위 순회

void preorder(Node *root) { if (root == NULL) return; printf("%c ", root->data); preorder(root->left); preorder(root->right); }

중위 순회

void inorder(Node *root) { if (root == NULL) return; inorder(root->left); printf("%c ", root->data); inorder(root->right); }

후위 순회

void postorder(Node *root) { if (root == NULL) return; postorder(root->left); postorder(root->right); printf("%c ", root->data); }
포인트: 전위는 printf가 재귀호출보다 앞, 중위는 가운데, 후위는 뒤에 있습니다.

4. 같은 트리의 결과 비교

순회규칙방문 결과
전위부모 → 왼쪽 → 오른쪽A B D E C F G
중위왼쪽 → 부모 → 오른쪽D B E A F C G
후위왼쪽 → 오른쪽 → 부모D E B F G C A
