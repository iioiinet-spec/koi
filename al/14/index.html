핵심 아이디어

가중치에 따라 BFS / 0-1 BFS / Dijkstra를 선택해!

세 가지 방법 비교

방법자료구조가중치복잡도정올 난이도
BFS큐(Queue)모두 동일O(N×M)실버
0-1 BFS덱(Deque)0 또는 1만O(N×M)골드
Dijkstra우선순위 큐임의 양수O(NMlogNM)골드

4방향 이동 벡터

4방향 벡터
int dr[] = {-1, 1,  0, 0};
int dc[] = { 0, 0, -1, 1};
// 상, 하, 좌, 우

범위 + 방문 체크

체크 패턴
int nr = r + dr[d];
int nc = c + dc[d];
if(nr<0||nr>=N) continue;
if(nc<0||nc>=M) continue;
if(grid[nr][nc]=='#') continue;
if(dist[nr][nc]!=-1) continue;

어떤 방법을 선택할까?

BFS — 모든 이동 비용이 같을 때
예: 미로 탈출, 이동 횟수 최소화, 섬 개수
0-1 BFS — 이동 비용이 0 또는 1만 있을 때
예: 문 통과 비용, 특정 조건 무료 이동
Dijkstra — 이동 비용이 임의 양수일 때
예: 지형 이동비용, 가중치 격자, 환승 비용
