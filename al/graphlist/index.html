인접리스트는 각 정점에 연결된 이웃 정점만 연결 리스트로 저장합니다.

간선이 적은 희소 그래프에서는 인접행렬보다 메모리를 훨씬 적게 사용합니다.
2

배열과 연결 리스트의 결합

배열의 역할

adj[1], adj[2]처럼 각 정점의 연결 리스트 시작 주소를 저장합니다.

Node *adj[MAX + 1];

연결 리스트 노드의 역할

이웃 정점 번호와 다음 노드의 주소를 저장합니다.

typedef struct Node
{
    int vertex;
    struct Node *next;
} Node;
3

간선 추가 시각화

간선을 선택하면 그래프와 두 정점의 인접리스트가 함께 강조됩니다.
4

무방향 그래프와 방향 그래프

양쪽 리스트에 모두 추가

addEdge(u, v);
addEdge(v, u);
간선 1-2는 1의 리스트에 2를, 2의 리스트에 1을 넣습니다.

출발 정점 리스트에만 추가

addEdge(u, v);
간선 1→2라면 1의 리스트에만 2를 저장합니다.

C언어 구현

전체 저장 코드
#include <stdio.h>
#include <stdlib.h>

#define MAX 100

typedef struct Node
{
    int vertex;
    struct Node *next;
} Node;

Node *adj[MAX + 1];

Node *createNode(int vertex)
{
    Node *newNode;

    newNode = (Node *)malloc(sizeof(Node));

    if (newNode == NULL)
    {
        printf("메모리 할당 실패\n");
        exit(1);
    }

    newNode->vertex = vertex;
    newNode->next = NULL;

    return newNode;
}

void addEdge(int from, int to)
{
    Node *newNode = createNode(to);

    newNode->next = adj[from];
    adj[from] = newNode;
}

int main(void)
{
    int n, m;
    int u, v;

    scanf("%d %d", &n, &m);

    for (int i = 0; i < m; i++)
    {
        scanf("%d %d", &u, &v);

        addEdge(u, v);
        addEdge(v, u);
    }

    for (int i = 1; i <= n; i++)
    {
        Node *current = adj[i];

        printf("%d: ", i);

        while (current != NULL)
        {
            printf("%d ", current->vertex);
            current = current->next;
        }

        printf("\n");
    }

    return 0;
}

코드 실행 흐름

1. 정점마다 시작 포인터 배열 선언
2. 새 연결 리스트 노드 생성
3. 새 노드가 기존 첫 노드를 가리킴
4. adj[from]이 새 노드를 가리킴
5. 무방향이면 반대 방향도 추가
