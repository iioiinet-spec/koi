큐(Queue)란?

세영코딩연구소 | 정올 준비 · 자료구조 3단원

핵심 비유 — 은행 번호표 줄
먼저 온 사람이 먼저 서비스를 받아. 나중에 온 사람은 줄의 맨 뒤에 서야 해.
이걸 FIFO — First In, First Out (먼저 들어온 것이 먼저 나간다) 라고 해.

큐가 비어 있어. enqueue로 원소를 추가해봐!

rear = -1
size = 0

실행 로그

배열 큐의 문제점 — 앞 공간 낭비
dequeue를 하면 front 인덱스가 앞으로 이동해. 하지만 앞의 빈 공간은 다시 사용하지 못해.
이걸 해결한 것이 원형 큐(Circular Queue)야! 🔄 탭을 눌러서 확인해봐.

원형 큐 (Circular Queue)

배열의 끝에서 다시 처음으로 이어지는 구조 — 앞 공간 낭비 문제 해결!

핵심 아이디어
rear가 배열 끝(MAX-1)에 도달하면, 다음 위치는 0으로 돌아가. rear = (rear + 1) % MAX
나머지 연산(%)으로 인덱스를 원형으로 순환시켜!
원형 큐 시각화 (크기=8)
front = 0
rear = 7
size = 0
로그
▶ enqueue로 시작!

원형 큐 핵심 공식

circular_queue_formula.c
// 원형 큐의 핵심: 나머지 연산으로 인덱스 순환

// enqueue: rear를 한 칸 앞으로 (원형으로)
rear = (rear + 1) % MAX;
queue[rear] = x;

// dequeue: front를 한 칸 앞으로 (원형으로)
int val = queue[front];
front = (front + 1) % MAX;

// isEmpty: front와 rear가 같은 위치에 오면 빈 큐
// (단, 공간 하나를 비워두는 방식 사용)
int isEmpty() { return front == rear; }
int isFull()  { return (rear + 1) % MAX == front; }

// size 계산
int size() { return (rear - front + MAX) % MAX; }
왜 공간 하나를 비워두나?
원형 큐에서 front == rear이면 빈 큐야. 그런데 꽉 찬 큐도 front == rear가 될 수 있어서 구별이 안 돼. 그래서 한 칸을 비워두고, (rear+1)%MAX == front이면 꽉 찬 것으로 판단해!
