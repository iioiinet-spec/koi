스택으로 구현하는 DFS

세영코딩연구소 · 그래프 탐색 | 깊이 우선 탐색 (Depth-First Search)

DFS란?
그래프에서 한 방향으로 끝까지 파고들다가, 더 이상 갈 곳이 없으면 되돌아와서 다른 길을 탐색하는 방법이야. 미로를 탐험할 때 한쪽 벽을 따라 끝까지 가다가 막히면 돌아오는 것과 같아!

DFS 핵심 성질

  • 깊이 우선: 이웃 중 하나를 골라 끝까지
  • 방문 체크: visited[] 배열로 중복 방지
  • LIFO: 스택으로 자연스럽게 구현
  • O(V+E): 정점+간선 수에 비례

왜 스택이 DFS와 맞을까?

재귀 함수는 내부적으로 콜 스택을 사용해.
스택 DFS는 이걸 직접 명시적으로 구현하는 것이야!

push 시작 노드
while 스택 비지 않음:
  pop → 방문 처리
  이웃 → push (미방문)

DFS 동작 3단계

①
시작 노드를 스택에 push
visited를 초기화하고 시작 노드를 스택에 넣는다.
②
스택에서 pop → 방문 처리
꺼낸 노드가 이미 방문됐으면 skip. 새 노드면 방문 표시 후 이웃을 탐색.
③
미방문 이웃을 스택에 push → ②반복
스택이 빌 때까지 ②③을 반복. 스택이 비면 DFS 종료.
정올에서 DFS가 쓰이는 문제 유형
연결 요소(Connected Components) 개수 세기 · 사이클 탐지 · 위상 정렬 · 경로 존재 여부 · 미로 탈출 가능 여부 · 트리 순회 · 백트래킹 기반 문제

재귀 DFS vs 스택 DFS

두 방법은 같은 알고리즘이지만 구현 방식과 방문 순서가 조금 달라!

⚠️ 중요한 차이!
재귀 DFS는 이웃을 번호 순서대로 방문하지만,
스택 DFS는 이웃을 역순으로 push하지 않으면 방문 순서가 달라져.
두 방법의 방문 순서를 맞추려면 스택 DFS에서 이웃을 역순으로 push해야 해!
🔁 재귀 DFS
dfs_recursive.c
int visited[MAX];
int adj[MAX][MAX]; // 인접행렬

void dfs(int v) {
    visited[v] = 1;
    printf("%d ", v);
    for (int w=1; w<=n; w++) {
        if (adj[v][w] &&
            !visited[w])
            dfs(w); // 재귀 호출
    }
}

// 시작: dfs(1);
장점: 코드 짧고 직관적
단점: 스택 깊이 제한 (스택 오버플로우 위험)
📚 스택 DFS
dfs_stack.c
int visited[MAX];
int stk[MAX], top=-1;

void dfs_stack(int start) {
    stk[++top] = start;
    while (top != -1) {
        int v = stk[top--];
        if (visited[v]) continue;
        visited[v] = 1;
        printf("%d ", v);
        for (int w=n; w>=1; w--)
            if (adj[v][w] &&
                !visited[w])
                stk[++top] = w;
    }
}
장점: 스택 오버플로우 없음, 반복문
단점: 코드 약간 길고, 순서 주의

방문 순서 맞추기 — 역순 push

그래프: 1-2, 1-3, 2-4, 2-5 / 시작: 1

방법1 방문 후다음 방문전체 순서
재귀 DFS 이웃 2,3 순서대로 2 먼저 1→2→4→5→3
스택 DFS (역순 push) 3,2 역순으로 push top=2 먼저 pop 1→2→4→5→3
스택 DFS (정순 push) 2,3 순서로 push top=3 먼저 pop 1→3→2→5→4
결론: 정올에서 방문 순서가 중요한 문제라면 이웃을 역순으로 push해야 재귀와 같은 순서가 나와.
연결 여부만 확인하는 문제라면 순서는 중요하지 않아!
