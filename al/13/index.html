원형 큐 (Circular Queue)

세영코딩연구소 · 정올 자료구조 | 배열 끝에서 처음으로 이어지는 큐!

선형 큐의 문제 → 원형 큐로 해결!
선형 큐는 dequeue 후 앞 공간이 낭비돼. rear가 MAX-1에 닿으면 앞에 빈 공간이 있어도 더 넣을 수 없어!
원형 큐는 나머지 연산(%)으로 인덱스를 순환시켜 앞 공간을 재활용해.

순환

원형 큐의 핵심 공식

enqueue: rear = (rear + 1) % MAX
dequeue: front = (front + 1) % MAX
isFull: (rear + 1) % MAX == front
isEmpty: front == rear
size: (rear - front + MAX) % MAX

front·rear 포인터 역할

포인터초기값가리키는 곳
front0첫 원소 바로 앞 슬롯
(항상 비워두는 센티널)
rear0마지막으로 넣은 슬롯
(실제 데이터 위치)
왜 front를 비워두나?
front==rear이면 빈 큐. (rear+1)%MAX==front이면 꽉 찬 큐.
구별을 위해 한 칸을 희생! MAX개 배열 → MAX-1개 저장 가능.

손 추적 연습

MAX=6, 연산 순서를 따라가며 front·rear가 어떻게 변하는지 직접 확인해봐!

추적 방법: 각 연산마다 ① rear=(rear+1)%MAX 또는 front=(front+1)%MAX 계산, ② 배열 상태, ③ front·rear 값을 표에 채워봐!
isEmpty / isFull 체크 연습
front=3, rear=3, MAX=6 → isEmpty! (front==rear)
front=2, rear=1, MAX=6 → isFull! ((1+1)%6=2 == front=2)
front=0, rear=3, MAX=6 → size = (3-0+6)%6 = 3 (원소 3개)
