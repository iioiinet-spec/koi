비트마스킹 DFS,
정수 하나로 방문 상태를 다루는 법

배열 대신 정수 하나의 비트로 "방문 여부"를 표현하면 어떤 일이 벌어질까요? 정점 4개짜리 작은 그래프에서 "모든 정점을 한 번씩 방문하는 경로의 수"를 세는 예제로, 비트 연산이 코드와 그래프 위에서 실시간으로 움직이는 것을 확인합니다.

01

비트마스킹 DFS란 무엇인가

지금까지의 DFS에서는 visited[MAX] 같은 배열로 방문 여부를 기록했습니다. 정점 개수가 20개 이하로 적을 때는, 배열 대신 정수 하나의 각 비트로 방문 여부를 표현할 수 있습니다 — 이것이 비트마스킹입니다.

비트 하나 = 정점 하나

정수의 0번째 비트는 정점 0, 1번째 비트는 정점 1... 이런 식으로 대응시킵니다. 정점 4개면 0000~1111(0~15) 사이의 정수 하나로 모든 방문 상태를 표현할 수 있습니다.

핵심 인사이트 — 백트래킹이 "저절로" 된다

배열은 재귀 호출 후 visited[next]=0으로 직접 되돌려야 했습니다. 하지만 비트마스크는 값으로 전달되므로, 각 재귀 호출이 독립된 복사본을 가져 되돌리는 코드 자체가 필요 없습니다.

세 가지 비트 연산만 알면 충분합니다.

1 << i
i번째 비트만 켜진 값을 만듭니다. 예: 1<<2 = 0100
mask | (1<<i)
i번째 비트를 켭니다 (정점 i를 "방문함"으로 표시).
mask & (1<<i)
i번째 비트가 켜져 있는지 확인합니다 (0이면 아직 방문 안 함).

예를 들어 정점 0과 2를 방문했다면 마스크는 0101(십진수 5)입니다.

02

예제 그래프 살펴보기 — 해밀턴 경로 세기

정점 4개가 모두 서로 연결된 완전 그래프(K4)입니다. 문제: 정점 0에서 시작해서 모든 정점을 정확히 한 번씩 방문하는 경로(해밀턴 경로)는 몇 개일까요? 정점을 클릭해 연결 관계를 확인하고, 직접 예측해보세요.

정점을 클릭하면 연결된 이웃이 표시됩니다. (힌트: 모든 정점이 서로 연결되어 있습니다)

04

실시간 시각화 — 코드와 비트마스크가 함께 움직인다

재생 버튼을 누르면 dfs()가 한 줄씩 실행되며, 그래프의 방문 정점, 오른쪽의 비트마스크(2진수)와 호출 스택이 실시간으로 바뀝니다. 재귀에서 돌아올 때 비트가 저절로 원래대로 보이는 것을 확인해보세요 — 되돌리는 코드가 없는데도 그렇습니다.

05

정리 & 퀴즈

비트마스킹은 "정점 개수가 적을 때 상태를 압축해서 표현한다"는 원리 하나로 다양한 고급 문제에 쓰입니다.

외판원 순회 (TSP)
DP + 비트마스크로 "현재까지 방문한 도시 집합"을 상태로 사용해 최단 경로를 구합니다.
부분집합 열거
N개 원소의 모든 부분집합(2^N개)을 정수 하나로 표현하고 순회할 수 있습니다.
해밀턴 경로/사이클
모든 정점을 한 번씩 방문하는 경로나 사이클의 존재 여부·개수를 구합니다.
조합 최적화
선택 가능한 조합이 많지 않을 때, 완전 탐색을 비트마스크로 빠르고 간결하게 구현합니다.
