다항식(Polynomial)이란?

다항식은 문자 x의 거듭제곱에 숫자를 곱한 항(term)들을 더해 놓은 식입니다. 일반적인 모양은 다음과 같습니다.

P(x) = anxn + an-1xn-1 + ··· + a1x + a0

용어 3가지만 기억하세요

용어뜻P(x) = 2x² + 3x + 1 에서
항 (term)덧셈으로 연결된 각 조각2x² , 3x , 1
계수 (coefficient)각 항에서 x 앞에 곱해진 수2 , 3 , 1
차수 (degree)x가 곱해진 횟수 중 가장 큰 것2 (최고차항이 x²)

컴퓨터는 다항식을 어떻게 저장할까?

핵심 아이디어는 딱 하나입니다. 배열의 인덱스(index)를 차수로, 배열의 값을 계수로 쓰는 것입니다. 즉 a[i]는 xi의 계수입니다.

💡
a[i] = xi의 계수. 이 약속 하나면 다항식 전체를 배열 하나로 표현할 수 있고, 사칙연산은 전부 "배열 계산"이 됩니다.

배열 길이 − 1 = 다항식의 차수. 중간에 없는 항(예: x항이 없는 x²+5)은 계수를 0으로 채웁니다 → [5, 0, 1]

C와 파이썬으로 선언하고, 값을 계산해 보기

다항식을 배열로 만들고, x = 2를 대입한 값 P(2) = 2·4 + 3·2 + 1 = 15를 계산해 봅니다.

C poly.c
#include <stdio.h>

int main(void) {
    /* 2x^2 + 3x + 1 : 인덱스 = 차수 */
    int A[] = {1, 3, 2};
    int d = 2;          /* 차수 */
    int x = 2;

    /* P(x) 값 계산: a[i] * x^i 를 모두 더한다 */
    int val = 0, pw = 1;   /* pw = x^i */
    for (int i = 0; i <= d; i++) {
        val += A[i] * pw;
        pw  *= x;
    }
    printf("P(2) = %d\n", val);
    return 0;
}
실행 결과P(2) = 15

왜 낮은 차수를 앞(인덱스 0)에 둘까? "인덱스 = 차수"가 되어 곱셈 공식 c[i+j] += a[i]*b[j]가 그대로 성립하기 때문입니다. 높은 차수를 앞에 두면 항마다 차수를 따로 계산해야 해서 코드가 복잡해집니다.

덧셈 · 뺄셈의 원리 — 같은 차수끼리!

수학 시간에 배운 그대로입니다. 같은 차수의 항끼리(=동류항끼리) 계수를 더하거나 뺍니다. 배열로 말하면 같은 인덱스끼리 더하고 빼면 끝입니다.

c[i] = a[i] + b[i]   (뺄셈은 a[i] − b[i])

A(x) = 2x² + 3x + 1,   B(x) = x + 2 를 더하면?

x² 자리 (i=2)x 자리 (i=1)상수 자리 (i=0)
A231
B0 (없으면 0)12
A + B243

⟶ A + B = 2x² + 4x + 3 = [3, 4, 2]  ·  A − B = 2x² + 2x − 1 = [-1, 2, 2]

💡
두 다항식의 길이가 다르면 짧은 쪽에 없는 항은 계수 0으로 취급합니다. 결과 배열의 길이는 max(두 길이)로 잡으면 안전합니다.

코드로 구현하기

C poly_add.c
#include <stdio.h>

int maxi(int x, int y) { return x > y ? x : y; }

/* c = a + b (sign=+1), a - b (sign=-1)
   da, db : 각 다항식의 차수 / 반환값 : c의 차수 */
int polyAddSub(int a[], int da,
               int b[], int db,
               int c[], int sign) {
    int d = maxi(da, db);
    for (int i = 0; i <= d; i++) {
        int x = (i <= da) ? a[i] : 0;  /* 없으면 0 */
        int y = (i <= db) ? b[i] : 0;
        c[i] = x + sign * y;
    }
    while (d > 0 && c[d] == 0) d--;  /* 최고차 0 정리 */
    return d;
}

int main(void) {
    int A[] = {1, 3, 2};  /* 2x^2 + 3x + 1 */
    int B[] = {2, 1};     /* x + 2 */
    int C[10];

    int dc = polyAddSub(A, 2, B, 1, C, +1);
    for (int i = 0; i <= dc; i++) printf("%d ", C[i]);
    printf("\n");

    dc = polyAddSub(A, 2, B, 1, C, -1);
    for (int i = 0; i <= dc; i++) printf("%d ", C[i]);
    printf("\n");
    return 0;
}

Python poly_add.py
def poly_add_sub(a, b, sign=1):
    """sign=1이면 a+b, sign=-1이면 a-b"""
    n = max(len(a), len(b))
    c = [0] * n
    for i in range(n):
        x = a[i] if i < len(a) else 0  # 없으면 0
        y = b[i] if i < len(b) else 0
        c[i] = x + sign * y
    while len(c) > 1 and c[-1] == 0:
        c.pop()                # 최고차 0 정리
    return c

A = [1, 3, 2]   # 2x² + 3x + 1
B = [2, 1]      # x + 2

print(poly_add_sub(A, B, +1))
print(poly_add_sub(A, B, -1))
실행 결과 (덧셈 / 뺄셈)[3, 4, 2]
[-1, 2, 2]
⚠️
최고차항이 사라지는 경우를 조심! 예를 들어 (2x² + x) − (2x² + 5) = x − 5 처럼 뺄셈 후 최고차항의 계수가 0이 될 수 있습니다. 그래서 마지막에 while 문으로 맨 뒤의 0을 지워 차수를 줄여 주는 것입니다.
⏱️
시간 복잡도: O(max(n, m)) — 배열을 한 번만 훑으면 되므로 매우 빠릅니다.

곱셈의 원리 — 분배법칙, 그리고 차수의 덧셈

곱셈은 분배법칙으로 모든 항을 서로 곱한 뒤, 같은 차수끼리 모으는 것입니다. 여기서 결정적인 성질이 나옵니다.

xi × xj = xi+j   ⟶   c[i+j] += a[i] × b[j]

a[i](xi의 계수)와 b[j](xj의 계수)를 곱하면 그 결과는 xi+j의 계수에 더해집니다. 이중 for문 하나로 곱셈이 끝나는 이유입니다.

(2x² + 3x + 1) × (x + 2) 를 표로 펼치면?

×x  (b[1])2  (b[0])
2x² (a[2])2x³4x²
3x (a[1])3x²6x
1 (a[0])x2

같은 차수끼리 모으면 ⟶ 2x³ + (4+3)x² + (6+1)x + 2 = 2x³ + 7x² + 7x + 2 = [2, 7, 7, 2]

💡
결과의 차수 = 두 차수의 합. 차수 da와 db인 다항식을 곱하면 결과는 차수 da+db, 배열 길이는 len(a) + len(b) − 1입니다. 결과 배열은 반드시 0으로 초기화한 뒤 누적(+=)해야 합니다.

코드로 구현하기

C poly_mul.c
#include <stdio.h>

/* c = a * b, 반환값 : c의 차수 */
int polyMul(int a[], int da,
            int b[], int db, int c[]) {
    int dc = da + db;            /* 차수의 합 */
    for (int i = 0; i <= dc; i++) c[i] = 0;

    for (int i = 0; i <= da; i++)
        for (int j = 0; j <= db; j++)
            c[i + j] += a[i] * b[j];  /* 핵심! */
    return dc;
}

int main(void) {
    int A[] = {1, 3, 2};  /* 2x^2 + 3x + 1 */
    int B[] = {2, 1};     /* x + 2 */
    int C[10];

    int dc = polyMul(A, 2, B, 1, C);
    for (int i = 0; i <= dc; i++) printf("%d ", C[i]);
    printf("\n");
    return 0;
}
실행 결과2 7 7 2
Python poly_mul.py
def poly_mul(a, b):
    # 결과 길이 = len(a) + len(b) - 1, 0으로 초기화
    c = [0] * (len(a) + len(b) - 1)
    for i in range(len(a)):
        for j in range(len(b)):
            c[i + j] += a[i] * b[j]   # 핵심!
    return c

A = [1, 3, 2]   # 2x² + 3x + 1
B = [2, 1]      # x + 2

print(poly_mul(A, B))
실행 결과[2, 7, 7, 2]
⏱️
시간 복잡도: O(n × m) — 모든 항의 쌍을 한 번씩 곱하기 때문입니다. 참고로 KOI 상급 문제에서는 이보다 빠른 FFT(고속 푸리에 변환)로 O(n log n)에 곱하기도 하지만, 지금은 이 이중 for문을 완벽히 이해하는 것이 먼저입니다.
🎮

나눗셈의 원리 — 다항식 항등식

정수 나눗셈 17 ÷ 5 = 몫 3, 나머지 2 (17 = 5×3 + 2)와 완전히 같은 구조입니다. 다항식 A(x)를 B(x)로 나누면 몫 Q(x)와 나머지 R(x)가 나옵니다.

A(x) = B(x) · Q(x) + R(x)   (단, R의 차수 < B의 차수)
💡
나머지의 차수는 반드시 나누는 식보다 작아야 합니다. 정수 나눗셈에서 나머지가 나누는 수보다 작아야 하는 것과 같은 조건입니다. 그리고 몫의 차수 = A의 차수 − B의 차수입니다.

장제법(긴 나눗셈) 단계별로 따라가기

예제: (x³ + 2x² − 5x + 6) ÷ (x − 1). 매 단계 규칙은 하나뿐입니다 — "최고차항끼리 나눠 몫의 항을 정하고, (그 항 × 나누는 식)을 빼서 차수를 낮춘다."

1
최고차항끼리 나누기: x³ ÷ x = x²
몫의 첫 항은 x². 이제 x²·(x−1) = x³ − x² 을 A에서 뺍니다.
(x³ + 2x² − 5x + 6) − (x³ − x²) = 3x² − 5x + 6
2
남은 식의 최고차항: 3x² ÷ x = 3x
몫에 +3x를 추가. 3x·(x−1) = 3x² − 3x 를 뺍니다.
(3x² − 5x + 6) − (3x² − 3x) = −2x + 6
3
남은 식의 최고차항: −2x ÷ x = −2
몫에 −2를 추가. −2·(x−1) = −2x + 2 를 뺍니다.
(−2x + 6) − (−2x + 2) = 4  ← 차수 0 < 1 이므로 여기서 끝!

몫 Q(x) = x² + 3x − 2,  나머지 R(x) = 4

검산: (x − 1)(x² + 3x − 2) + 4 = x³ + 2x² − 5x + 6 ✓

코드로 구현하기

코드에서는 위 과정을 그대로 옮깁니다. 나머지 배열 rem을 A의 복사본으로 시작해서, 몫의 항을 높은 차수부터 하나씩 결정하며 빼 나갑니다. 예제는 앞에서 쓰던 A = 2x²+3x+1, B = x+2입니다. (몫 2x−1, 나머지 3)

C poly_div.c
#include <stdio.h>

/* a ÷ b → 몫 q(차수 *dq), 나머지 r(차수 *dr)
   몫이 분수가 될 수 있으므로 double 사용
   (단, da >= db 라고 가정) */
void polyDiv(double a[], int da,
             double b[], int db,
             double q[], int *dq,
             double r[], int *dr) {
    double rem[50];
    for (int i = 0; i <= da; i++) rem[i] = a[i];

    *dq = da - db;               /* 몫의 차수 */
    for (int k = *dq; k >= 0; k--) {
        /* 1) 최고차항끼리 나누기 */
        double coef = rem[db + k] / b[db];
        q[k] = coef;
        /* 2) coef * x^k * B 를 빼기 */
        for (int j = 0; j <= db; j++)
            rem[j + k] -= coef * b[j];
    }
    /* 남은 낮은 차수 부분이 나머지 */
    *dr = db - 1;
    for (int i = 0; i <= *dr; i++) r[i] = rem[i];
    while (*dr > 0 && r[*dr] == 0) (*dr)--;
}

int main(void) {
    double A[] = {1, 3, 2};  /* 2x^2+3x+1 */
    double B[] = {2, 1};     /* x+2 */
    double Q[10], R[10];
    int dq, dr;

    polyDiv(A, 2, B, 1, Q, &dq, R, &dr);
    for (int i = 0; i <= dq; i++) printf("%g ", Q[i]);
    printf("\n");
    for (int i = 0; i <= dr; i++) printf("%g ", R[i]);
    printf("\n");
    return 0;
}

Python poly_div.py
def poly_div(a, b):
    """a ÷ b → (몫, 나머지). len(a) >= len(b) 가정"""
    rem = a[:]                  # A의 복사본에서 시작
    dq = len(a) - len(b)        # 몫의 차수
    q = [0] * (dq + 1)

    for k in range(dq, -1, -1):   # 높은 차수부터
        coef = rem[len(b)-1 + k] / b[-1]  # 최고차항끼리
        q[k] = coef
        for j in range(len(b)):     # coef·x^k·B 빼기
            rem[j + k] -= coef * b[j]

    r = rem[:len(b)-1] if len(b) > 1 else [0]
    while len(r) > 1 and r[-1] == 0:
        r.pop()
    return q, r

Q, R = poly_div([1, 3, 2], [2, 1])
print(Q)
print(R)
실행 결과 (몫 / 나머지)[-1.0, 2.0]
[3.0]
⚠️
두 가지 주의점. ① 정수 계수끼리 나눠도 몫은 분수가 될 수 있으므로(예: 2x² ÷ 3x) double/실수 나눗셈을 씁니다. ② 코드는 A의 차수 ≥ B의 차수를 가정합니다. A의 차수가 더 작으면 몫은 0, 나머지는 A 그대로입니다.
🎯
나머지정리 미리보기: A(x)를 (x − 1)로 나눈 나머지는 A(1)과 같습니다. 위 예제에서 A(1) = 1 + 2 − 5 + 6 = 4 — 장제법 결과와 일치하죠! 코드 검증에 아주 유용한 성질입니다.

확인 퀴즈 — 7문제

보기를 클릭하면 바로 채점됩니다. 초록색이 정답, 빨간색이 오답입니다.

맞힌 개수: 0 / 7
1배열 [4, 0, 3] 이 나타내는 다항식은? (인덱스 = 차수)
인덱스 0 → 상수항 4, 인덱스 1 → x의 계수 0, 인덱스 2 → x²의 계수 3. 따라서 3x² + 4 입니다.
2차수 3인 다항식과 차수 2인 다항식을 곱하면 결과의 차수는?
x³ × x² = x⁵. 곱셈에서 결과의 차수는 두 차수의 합입니다 (3 + 2 = 5).
3P(x) = x² + 2x, Q(x) = −x² + x + 5 일 때 P + Q 는?
x² 항: 1 + (−1) = 0 으로 사라집니다! 그래서 덧셈 코드 마지막에 최고차의 0을 지우는 while문이 필요한 것입니다.
4곱셈 코드에서 a[i] * b[j] 는 결과 배열의 어느 칸에 더해질까?
x^i × x^j = x^(i+j) 이므로 차수가 i+j인 칸, 즉 c[i+j]에 누적됩니다.
5A(x)를 B(x)로 나눌 때, 나머지 R(x)가 만족해야 하는 조건은?
나머지의 차수가 나누는 식보다 작아질 때까지 계속 나눕니다. 정수 나눗셈에서 나머지 < 나누는 수와 같은 조건입니다.
6(x³ + 2x² − 5x + 6) ÷ (x − 1) 의 나머지는?

모든 항의 쌍 n×m개를 각각 한 번씩 곱하므로 O(n × m)입니다. FFT를 쓰면 O(n log n)까지 빨라집니다.
