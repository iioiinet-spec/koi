정올 1104 비슷한 단어

알파벳 개수 차이로 비슷한 단어 판정하기

1. 문제 핵심

첫 번째 단어를 기준으로 나머지 단어들이 비슷한 단어인지 판단해서 개수를 출력합니다.

1. 구성이 완전히 같으면 비슷한 단어입니다.

2. 한 문자를 추가해서 같아질 수 있으면 비슷한 단어입니다.

3. 한 문자를 삭제해서 같아질 수 있으면 비슷한 단어입니다.

4. 한 문자를 다른 문자로 바꾸어 같아질 수 있으면 비슷한 단어입니다.

2. 핵심 판정 방법

단어의 순서는 중요하지 않습니다. 알파벳이 각각 몇 개 있는지만 비교합니다.

diff = 알파벳 26개의 개수 차이의 합

1. 길이가 같고 diff가 0이면 구성이 완전히 같습니다.

2. 길이가 같고 diff가 2이면 한 글자 교체로 같아집니다.

3. 길이 차이가 1이고 diff가 1이면 한 글자 추가 또는 삭제로 같아집니다.

4. 그 외는 비슷한 단어가 아닙니다.

3. 인터렉티브 판정기

4. 여러 단어 한 번에 판정하기

5. 예제 이해

입력
4
DOG
GOD
GOOD
DOLL

출력
2

GOD은 DOG와 구성이 같고, GOOD은 DOG에 O 하나를 추가하면 같아집니다. DOLL은 한 번의 추가, 삭제, 교체로 같아질 수 없습니다.

6. 코드 작성 방법

1. 알파벳 개수 배열 만들기

int cnt[26] = {0};

for (int i = 0; word[i] != '\0'; i++) {
    cnt[word[i] - 'A']++;
}

2. diff 계산

for (int i = 0; i < 26; i++) {

}

3. 비슷한 단어 판정

if (lenDiff == 0 && (diff == 0 || diff == 2)) return 1;
if (lenDiff == 1 && diff == 1) return 1;
return 0;

7. 정답 C 코드

#include <stdio.h>
#include <string.h>

int absValue(int x) {
    if (x < 0) return -x;
    return x;
}

int isSimilar(int base[], int baseLen, char word[]) {
    int cur[26] = {0};
    int curLen = strlen(word);

    for (int i = 0; word[i] != '\0'; i++) {
        cur[word[i] - 'A']++;
    }

    int diff = 0;

    for (int i = 0; i < 26; i++) {
        diff += absValue(base[i] - cur[i]);
    }

    int lenDiff = absValue(baseLen - curLen);

    if (lenDiff == 0 && (diff == 0 || diff == 2)) return 1;
    if (lenDiff == 1 && diff == 1) return 1;

    return 0;
}

int main() {
    int N;
    char baseWord[15];
    int base[26] = {0};

    scanf("%d", &N);
    scanf("%s", baseWord);

    int baseLen = strlen(baseWord);

    for (int i = 0; baseWord[i] != '\0'; i++) {
        base[baseWord[i] - 'A']++;
    }

    int answer = 0;

    for (int i = 1; i < N; i++) {
        char word[15];
        scanf("%s", word);

        if (isSimilar(base, baseLen, word)) {
            answer++;
        }
    }

    printf("%d\n", answer);

    return 0;
}

8. 자주 하는 실수

실수 1. 단어 순서를 비교하는 경우

DOG와 GOD은 순서가 다르지만 같은 구성입니다. 문자열 자체가 아니라 알파벳 개수를 비교해야 합니다.

실수 2. 교체를 diff == 1로 생각하는 경우

DOG와 DIG는 O가 1 줄고 I가 1 늘어나므로 diff는 2입니다.

실수 3. 길이 차이를 확인하지 않는 경우

길이가 같을 때와 길이 차이가 1일 때의 판정 조건이 다릅니다.

9. 핵심 정리

1. 알파벳 26개 개수 배열로 비교합니다.

2. 길이가 같으면 diff가 0 또는 2일 때 비슷합니다.

3. 길이 차이가 1이면 diff가 1일 때 비슷합니다.

4. 첫 번째 단어와 나머지 단어들을 하나씩 비교합니다.
