정올 5848 다항식2

구조체 정렬 + 같은 차수 합치기 + 출력 형식 처리

1. 문제 핵심

차수는 최대 1,000,000,000이므로 차수를 배열 인덱스로 사용할 수 없습니다. 전체 항은 최대 450개뿐이므로 구조체 배열에 저장하고 정렬합니다.

해결 순서

1. 모든 항 저장

2. 차수 내림차순 정렬

3. 같은 차수 계수 합산

4. 계수 0 항 제거

5. 형식에 맞춰 출력

출력 주의

차수 0 → 계수만 출력

계수 절댓값 1 → 숫자 1 생략

차수 1도 X^1 출력

모든 항이 사라지면 0 출력

2. 직접 계산하기

최종 다항식

계산 전입니다.

항 표현

진행 로그

3. 입력된 모든 항

순서계수차수항

4. 정렬 후 같은 차수 합치기

차수계수 목록합계최종 항출력 여부

5. 코드 작성 단계

단계설명
1단계Term 구조체에 coefficient와 degree를 저장한다.
2단계모든 다항식의 항을 하나의 배열에 모은다.
3단계qsort로 차수 내림차순 정렬한다.
4단계같은 차수인 동안 계수를 합친다.
5단계합계가 0이면 제거한다.
6단계첫 항과 이후 항의 부호를 구분한다.
7단계차수 0, 계수 ±1, 차수 1 형식을 처리한다.
8단계출력할 항이 없으면 0을 출력한다.

6. 정답 C 코드

#include <stdio.h>
#include <stdlib.h>

#define MAX_TERMS 450

typedef struct {
    int coefficient;
    int degree;
} Term;

Term terms[MAX_TERMS];

int compare(const void *a, const void *b) {
    const Term *x = (const Term *)a;
    const Term *y = (const Term *)b;

    if (x->degree < y->degree) return 1;
    if (x->degree > y->degree) return -1;
    return 0;
}

int main(void) {
    int N, count = 0;
    scanf("%d", &N);

    for (int i = 0; i < N; i++) {
        int M;
        scanf("%d", &M);
        for (int j = 0; j < M; j++) {
            scanf("%d %d", &terms[count].coefficient, &terms[count].degree);
            count++;
        }
    }

    qsort(terms, count, sizeof(Term), compare);

    int i = 0, first = 1;
    while (i < count) {
        int degree = terms[i].degree;
        int sum = 0;
        while (i < count && terms[i].degree == degree) {
            sum += terms[i].coefficient;
            i++;
        }
        if (sum == 0) continue;

        int absCoefficient = sum < 0 ? -sum : sum;
        if (first) {
            if (sum < 0) printf("-");
        } else {
            printf(sum > 0 ? "+" : "-");
        }

        if (degree == 0) printf("%d", absCoefficient);
        else {
            if (absCoefficient != 1) printf("%d", absCoefficient);
            printf("X^%d", degree);
        }
        first = 0;
    }

    if (first) printf("0");
    printf("\n");
    return 0;
}
