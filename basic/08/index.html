1. 문제 이해

존은 8마리의 소에게서 우유를 짭니다. 소들은 몇 가지 조건을 요구합니다. 조건은 항상 다음 형태입니다.

X must be milked beside Y

이 뜻은 X와 Y가 반드시 서로 바로 옆에 있어야 한다는 의미입니다. X가 Y의 앞에 있어도 되고, Y가 X의 앞에 있어도 됩니다.

답이 여러 개라면 사전순으로 가장 빠른 순서를 출력해야 합니다.

5. 조건 검사 원리

어떤 순서가 만들어졌다고 합시다. 그러면 각 소의 위치를 배열에 저장합니다.

pos[소] = 소가 서 있는 위치

X와 Y가 바로 옆에 있으려면 위치 차이가 1이어야 합니다.

abs(pos[X] - pos[Y]) == 1

예시

소 위치
Blue 5
Bella 6

Blue와 Bella의 위치 차이는 1이므로 둘은 바로 옆에 있습니다.

9. 정답 C 코드

#include <stdio.h>
#include <string.h>
#include <stdlib.h>

char cows[8][20] = {
    "Beatrice",
    "Belinda",
    "Bella",
    "Bessie",
    "Betsy",
    "Blue",
    "Buttercup",
    "Sue"
};

int N;
int condA[10], condB[10];

int used[8];
int order[8];
int answerFound = 0;

int getIndex(char name[]) {
    int i;

    for (i = 0; i < 8; i++) {
        if (strcmp(cows[i], name) == 0) {
            return i;
        }
    }

    return -1;
}

int checkCondition() {
    int pos[8];
    int i;

    for (i = 0; i < 8; i++) {
        pos[order[i]] = i;
    }

    for (i = 0; i < N; i++) {
        if (abs(pos[condA[i]] - pos[condB[i]]) != 1) {
            return 0;
        }
    }

    return 1;
}

void dfs(int depth) {
    int i;

    if (answerFound == 1) {
        return;
    }

    if (depth == 8) {
        if (checkCondition()) {
            for (i = 0; i < 8; i++) {
                printf("%s\n", cows[order[i]]);
            }
            answerFound = 1;
        }
        return;
    }

    for (i = 0; i < 8; i++) {
        if (used[i] == 0) {
            used[i] = 1;
            order[depth] = i;

            dfs(depth + 1);

            used[i] = 0;
        }
    }
}

int main() {
    int i;
    char X[20], temp1[20], temp2[20], temp3[20], temp4[20], Y[20];

    scanf("%d", &N);

    for (i = 0; i < N; i++) {
        scanf("%s %s %s %s %s %s", X, temp1, temp2, temp3, temp4, Y);

        condA[i] = getIndex(X);
        condB[i] = getIndex(Y);
    }

    dfs(0);

    return 0;
}

10. 마무리 정리

이 문제는 소가 8마리뿐이므로 복잡한 알고리즘보다 완전탐색이 가장 쉽고 안전합니다.

사전순으로 정렬된 배열에서 순열을 만들면, 첫 번째로 조건을 만족하는 순서가 바로 정답입니다.

완전탐색 문제에서는 먼저 데이터 크기를 확인하고, 가능한 모든 경우를 검사해도 되는지 판단하는 것이 중요합니다.
