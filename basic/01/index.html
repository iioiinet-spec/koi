BIKO 5930 슬픔을 나누면 2

계속 반으로 나누었을 때 B가 될 수 있는지 확인하기

1. 문제 핵심

슬픔의 양 A를 계속 반으로 나누었을 때, 어떤 조각의 크기가 B가 될 수 있는지 확인하는 문제입니다.

1. x가 짝수이면 x/2, x/2로 나뉩니다.

2. x가 홀수이면 ⌊x/2⌋, ⌊x/2⌋+1로 나뉩니다.

3. 가능하면 1, 불가능하면 0을 출력합니다.

2. 핵심 공식

A를 k번 나누었을 때 나올 수 있는 조각 크기는 다음 둘 중 하나입니다.

⌊ A / 2^k ⌋
⌈ A / 2^k ⌉

B가 이 둘 중 하나이면 만들 수 있습니다.

3. 인터렉티브 확인기

4. 예제 이해

예제 1

3 1

3을 한 번 나누면 1과 2가 됩니다. 1을 만들 수 있으므로 정답은 1입니다.

예제 2

10 4

10 → 5,5 → 2,3 이므로 4는 나오지 않습니다. 정답은 0입니다.

5. 코드 작성 방법

1. long long 사용

long long A, B;

2. floor와 ceil 계산

long long low = A / div;
long long high = (A + div - 1) / div;

3. B와 비교

if (B == low || B == high) {
    printf("1\n");
    return 0;
}

6. 정답 C 코드

#include <stdio.h>

int main() {
    long long A, B;

    scanf("%lld %lld", &A, &B);

    long long div = 2;

    for (int k = 1; k <= 60; k++) {
        long long low = A / div;
        long long high = (A + div - 1) / div;

        if (B == low || B == high) {
            printf("1\n");
            return 0;
        }

        div *= 2;
    }

    printf("0\n");

    return 0;
}

7. 왜 60번만 확인할까?

A의 최대값은 10^18입니다. 2^60은 10^18보다 크기 때문에 60번 정도 확인하면 충분합니다.

8. 자주 하는 실수

실수 1. int 사용

A와 B가 최대 10^18입니다.

int는 약 21억까지만 저장할 수 있습니다. 반드시 long long을 사용해야 합니다.

실수 2. 모든 조각을 저장

조각 개수는 계속 2배로 늘어납니다.

k번 나누었을 때 가능한 값은 ⌊A/2^k⌋ 또는 ⌈A/2^k⌉뿐이라는 성질을 이용합니다.

실수 3. ceil 계산 실수

ceil(A/div)는 (A + div - 1) / div 로 계산할 수 있습니다.

9. 핵심 정리

1. k번 나눈 뒤 가능한 값은 ⌊A/2^k⌋ 또는 ⌈A/2^k⌉입니다.

2. B가 둘 중 하나이면 만들 수 있습니다.

3. A가 10^18 이하이므로 60번만 확인하면 됩니다.

4. 반드시 long long을 사용합니다.
