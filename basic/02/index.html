정올 1295 이진탐색

정렬된 배열에서 원하는 수의 위치를 빠르게 찾기

1. 문제 핵심

오름차순으로 정렬된 N개의 수에서 찾고 싶은 수가 몇 번째 위치에 있는지 출력하는 문제입니다.

1. 배열은 이미 오름차순으로 정렬되어 있습니다.

2. 값은 서로 다릅니다.

3. 찾은 위치는 1부터 시작합니다.

4. 없으면 0을 출력합니다.

2. 이진탐색 원리

이진탐색은 가운데 값과 비교해서 탐색 범위를 절반씩 줄입니다.

1. left와 right를 정한다.
2. mid = (left + right) / 2 를 구한다.
3. arr[mid]와 target을 비교한다.
4. 같으면 찾은 위치를 반환한다.
5. arr[mid]가 작으면 오른쪽을 찾는다.
6. arr[mid]가 크면 왼쪽을 찾는다.

3. 인터렉티브 이진탐색

배열과 찾을 값을 입력하고 한 단계씩 실행해 보세요.


4. 여러 개의 수 한 번에 찾기

문제처럼 T개의 수를 한 번에 입력해서 위치를 확인합니다.

5. 예제 이해

입력
7
2 4 9 10 14 23 32
3
6 23 9

출력
0
6
3

6은 없으므로 0, 23은 6번째, 9는 3번째입니다.

6. 코드 작성 방법

1. left, right 설정

int left = 0;
int right = n - 1;

2. 가운데 위치 mid 계산

int mid = (left + right) / 2;

3. 값을 찾았을 때

if (arr[mid] == target) {
    return mid + 1;
}

4. 오른쪽 탐색

else if (arr[mid] < target) {
    left = mid + 1;
}

5. 왼쪽 탐색

else {
    right = mid - 1;
}

7. 정답 C 코드

#include <stdio.h>

#define MAXN 50000

int arr[MAXN];

int binarySearch(int n, int target) {
    int left = 0;
    int right = n - 1;

    while (left <= right) {
        int mid = (left + right) / 2;

        if (arr[mid] == target) {
            return mid + 1;
        }
        else if (arr[mid] < target) {
            left = mid + 1;
        }
        else {
            right = mid - 1;
        }
    }

    return 0;
}

int main() {
    int N;
    int T;

    scanf("%d", &N);

    for (int i = 0; i < N; i++) {
        scanf("%d", &arr[i]);
    }

    scanf("%d", &T);

    for (int i = 0; i < T; i++) {
        int target;
        scanf("%d", &target);

        printf("%d\n", binarySearch(N, target));
    }

    return 0;
}

8. 자주 하는 실수

실수 1. 위치를 mid로 출력하는 경우

문제의 위치는 1부터 시작합니다.

C 배열 인덱스는 0부터 시작하므로 찾은 위치는 mid + 1을 출력해야 합니다.

실수 2. left와 right 갱신을 반대로 하는 경우

arr[mid]가 target보다 작으면 오른쪽을 봐야 합니다.

arr[mid] < target이면 left = mid + 1입니다. arr[mid] > target이면 right = mid - 1입니다.

실수 3. 못 찾았을 때 0을 출력하지 않는 경우

left > right가 되면 탐색 실패입니다.

while문이 끝날 때까지 못 찾으면 return 0을 해야 합니다.

9. 핵심 정리

1. 정렬된 배열에서는 이진탐색을 사용할 수 있습니다.

2. 한 번 비교할 때마다 탐색 범위가 절반으로 줄어듭니다.

3. 찾으면 mid + 1을 반환합니다.

4. 못 찾으면 0을 반환합니다.

5. 시간복잡도는 O(T log N)입니다.
