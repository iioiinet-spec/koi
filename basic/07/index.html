정올 5176 예쁜 수열

연속 구간에서 증가했다가 감소하는 최대 길이 찾기

1. 문제 핵심

연속한 구간을 골랐을 때 숫자가 증가했다가 감소하는 모양이면 예쁜 수열입니다.

1. 하나만 있는 구간은 예쁜 수열이 아닙니다.

2. 증가만 하는 구간도 예쁜 수열이 아닙니다.

3. 감소만 하는 구간도 예쁜 수열이 아닙니다.

4. 반드시 증가 부분과 감소 부분이 모두 있어야 합니다.

2. 핵심 아이디어

각 위치를 꼭대기라고 생각합니다.

left[i]  = i에서 끝나는 연속 증가 구간의 길이
right[i] = i에서 시작하는 연속 감소 구간의 길이

예쁜 수열 길이 = left[i] + right[i] - 1

left[i]가 2 이상이고 right[i]가 2 이상이어야 진짜 예쁜 수열입니다.

3. 인터렉티브 계산기

4. 예제 이해

입력
8
4 3 1 2 7 6 5 8

예쁜 수열
1 2 7 6 5

모양
1 < 2 < 7 > 6 > 5

길이
5

5. left 배열 만들기

left[0] = 1;

for (int i = 1; i < N; i++) {
    if (arr[i - 1] < arr[i]) {
        left[i] = left[i - 1] + 1;
    } else {
        left[i] = 1;
    }
}

6. right 배열 만들기

right[N - 1] = 1;

for (int i = N - 2; i >= 0; i--) {
    if (arr[i] > arr[i + 1]) {
        right[i] = right[i + 1] + 1;
    } else {
        right[i] = 1;
    }
}

7. 정답 C 코드

#include <stdio.h>

#define MAXN 55

int arr[MAXN];
int left[MAXN];
int right[MAXN];

int main() {
    int N;

    scanf("%d", &N);

    for (int i = 0; i < N; i++) {
        scanf("%d", &arr[i]);
    }

    left[0] = 1;

    for (int i = 1; i < N; i++) {
        if (arr[i - 1] < arr[i]) {
            left[i] = left[i - 1] + 1;
        } else {
            left[i] = 1;
        }
    }

    right[N - 1] = 1;

    for (int i = N - 2; i >= 0; i--) {
        if (arr[i] > arr[i + 1]) {
            right[i] = right[i + 1] + 1;
        } else {
            right[i] = 1;
        }
    }

    int answer = 0;

    for (int i = 0; i < N; i++) {
        if (left[i] >= 2 && right[i] >= 2) {
            int len = left[i] + right[i] - 1;

            if (len > answer) {
                answer = len;
            }
        }
    }

    printf("%d\n", answer);

    return 0;
}

8. 자주 하는 실수

실수 1. 증가만 하는 구간을 답으로 세는 경우

left[i]가 길어도 right[i]가 1이면 감소 부분이 없으므로 예쁜 수열이 아닙니다.

실수 2. 감소만 하는 구간을 답으로 세는 경우

right[i]가 길어도 left[i]가 1이면 증가 부분이 없으므로 예쁜 수열이 아닙니다.

실수 3. 꼭대기를 두 번 세는 경우

left와 right 모두 꼭대기 i를 포함하므로 길이는 left[i] + right[i] - 1입니다.

9. 핵심 정리

1. 예쁜 수열은 증가 후 감소하는 연속 구간입니다.

2. 각 위치를 꼭대기로 생각합니다.

3. left[i]는 i에서 끝나는 연속 증가 길이입니다.

4. right[i]는 i에서 시작하는 연속 감소 길이입니다.

5. left[i] >= 2, right[i] >= 2일 때만 가능합니다.

6. 길이는 left[i] + right[i] - 1입니다.
