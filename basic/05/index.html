정올 2902 30의 배수2

100,000자리 수를 문자열과 숫자 개수로 처리하기

1. 문제 핵심

주어진 숫자의 각 자리 숫자들을 재배치해서 만들 수 있는 수 중 가장 큰 30의 배수를 출력합니다. 만들 수 없으면 -1을 출력합니다.

1. 숫자는 최대 100,000자리이므로 정수형으로 저장할 수 없습니다.

2. 문자열로 입력받아야 합니다.

3. 30의 배수 조건을 확인합니다.

4. 가능하면 숫자를 큰 것부터 출력합니다.

2. 30의 배수 조건

30 = 3 × 10

1. 10의 배수 조건: 마지막 자리가 0이어야 하므로 숫자 0이 반드시 있어야 합니다.

2. 3의 배수 조건: 모든 자리 숫자의 합이 3의 배수여야 합니다.

3. 인터렉티브 확인기

4. 가장 큰 수를 만드는 방법

30의 배수를 만들 수 있다면, 가장 큰 수를 만들기 위해 숫자를 내림차순으로 배치합니다.

9, 8, 7, 6, 5, 4, 3, 2, 1, 0 순서로 출력

5. 코드 작성 방법

1. 문자열로 입력받기

char num[100005];
scanf("%s", num);

2. 숫자 개수 세기

int count[10] = {0};

for (int i = 0; num[i] != '\0'; i++) {
    int digit = num[i] - '0';
    count[digit]++;
    sum += digit;
}

3. 30의 배수 가능 여부 확인

if (count[0] == 0 || sum % 3 != 0) {
    printf("-1\n");
    return 0;
}

4. 가장 큰 수 출력

for (int d = 9; d >= 0; d--) {
    for (int i = 0; i < count[d]; i++) {
        printf("%d", d);
    }
}

6. 정답 C 코드

#include <stdio.h>

int main() {
    char num[100005];
    int count[10] = {0};
    int sum = 0;

    scanf("%s", num);

    for (int i = 0; num[i] != '\0'; i++) {
        int digit = num[i] - '0';

        count[digit]++;
        sum += digit;
    }

    if (count[0] == 0 || sum % 3 != 0) {
        printf("-1\n");
        return 0;
    }

    for (int d = 9; d >= 0; d--) {
        for (int i = 0; i < count[d]; i++) {
            printf("%d", d);
        }
    }

    printf("\n");

    return 0;
}

7. 자주 하는 실수

실수 1. int나 long long으로 입력받는 경우

정수형 범위를 훨씬 넘기 때문에 반드시 문자열 char 배열로 입력받아야 합니다.

실수 2. 3의 배수 조건만 확인하는 경우

자릿수 합이 3의 배수여도 0이 없으면 마지막 자리를 0으로 만들 수 없으므로 30의 배수가 아닙니다.

실수 3. 오름차순으로 출력하는 경우

가장 큰 수를 만들려면 9부터 0까지 내림차순으로 출력해야 합니다.

8. 핵심 정리

1. 30의 배수 조건은 0이 있음 + 자릿수 합이 3의 배수입니다.

2. 입력이 매우 크므로 문자열로 처리합니다.

3. 숫자 개수 배열 count[10]을 사용합니다.

4. 만들 수 있으면 9부터 0까지 출력합니다.

5. 만들 수 없으면 -1을 출력합니다.
