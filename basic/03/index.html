정올 1161 하노이1

재귀로 하노이 탑 최소 이동 과정 출력하기

1. 문제 핵심

N개의 원판이 모두 1번 기둥에 있습니다. 모든 원판을 최소 횟수로 3번 기둥으로 옮기는 과정을 출력해야 합니다.

1. 한 번에 하나의 원판만 옮길 수 있습니다.

2. 큰 원판은 작은 원판 위에 올라갈 수 없습니다.

3. 원판 번호는 작은 원판부터 1, 2, 3, ..., N입니다.

4. 처음 호출은 hanoi(N, 1, 3, 2)입니다.

2. 인터렉티브 하노이 실행기

1번 기둥
2번 기둥
3번 기둥

3. 재귀 구조 이해하기

hanoi(n, from, to, temp)

1. hanoi(n - 1, from, temp, to)
2. n번 원판을 from에서 to로 이동
3. hanoi(n - 1, temp, to, from)

큰 원판 n을 옮기려면, 그 위의 n-1개 원판을 먼저 보조 기둥으로 치워야 합니다.

4. N = 3 호출 구조

hanoi(3, 1, 3, 2)

1. hanoi(2, 1, 2, 3)
2. 3 : 1 -> 3
3. hanoi(2, 2, 3, 1)
1 : 1 -> 3
2 : 1 -> 2
1 : 3 -> 2
3 : 1 -> 3
1 : 2 -> 1
2 : 2 -> 3
1 : 1 -> 3

5. 최소 이동 횟수

2^N - 1

N=3이면 2^3 - 1 = 7번입니다.

6. 정답 C 코드

#include <stdio.h>

void hanoi(int n, int from, int to, int temp) {
    if (n == 1) {
        printf("1 : %d -> %d\n", from, to);
        return;
    }

    hanoi(n - 1, from, temp, to);

    printf("%d : %d -> %d\n", n, from, to);

    hanoi(n - 1, temp, to, from);
}

int main() {
    int N;
    scanf("%d", &N);
    hanoi(N, 1, 3, 2);
    return 0;
}

7. 코드 작성 방법

1. 함수 정의

void hanoi(int n, int from, int to, int temp)

2. 종료 조건

if (n == 1) {
    printf("1 : %d -> %d\n", from, to);
    return;
}

3. 재귀 호출

hanoi(n - 1, from, temp, to);
printf("%d : %d -> %d\n", n, from, to);
hanoi(n - 1, temp, to, from);

8. 자주 하는 실수

실수 1. 보조 기둥 순서를 헷갈리는 경우

처음에는 n-1개를 보조 기둥으로 보내므로 hanoi(n-1, from, temp, to)입니다.

실수 2. 원판 번호를 잘못 출력하는 경우

현재 옮기는 가장 큰 원판 번호는 n입니다.

실수 3. 출력 형식을 다르게 쓰는 경우

원판번호 : 이동전 기둥번호 -> 이동후 기둥번호 형식으로 출력합니다.

9. 핵심 정리

1. 하노이는 재귀의 대표 문제입니다.

2. N개를 옮기려면 먼저 N-1개를 보조 기둥으로 옮깁니다.

3. N번 원판을 목표 기둥으로 옮깁니다.

4. N-1개를 다시 목표 기둥으로 옮깁니다.

5. 최소 이동 횟수는 2^N - 1입니다.
