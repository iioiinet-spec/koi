정올 8222 가위 바위 보

문자열 두 개를 한 글자씩 비교하여 정올이와 한글이의 승리 횟수를 세는 기초 구현 문제입니다.

문자열조건문반복문C언어

1. 문제 이해

정올이와 한글이가 총 N번 가위바위보를 합니다.

정올이의 손 모양은 문자열 S, 한글이의 손 모양은 문자열 T로 주어집니다.

이 문제에서는 정올이는 R, S만 낼 수 있고, 한글이는 R, P만 낼 수 있습니다.

2. 가위바위보 규칙

손 모양뜻이기는 상대
R바위S
S가위P
P보R

3. 가능한 경우 정리

정올이한글이결과
RR비김
RP한글이 승
SR한글이 승
SP정올이 승
정올이가 이기는 경우는 오직 S vs P입니다. 나머지 서로 다른 경우는 한글이가 이깁니다.

4. 인터랙티브 시뮬레이터

입력하기

출력 결과

판정하기 버튼을 눌러보세요.

5. 알고리즘

1. N을 입력받습니다.

2. 문자열 S와 T를 입력받습니다.

3. i를 0부터 N-1까지 반복합니다.

4. S[i]와 T[i]가 같으면 비긴 것이므로 아무 점수도 올리지 않습니다.

5. S[i]가 'S'이고 T[i]가 'P'이면 정올이가 이깁니다.

6. 그 외 서로 다른 경우는 한글이가 이깁니다.

6. 정답 C 코드

#include <stdio.h>

int main() {
    int N;
    char S[105];
    char T[105];

    scanf("%d", &N);
    scanf("%s", S);
    scanf("%s", T);

    int jungolWin = 0;
    int hangulWin = 0;

    for (int i = 0; i < N; i++) {
        if (S[i] == T[i]) {
            continue;
        }

        if (S[i] == 'S' && T[i] == 'P') {
            jungolWin++;
        } else {
            hangulWin++;
        }
    }

    printf("%d %d\n", jungolWin, hangulWin);

    return 0;
}

7. 코드 자세한 설명

1. 입력

scanf("%d", &N);
scanf("%s", S);
scanf("%s", T);

N과 두 문자열을 입력받습니다.

2. 승리 횟수 변수

int jungolWin = 0;
int hangulWin = 0;

정올이와 한글이의 승리 횟수를 저장합니다.

3. 한 글자씩 비교

for (int i = 0; i < N; i++)

문자열의 0번 위치부터 N-1번 위치까지 차례대로 확인합니다.

4. 비긴 경우

if (S[i] == T[i]) {
    continue;
}

두 손 모양이 같으면 아무도 이기지 않았으므로 다음 회차로 넘어갑니다.

5. 정올이가 이기는 경우

if (S[i] == 'S' && T[i] == 'P') {
    jungolWin++;
}

가위는 보를 이기므로 정올이 승리입니다.

6. 한글이가 이기는 경우

else {
    hangulWin++;
}

비기지 않았고 정올이가 이긴 경우도 아니면 한글이가 이깁니다.

8. 미니 퀴즈

문제 1

정올이가 S, 한글이가 P를 냈다면 누가 이길까요?

정답: 정올이입니다. S는 가위, P는 보이고, 가위는 보를 이깁니다.

문제 2

정올이가 R, 한글이가 P를 냈다면 누가 이길까요?

정답: 한글이입니다. P는 보, R은 바위이고, 보는 바위를 이깁니다.

문제 3

두 사람이 모두 R을 냈다면 승리 횟수는 올라갈까요?

정답: 올라가지 않습니다. 같은 손 모양이면 비깁니다.
