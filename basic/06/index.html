초콜릿 포장

길이 2 또는 3 묶음으로 자르는 DP 문제

1. 문제 핵심

초콜릿 문자열을 앞에서부터 여러 묶음으로 잘라 포장합니다. 각 묶음은 연속한 2개 또는 3개여야 하고, 불량 초콜릿 F는 묶음 하나에 최대 1개만 들어갈 수 있습니다.

1. 모든 초콜릿을 반드시 사용해야 합니다.

2. 묶음 길이는 2 또는 3입니다.

3. 한 묶음에 F가 2개 이상이면 불가능합니다.

4. 얻을 수 있는 금액의 최댓값을 구합니다.

2. 가격표

묶음 길이F 개수가격
204
213
307
315
2 또는 32개 이상불가능

3. 핵심 DP

앞에서부터 i개 초콜릿을 포장했을 때의 최대 금액을 저장합니다.

dp[i] = 앞에서부터 i개를 포장했을 때 얻을 수 있는 최대 금액

마지막 묶음은 길이 2 또는 3뿐입니다.

dp[i] = max(
    dp[i - 2] + 마지막 2개 가격,
    dp[i - 3] + 마지막 3개 가격
)

4. 인터렉티브 DP 계산기

문자열을 입력하고 DP 계산 과정을 확인하세요.

5. 예제 이해

입력
14
CCFCCFCFCCCFCC

가능한 포장
CCF / CCF / CF / CCC / FCC

가격
5 + 5 + 3 + 7 + 5 = 25

따라서 최댓값은 25입니다.

6. 누적합으로 F 개수 구하기

매번 묶음 안의 F를 직접 세지 않고, prefix 배열을 사용합니다.

prefix[i] = 1번부터 i번까지 F의 개수

구간 l~r의 F 개수
= prefix[r] - prefix[l - 1]

7. 정답 C 코드

#include <stdio.h>

#define MAXN 300005
#define NEG -1000000000

int dp[MAXN];
int prefix[MAXN];
char S[MAXN];

int max(int a, int b) {
    return a > b ? a : b;
}

int getPrice(int len, int fCount) {
    if (fCount >= 2) {
        return NEG;
    }

    if (len == 2) {
        if (fCount == 0) return 4;
        else return 3;
    }

    if (len == 3) {
        if (fCount == 0) return 7;
        else return 5;
    }

    return NEG;
}

int main() {
    int N;

    scanf("%d", &N);
    scanf("%s", S + 1);

    for (int i = 1; i <= N; i++) {
        prefix[i] = prefix[i - 1];

        if (S[i] == 'F') {
            prefix[i]++;
        }
    }

    for (int i = 0; i <= N; i++) {
        dp[i] = NEG;
    }

    dp[0] = 0;

    for (int i = 1; i <= N; i++) {
        if (i >= 2 && dp[i - 2] != NEG) {
            int fCount = prefix[i] - prefix[i - 2];
            int price = getPrice(2, fCount);

            if (price != NEG) {
                dp[i] = max(dp[i], dp[i - 2] + price);
            }
        }

        if (i >= 3 && dp[i - 3] != NEG) {
            int fCount = prefix[i] - prefix[i - 3];
            int price = getPrice(3, fCount);

            if (price != NEG) {
                dp[i] = max(dp[i], dp[i - 3] + price);
            }
        }
    }

    if (dp[N] == NEG) {
        printf("-1\n");
    } else {
        printf("%d\n", dp[N]);
    }

    return 0;
}

8. 자주 하는 실수

실수 1. 길이 1 묶음을 허용하는 경우

묶음은 반드시 2개 또는 3개입니다.

dp[i-1]은 고려하면 안 됩니다. 오직 dp[i-2], dp[i-3]만 봅니다.

실수 2. F가 2개 이상인 묶음을 포장하는 경우

한 묶음에 불량 초콜릿은 최대 1개입니다.

fCount >= 2이면 그 묶음은 불가능 처리해야 합니다.

실수 3. 불가능 상태를 0으로 두는 경우

아직 만들 수 없는 dp 상태와 실제 가격 0을 구분해야 합니다.

NEG 같은 아주 작은 값을 사용해서 불가능 상태를 표시합니다.

9. 핵심 정리

1. dp[i]는 앞에서부터 i개를 포장한 최대 금액입니다.

2. 마지막 묶음은 길이 2 또는 3입니다.

3. F 개수는 prefix로 빠르게 구합니다.

4. fCount가 2 이상이면 그 묶음은 불가능합니다.

5. dp[N]이 불가능 상태이면 -1을 출력합니다.
