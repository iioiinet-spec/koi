중등올림피아드 이진탐색 Binary Search

정렬된 자료에서 절반씩 줄이며 빠르게 찾는 알고리즘을 직접 실습합니다.

1. 이진탐색이란?

이진탐색은 정렬된 배열에서 원하는 값을 찾을 때 사용하는 매우 빠른 탐색 방법입니다.

가운데 값을 확인하고, 찾을 범위를 절반으로 줄인다.
1단계
왼쪽 끝을 left, 오른쪽 끝을 right로 정합니다.
2단계
가운데 위치 mid를 계산합니다.
3단계
가운데 값과 찾는 값을 비교해서 왼쪽 또는 오른쪽 절반을 버립니다.

중요 조건 배열은 반드시 정렬되어 있어야 합니다.

2. 왜 빠를까?

처음부터 하나씩 찾는 방법을 순차탐색이라고 합니다. 자료가 1,000개라면 최악의 경우 1,000번 확인해야 합니다.

하지만 이진탐색은 한 번 확인할 때마다 범위가 절반으로 줄어듭니다.

자료 개수순차탐색 최악이진탐색 대략
10개10번4번 정도
100개100번7번 정도
1,000개1,000번10번 정도
1,000,000개1,000,000번20번 정도
시간복잡도: O(log N)

4. 코드 작성 단계

1단계. 시작 범위 정하기
left = 0, right = n - 1로 시작합니다.
2단계. 반복 조건 만들기
left <= right인 동안 찾을 수 있습니다.
3단계. 가운데 위치 계산하기
mid = (left + right) / 2
큰 수에서는 안전하게 mid = left + (right - left) / 2를 사용합니다.
4단계. 가운데 값 비교하기
같으면 찾은 것입니다. 작으면 오른쪽으로, 크면 왼쪽으로 범위를 줄입니다.
5단계. 끝까지 못 찾으면 -1
반복이 끝났는데 못 찾으면 배열에 없는 값입니다.

5. C 코드 구현

#include <stdio.h>

int binarySearch(int arr[], int n, int target) {
    int left = 0;
    int right = n - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (arr[mid] == target) {
            return mid;
        }
        else if (arr[mid] < target) {
            left = mid + 1;
        }
        else {
            right = mid - 1;
        }
    }

    return -1;
}

int main() {
    int arr[] = {2, 5, 8, 12, 16, 23, 38, 45, 56, 72, 91};
    int n = sizeof(arr) / sizeof(arr[0]);
    int target = 38;

    int result = binarySearch(arr, n, target);

    if (result == -1) {
        printf("찾는 값이 없습니다.\n");
    } else {
        printf("%d는 %d번째 위치에 있습니다.\n", target, result);
    }

    return 0;
}

def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1

7. 올림피아드에서 자주 나오는 이진탐색 유형

유형 1. 값 찾기
정렬된 배열에서 특정 숫자가 있는지 찾습니다.
유형 2. lower_bound
target 이상이 처음 나오는 위치를 찾습니다.
유형 3. upper_bound
target보다 큰 값이 처음 나오는 위치를 찾습니다.
유형 4. 매개변수 탐색
정답이 될 수 있는 범위를 이진탐색합니다. 예: 랜선 자르기, 나무 자르기, 용량 정하기

8. lower_bound 실습

lower_bound는 정렬된 배열에서 target 이상이 처음 나오는 위치를 찾는 방법입니다.

arr[index] ≥ target 인 가장 작은 index
int lowerBound(int arr[], int n, int target) {
    int left = 0;
    int right = n;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (arr[mid] >= target) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    return left;
}

9. 확인 문제

문제 1. 이진탐색을 사용하려면 배열은 어떤 상태여야 하나요?
정답: 정렬되어 있어야 합니다. 이진탐색은 가운데 값을 기준으로 왼쪽 또는 오른쪽을 버리기 때문입니다.
문제 2. 배열 [1, 3, 5, 7, 9]에서 7을 찾을 때 처음 mid 위치는 어디인가요?
정답: index 2입니다. left=0, right=4이므로 mid=(0+4)/2=2입니다.
문제 3. arr[mid] < target이면 다음에는 어느 쪽을 탐색해야 하나요?
정답: 오른쪽입니다. 가운데 값이 너무 작으므로 left = mid + 1로 바꿉니다.
문제 4. 이진탐색의 시간복잡도는 무엇인가요?
정답: O(log N)입니다. 한 번 비교할 때마다 탐색 범위가 절반으로 줄어듭니다.

10. 수업 정리

이진탐색은 단순히 코드를 외우는 알고리즘이 아닙니다. 핵심은 정렬된 자료에서 가운데를 기준으로 탐색 범위를 절반씩 줄이는 생각입니다.

leftrightmid 세 변수가 어떻게 움직이는지 표로 추적하면 코드를 훨씬 쉽게 이해할 수 있습니다.
