정올 1450 케이크자르기

격자 모델링 · 절단선 표시 · BFS로 조각 개수 세기

1. 문제 이해

직사각형 케이크를 여러 개의 사각형 틀로 자릅니다. 사각형 틀은 내부를 없애는 것이 아니라 사각형의 둘레를 따라 케이크를 자릅니다.

출력해야 하는 것은 잘라진 뒤의 연결된 케이크 조각 수입니다.

핵심: 1×1 칸으로 나누고, 칸 사이의 절단선을 벽처럼 처리한 뒤 BFS로 연결 요소를 셉니다.

2. 좌표와 칸의 관계

케이크 크기가 H × W라면 실제 칸은 H × W개입니다. 좌표는 선 위의 위치이고, 칸은 좌표 사이의 작은 사각형입니다.

세로 절단선 vcut[y][x]
x 위치의 세로선이 있으면 왼쪽 칸과 오른쪽 칸이 분리됩니다.
가로 절단선 hcut[y][x]
y 위치의 가로선이 있으면 아래 칸과 위 칸이 분리됩니다.

3. 사각형 둘레 표시 방법

left = min(x1, x2)
right = max(x1, x2)
bottom = min(y1, y2)
top = max(y1, y2)

네 변을 절단선으로 표시합니다.

왼쪽 세로선: x = left
오른쪽 세로선: x = right
아래 가로선: y = bottom
위 가로선: y = top
케이크 바깥 테두리의 절단선은 따로 표시하지 않아도 됩니다. BFS 범위 검사로 밖으로 이동하지 못하게 합니다.

8. 정답 C 코드

#include <stdio.h>

int H, W, N;
int vcut[25][25];
int hcut[25][25];
int visited[25][25];
int qy[1000], qx[1000];

int minValue(int a, int b) { return a < b ? a : b; }
int maxValue(int a, int b) { return a > b ? a : b; }

void addVerticalCut(int x, int y1, int y2) {
    int y;
    if (x <= 0 || x >= W) return;
    for (y = y1; y < y2; y++) vcut[y][x] = 1;
}

void addHorizontalCut(int y, int x1, int x2) {
    int x;
    if (y <= 0 || y >= H) return;
    for (x = x1; x < x2; x++) hcut[y][x] = 1;
}

void bfs(int sy, int sx) {
    int front = 0, rear = 0;
    qy[rear] = sy;
    qx[rear] = sx;
    rear++;
    visited[sy][sx] = 1;

    while (front < rear) {
        int y = qy[front];
        int x = qx[front];
        front++;

        if (x > 0 && vcut[y][x] == 0 && visited[y][x - 1] == 0) {
            visited[y][x - 1] = 1;
            qy[rear] = y;
            qx[rear] = x - 1;
            rear++;
        }

        if (x < W - 1 && vcut[y][x + 1] == 0 && visited[y][x + 1] == 0) {
            visited[y][x + 1] = 1;
            qy[rear] = y;
            qx[rear] = x + 1;
            rear++;
        }

        if (y > 0 && hcut[y][x] == 0 && visited[y - 1][x] == 0) {
            visited[y - 1][x] = 1;
            qy[rear] = y - 1;
            qx[rear] = x;
            rear++;
        }

        if (y < H - 1 && hcut[y + 1][x] == 0 && visited[y + 1][x] == 0) {
            visited[y + 1][x] = 1;
            qy[rear] = y + 1;
            qx[rear] = x;
            rear++;
        }
    }
}

int main() {
    int i, x1, y1, x2, y2;
    int left, right, bottom, top;
    int y, x, answer = 0;

    scanf("%d %d", &H, &W);
    scanf("%d", &N);

    for (i = 0; i < N; i++) {
        scanf("%d %d %d %d", &x1, &y1, &x2, &y2);
        left = minValue(x1, x2);
        right = maxValue(x1, x2);
        bottom = minValue(y1, y2);
        top = maxValue(y1, y2);
        addVerticalCut(left, bottom, top);
        addVerticalCut(right, bottom, top);
        addHorizontalCut(bottom, left, right);
        addHorizontalCut(top, left, right);
    }

    for (y = 0; y < H; y++) {
        for (x = 0; x < W; x++) {
            if (visited[y][x] == 0) {
                bfs(y, x);
                answer++;
            }
        }
    }

    printf("%d\n", answer);
    return 0;
}

9. 마무리 정리

이 문제는 도형 문제처럼 보이지만 실제로는 격자 그래프 문제입니다.

사각형 둘레를 칸 사이의 벽으로 저장하고, BFS로 연결된 칸 덩어리 수를 세면 됩니다.

시간복잡도는 O(H × W + N × (H + W))이며, H와 W가 최대 20이므로 충분히 빠릅니다.
