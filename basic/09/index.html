정올 2137 개미 군단

충돌 문제 · 관점 바꾸기 · 최소 시간과 최대 시간

1. 문제 이해

길이 L cm인 막대기 위에 n마리의 개미가 있습니다. 모든 개미는 초속 1cm로 움직이고, 끝에 도착하면 떨어집니다.

두 개미가 만나면 방향을 반대로 바꾸지만, 처음 방향은 알 수 없습니다. 모든 개미가 떨어지는 최소 시간과 최대 시간을 구해야 합니다.

핵심 질문: 개미들이 서로 부딪히는 것을 실제로 시뮬레이션해야 할까요?

2. 가장 중요한 관찰

두 개미가 같은 속도로 움직이다가 만나서 방향을 바꾸는 상황을 생각해 봅시다.

두 개미가 충돌해서 방향을 바꾸는 것은, 사실상 서로 그냥 지나가는 것과 결과가 같습니다.

개미의 이름을 구분하지 않는다면, 충돌은 “이름표만 바뀌는 것”처럼 볼 수 있습니다. 그래서 전체 개미가 모두 떨어지는 시간만 구할 때는 충돌을 직접 계산하지 않아도 됩니다.

3. 최소 시간과 최대 시간 공식

위치가 x인 개미가 있다고 합시다.

왼쪽 끝까지 걸리는 시간
x
오른쪽 끝까지 걸리는 시간
L - x
가장 빨리 떨어지는 시간
min(x, L - x)
가장 늦게 떨어지는 시간
max(x, L - x)

모든 개미가 떨어져야 하므로, 각 개미의 시간 중 가장 큰 값을 봐야 합니다.

최소 정답 = max( min(x, L - x) )
최대 정답 = max( max(x, L - x) )

4. 인터랙티브 계산기

막대기 길이와 개미 위치를 입력하면 최소 시간과 최대 시간을 계산합니다.

0L
아직 계산하지 않았습니다.

5. 정올 입력 형식으로 계산하기

문제 입력을 그대로 붙여넣고 계산할 수 있습니다.


아직 계산하지 않았습니다.

7. 이해 확인 문제

문제 1

두 개미가 만나 방향을 바꾸는 것은 어떤 관점으로 볼 수 있나요?

문제 2

위치 x인 개미가 가장 빨리 떨어질 수 있는 시간은?

문제 3

모든 개미가 떨어지는 최소 시간은 어떻게 구하나요?

아직 채점하지 않았습니다.

8. 정답 C 코드

#include <stdio.h>

int main() {
    int L, n;
    int i;
    int x;
    int nearTime;
    int farTime;
    int minAnswer = 0;
    int maxAnswer = 0;

    scanf("%d %d", &L, &n);

    for (i = 0; i < n; i++) {
        scanf("%d", &x);

        if (x < L - x) {
            nearTime = x;
            farTime = L - x;
        } else {
            nearTime = L - x;
            farTime = x;
        }

        if (nearTime > minAnswer) {
            minAnswer = nearTime;
        }

        if (farTime > maxAnswer) {
            maxAnswer = farTime;
        }
    }

    printf("%d %d\n", minAnswer, maxAnswer);

    return 0;
}

9. 코드 흐름 정리

1. 막대기 길이 L과 개미 수 n을 입력받습니다.

2. 각 개미 위치 x를 입력받습니다.

3. 가까운 끝까지의 시간 min(x, L - x)을 구합니다.

4. 먼 끝까지의 시간 max(x, L - x)을 구합니다.

5. 모든 개미가 떨어져야 하므로 각각의 최댓값을 출력합니다.

시간복잡도는 O(n)입니다. n이 최대 1,000,000이어도 한 번만 검사하므로 충분히 빠릅니다.
