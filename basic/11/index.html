정올 1411 두 줄로 타일 깔기

DP 점화식 · 2×N 타일링 · 나머지 연산

1. 문제 이해

가로 2칸, 세로 N칸 크기의 판을 주어진 타일로 채우는 경우의 수를 구합니다. 회전이 가능하므로 마지막 칸을 기준으로 경우를 나누어 생각하면 됩니다.

출력은 경우의 수를 20100529로 나눈 나머지입니다.

3. DP 정의

dp[i]를 2×i 크기의 판을 채우는 방법의 수라고 정의합니다.

dp[1] = 1
dp[2] = 3

4. 점화식 이해

마지막 1칸 세로줄 채우기
dp[N-1]

맨 끝 한 줄을 세로 타일 1개로 채웁니다.

마지막 2칸 세로줄 채우기
2 × dp[N-2]

가로 타일 2개 또는 2×2 타일 1개로 채웁니다.

따라서 dp[N] = dp[N-1] + 2 × dp[N-2] 입니다.

9. 정답 C 코드

#include <stdio.h>

#define MOD 20100529

int dp[100001];

int main() {
    int N;
    int i;

    scanf("%d", &N);

    dp[1] = 1;

    if (N >= 2) {
        dp[2] = 3;
    }

    for (i = 3; i <= N; i++) {
        dp[i] = (dp[i - 1] + 2 * dp[i - 2]) % MOD;
    }

    printf("%d\n", dp[N]);

    return 0;
}

10. 마무리 정리

이 문제는 2×N 타일링의 대표적인 동적계획법 문제입니다. 마지막 1칸을 채우는 경우와 마지막 2칸을 채우는 경우로 나누면 점화식이 자연스럽게 나옵니다.

시간복잡도는 O(N)입니다. N이 100,000이어도 충분히 빠릅니다.
