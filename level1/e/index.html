2. 악수 정리 — 차수의 합은 간선 수의 2배

정리 · 악수 정리
모든 정점의 차수를 더하면 간선 수의 2배가 됩니다.
(차수의 합) = 2 × (간선의 수)

간선 하나는 양 끝의 두 정점에서 각각 한 번씩 세어지기 때문입니다. 위 그림에서 2 + 4 + 2 + 3 + 3 = 14 = 2 × 7로 맞습니다.

따름 정리
차수의 합은 항상 짝수입니다. 따라서 차수가 홀수인 정점은 반드시 짝수 개입니다.

짝수 차수 정점들의 합은 짝수이므로, 전체 합이 짝수가 되려면 홀수 차수 정점들의 합도 짝수여야 합니다. 홀수를 홀수 개 더하면 홀수가 되므로, 홀수 차수 정점은 짝수 개입니다.

생각 도구 · 불변량
“무엇을 하든 변하지 않는 성질”을 이용하면 불가능함을 보일 수 있습니다. 차수의 합이 항상 짝수라는 사실이 대표 문제의 열쇠입니다. 이런 생각은 주제 26(불변량)에서 다시 다룹니다.

간선 목록을 받아 인접 행렬을 만들고 차수를 구합니다. 무방향 그래프이므로 간선 하나를 넣을 때 양쪽에 모두 1을 적습니다. 마지막 줄에서 악수 정리를 검산합니다.

같은 일을 하는 두 프로그램
C
#include <stdio.h>

int main(void) {
    int n = 5, m = 7;                 /* 정점 수, 간선 수 */
    int e[7][2] = {{0,1},{1,2},{0,3},{1,3},{1,4},{2,4},{3,4}};
    int adj[5][5] = {{0}}, deg[5] = {0};
    for (int i = 0; i < m; i++) {
        int a = e[i][0], b = e[i][1];
        adj[a][b] = adj[b][a] = 1;    /* 무방향: 양쪽 모두 */
    }
    printf("   A B C D E  차수\n");
    int sum = 0;
    for (int i = 0; i < n; i++) {
        printf("%c: ", 'A' + i);
        for (int j = 0; j < n; j++) {
            printf("%d ", adj[i][j]);
            deg[i] += adj[i][j];
        }
        printf("   %d\n", deg[i]);
        sum += deg[i];
    }
    printf("차수의 합 %d, 간선 수 x 2 = %d\n", sum, 2 * m);
    return 0;
}

1. 오일러 회로와 오일러 경로

정의
그래프의 모든 간선을 정확히 한 번씩 지나는 경로를 오일러 경로, 그중 출발점으로 되돌아오는 것을 오일러 회로라고 합니다. 한붓그리기가 된다는 것은 오일러 경로가 있다는 뜻입니다.
정리 · 판정법
그래프가 연결되어 있을 때(한 덩어리일 때)
① 홀수 차수 정점이 0개 → 오일러 회로가 있다. 아무 점에서 출발해 제자리로 돌아온다.
② 홀수 차수 정점이 2개 → 오일러 경로가 있다. 한 홀수 정점에서 출발해 다른 홀수 정점에서 끝난다.
③ 홀수 차수 정점이 4개 이상 → 한붓그리기가 불가능하다.

2. 왜 홀짝이 중요한가

한붓그리기를 하는 동안 어떤 정점을 지나갈 때마다, 그 점으로 들어오는 간선 하나와 나가는 간선 하나를 함께 씁니다. 곧 간선을 2개씩 짝지어 쓰는 셈입니다.

정점의 역할쓰는 간선차수의 홀짝
중간에 지나가기만 하는 점들어오기 + 나가기 = 2개씩짝수
출발점맨 처음 나가기 1개 + (지날 때마다 2개씩)홀수
도착점맨 마지막 들어오기 1개 + (지날 때마다 2개씩)홀수
출발점 = 도착점 (회로)처음 나가기 + 마지막 들어오기 = 2개짝수
한 문장 요약
“들어오면 나간다”가 핵심입니다. 그래서 중간 점은 차수가 짝수여야 하고, 홀수 차수 정점은 출발점이나 도착점밖에 될 수 없습니다.

출발점과 도착점은 최대 2개이므로, 홀수 차수 정점이 3개 이상이면 자리가 모자라 한붓그리기가 불가능합니다.

3. 최소 몇 획이 필요한가

정리
연결된 그래프에서 홀수 차수 정점이 2k개(k ≥ 1)이면, 모든 간선을 그리는 데 필요한 최소 획 수는 k = 2k ÷ 2획입니다.

한 획은 홀수 차수 정점을 최대 2개(출발점과 도착점)까지만 처리할 수 있기 때문입니다. 홀수 정점이 4개면 2획, 6개면 3획입니다.

C
#include <stdio.h>

int main(void) {
    int n = 9, m = 12;                /* 3x3 점, 선분 12개 */
    int e[12][2] = {{0,1},{1,2},{3,4},{4,5},{6,7},{7,8},
                    {0,3},{3,6},{1,4},{4,7},{2,5},{5,8}};
    int deg[9] = {0};
    for (int i = 0; i < m; i++) {
        deg[e[i][0]]++;
        deg[e[i][1]]++;
    }
    int odd = 0, sum = 0;
    for (int i = 0; i < n; i++) {
        printf("%d번 차수 %d\n", i, deg[i]);
        if (deg[i] % 2 == 1) odd++;
        sum += deg[i];
    }
    printf("차수의 합 %d (간선 x 2 = %d)\n", sum, 2 * m);
    printf("홀수 차수 정점 %d개 -> ", odd);
    if (odd == 0)      printf("오일러 회로 있음 (1획)\n");
    else if (odd == 2) printf("오일러 경로 있음 (1획)\n");
    else               printf("불가능, 최소 %d획\n", odd / 2);
    return 0;
}

1. 트리의 정의

정의 · 트리

2. 정점 n개인 트리의 간선은 n − 1개

정리
정점이 n개인 트리의 간선은 정확히 n − 1개입니다. 거꾸로 연결 그래프의 간선이 n − 1개이면 그 그래프는 트리입니다.
정점 수 n123456…n
간선 수012345…n − 1

트리에 간선을 하나라도 더하면 사이클이 생기고, 하나라도 빼면 두 덩어리로 갈라집니다. 곧 트리는 연결을 유지하는 가장 적은 간선을 가진 그래프입니다.

악수 정리와 함께 쓰기
트리에서 차수의 합 = 2 × 간선 수 = 2(n − 1)입니다. 이 식 하나로 “차수가 3인 정점이 몇 개이면 리프는 몇 개인가” 같은 문제를 풀 수 있습니다. 대표 문제가 바로 이 유형입니다.

3. 두 정점을 잇는 경로는 유일하다

정리
트리에서 어떤 두 정점을 잇는 경로는 정확히 하나뿐입니다.

경로가 둘이라면 두 경로를 이어 붙여 출발점으로 돌아오는 사이클이 생기는데, 트리에는 사이클이 없으므로 모순입니다.

이 성질 덕분에 트리에서는 “두 점 사이의 거리”가 헷갈릴 일이 없습니다. 유일한 경로의 간선 수가 곧 거리입니다. 위 그림에서 D와 F 사이의 거리는 D → B → A → C → F로 4입니다.

자주 하는 실수
“가장 짧은 경로”를 찾는다고 여러 길을 비교하는 경우입니다. 트리에서는 길이 하나뿐이므로 비교할 것이 없습니다.

5. 차수 조건으로 리프 세기

트리의 두 식을 함께 씁니다. 정점 수를 n, 리프 수를 L이라 하면

푸는 틀
① 정점 수: n = (차수가 정해진 정점 수) + L
② 차수의 합: (정해진 차수들의 합) + 1 × L = 2(n − 1)
두 식을 연립하면 L이 나옵니다.

예를 들어 차수가 4인 정점이 5개, 나머지가 모두 리프인 트리라면 n = 5 + L이고 차수의 합은 20 + L = 2(5 + L − 1) = 8 + 2L입니다. 정리하면 L = 12이고 정점은 17개, 간선은 16개입니다.

검산
구한 값을 두 식에 모두 넣어 봅니다. 차수의 합 20 + 12 = 32이고 2(17 − 1) = 32로 맞습니다.

③손으로 따라가기

예제 1 · 대표 문제
차수가 3인 정점이 8개이고 나머지가 모두 리프(차수 1)인 트리에서 리프는 몇 개인가?
풀이

리프의 수를 L이라 하면 정점 수는 n = 8 + L입니다.

차수의 합을 두 가지로 계산합니다.

방법식
각 정점의 차수를 더한다3 × 8 + 1 × L = 24 + L
악수 정리 (트리는 간선이 n − 1개)2(n − 1) = 2(8 + L − 1) = 14 + 2L

두 값이 같아야 하므로

24 + L = 14 + 2L　→　L = 10

따라서 리프는 10개이고, 정점은 18개, 간선은 17개입니다.

검산. 차수의 합 24 + 10 = 34이고 2 × 17 = 34로 맞습니다.

핵심
트리 문제는 거의 모두 차수의 합을 두 가지 방법으로 세어 등식을 만드는 것으로 풀립니다. 주제 11의 “두 가지로 세기”와 같은 생각입니다.

#include <stdio.h>

int main(void) {
    int n = 6;
    /* 부모 배열: 루트 A(0)의 부모는 -1 */
    int par[6] = {-1, 0, 0, 1, 1, 2};

        if (par[i] < 0) depth[i] = 0;
        else {
            depth[i] = depth[par[i]] + 1;  /* 부모보다 1 깊다 */
            child[par[i]]++;

    }

        printf("%c: 깊이 %d, 자식 %d%s\n", 'A' + i, depth[i],
               child[i], child[i] == 0 ? " (리프)" : "");
        if (child[i] == 0) leaf++;
        if (depth[i] > h) h = depth[i];
    }
    printf("리프 %d개, 높이 %d, 간선 %d개\n", leaf, h, n - 1);
    return 0;
}

/* 중위의 [l, r] 구간을 맡아 후위 순서로 출력 */
void build(int l, int r) {
    if (l > r) return;
    char root = pre[pi++];
    int m = l;
    while (ino[m] != root) m++;   /* 중위에서 루트 찾기 */
    build(l, m - 1);              /* 왼쪽 서브트리 */

    printf("%c", root);           /* 마지막에 루트 = 후위 */
}

int main(void) {
    printf("후위: ");
    build(0, 5);
    printf("\n");
    return 0;
}

정점만 있고 간선이 하나도 없는 그래프에서 시작한다. 이때 모든 정점의 차수는 0이므로 차수의 합은 0이고 간선 수도 0이므로 “차수의 합 = 2 × 간선 수”가 성립한다.

이제 간선을 하나 그려 넣는다. 간선은 두 정점을 잇고, 그 양 끝 정점의 차수가 각각 1씩 늘어난다. 곧 차수의 합은 2만큼 늘고 간선 수는 1만큼 는다. 따라서 등식의 왼쪽이 2 늘고 오른쪽도 2 × 1 = 2 늘어 등식이 그대로 유지된다.

간선을 몇 개 그려 넣든 매번 같은 일이 일어나므로, 간선이 m개인 어떤 그래프에서도 차수의 합 = 2m이다.

홀수 차수 정점이 짝수 개인 이유 차수의 합 2m은 짝수다. 정점을 차수가 짝수인 무리와 홀수인 무리로 나누면

(짝수 차수들의 합) + (홀수 차수들의 합) = 짝수

앞의 괄호는 짝수끼리의 합이므로 짝수다. 따라서 뒤의 괄호도 짝수여야 한다. 홀수를 여러 개 더해 짝수가 되려면 더한 개수가 짝수여야 하므로, 차수가 홀수인 정점은 짝수 개다.

(2) 간선 수로 센다. 정점 n개인 트리의 간선은 n − 1개다. 한편 간선은 “부모 → 자식”이므로 자식의 수를 모두 더한 것과 같다. 자식이 2개인 정점이 a개, 1개인 정점을 b개, 0개인 정점(리프)이 L개라 하면 n = a + b + L이고 간선 수는 2a + b이므로
2a + b = n − 1 = a + b + L − 1　→　a = L − 1, 곧 L = a + 1이다.
서술 · 모범 답안

중위 순회의 규칙은 “왼쪽 서브트리를 모두 쓰고 → 루트를 쓰고 → 오른쪽 서브트리를 모두 쓴다”이다. 이 규칙에서 두 가지가 따라 나온다.

① 왼쪽 서브트리의 정점은 모두 루트보다 앞에 나온다. 루트를 쓰기 전에 왼쪽 서브트리를 “모두” 끝내기 때문이다.

② 오른쪽 서브트리의 정점은 모두 루트보다 뒤에 나온다. 루트를 쓴 뒤에 비로소 오른쪽 서브트리를 시작하기 때문이다.

트리의 모든 정점은 루트이거나 왼쪽 서브트리 또는 오른쪽 서브트리에 속하고 이 셋은 겹치지 않는다. 따라서 중위 순회 결과에서 루트의 위치를 찾으면 그 앞부분은 왼쪽 서브트리의 정점 전부, 뒷부분은 오른쪽 서브트리의 정점 전부가 된다.

복원이 가능한 이유 전위 순회의 첫 글자는 루트다. 그 루트를 중위 순회에서 찾으면 위의 성질에 따라 왼쪽·오른쪽 서브트리에 속한 정점들이 정해지고, 각 서브트리의 정점 개수도 알 수 있다. 전위 순회도 “루트 → 왼쪽 전부 → 오른쪽 전부” 순서이므로, 알아낸 개수만큼 끊으면 각 서브트리의 전위 순회가 된다. 이제 각 서브트리에 대해 똑같은 일을 되풀이하면 정점이 하나씩 남을 때까지 모양이 정해진다. 매 단계에서 왼쪽·오른쪽이 분명히 갈리므로 복원된 트리는 하나뿐이다.

채점 기준 중위의 규칙을 쓰고 ①②를 설명(2점), 세 부분이 겹치지 않고 빠짐없음을 밝힘(1점), 전위에서 루트를 얻는 점(1점), 개수를 알면 전위도 끊을 수 있고 되풀이하면 복원됨을 설명(2점).
