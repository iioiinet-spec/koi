#include <stdio.h>

int main(void) {
    int a[5] = {5, 1, 4, 2, 3}, n = 5;
    int b[5];
    for (int i = 0; i < n; i++) b[i] = a[i];  /* 사본 */

    int inv = 0;                    /* 역순쌍 세기 */
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (a[i] > a[j]) inv++;

    int sw = 0, cmp = 0;            /* 버블 정렬 */
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            cmp++;
            if (b[j] > b[j+1]) {
                int t = b[j]; b[j] = b[j+1]; b[j+1] = t;
                sw++;
            }
        }
        printf("%d바퀴:", i + 1);
        for (int k = 0; k < n; k++) printf(" %d", b[k]);
        printf("\n");
    }
    printf("비교 %d, 교환 %d, 역순쌍 %d\n", cmp, sw, inv);
    return 0;
}

2. 큐의 동작

정의
큐는 뒤에서 넣고 앞에서 뺍니다. 넣는 것을 enqueue, 빼는 것을 dequeue라고 합니다. 먼저 넣은 것이 먼저 나오므로 FIFO(First In First Out)입니다.

#include <stdio.h>

/* out[]이 스택 수열이면 1, 아니면 0 */
int ok(int out[], int n) {
    int st[10], top = 0, nxt = 1;
    for (int i = 0; i < n; i++) {
        while (top == 0 || st[top-1] != out[i]) {
            if (nxt > n) return 0;   /* 더 넣을 수 없다 */
            st[top++] = nxt++;       /* push */
        }
        top--;                       /* pop */
    }
    return 1;
}

from itertools import permutations

def ok(out):                         # 스택 수열이면 True
    st, nxt, n = [], 1, len(out)
    for x in out:
        while not st or st[-1] != x:
            if nxt > n:
                return False         # 더 넣을 수 없다
            st.append(nxt)           # push
            nxt += 1
        st.pop()                     # pop
    return True

print("3124:", "가능" if ok((3,1,2,4)) else "불가능")
print("3214:", "가능" if ok((3,2,1,4)) else "불가능")

배열에서 이웃한 두 자리의 값을 x, y(x가 앞)라 하고, x > y여서 자리를 바꾼다고 하자. 두 자리 사이에는 다른 수가 없다.

① 바꾼 두 수의 쌍 교환 전에는 앞의 x가 뒤의 y보다 크므로 이 쌍은 역순쌍이었다. 교환 후에는 y가 앞, x가 뒤가 되어 역순쌍이 아니게 된다. 곧 이 쌍에서 역순쌍이 1 줄었다.

② 나머지 모든 쌍 두 자리 이외의 수 z를 생각하자. z는 두 자리보다 앞에 있거나 뒤에 있다.

  • z가 앞에 있으면: 교환 전에도 후에도 z는 x, y보다 앞이다. (z, x)와 (z, y)의 앞뒤 관계와 값이 그대로이므로 역순쌍 여부가 바뀌지 않는다.
  • z가 뒤에 있으면: 마찬가지로 (x, z), (y, z)의 관계가 그대로다.
  • x, y를 포함하지 않는 쌍은 아예 건드리지 않았다.

따라서 교환 한 번으로 달라지는 것은 바꾼 두 수의 쌍 하나뿐이고, 역순쌍의 개수는 정확히 1 줄어든다.

(2) 다섯 가지 모두 올바른 괄호다. 이유는 두 가지다. ① push와 pop이 각각 3번씩이므로 괄호의 개수가 같아 끝에 0이 된다. ② 스택에 들어 있지 않은 것은 pop할 수 없으므로, 어느 시점에서도 지금까지의 pop 횟수가 push 횟수를 넘을 수 없다. 이는 “도중에 음수가 되지 않는다”와 정확히 같은 조건이다.
거꾸로 올바른 괄호 하나는 push/pop의 방법 하나에 짝지어지므로, 스택 수열의 개수와 올바른 괄호 문자열의 개수는 같다. 둘 다 카탈란 수인 이유다.
도전 3(1) 스택 14가지, 큐 1가지　(2) 설명 참고(1) 스택은 n = 4의 카탈란 수 14가지, 큐는 입력 순서 그대로인 1234 1가지뿐이다.
(2) 큐는 넣는 곳(뒤)과 빼는 곳(앞)이 다르다. 먼저 들어간 것이 항상 앞에 있으므로 나중에 들어온 것이 앞지를 수 없다. 반면 스택은 넣는 곳과 빼는 곳이 같다. 나중에 들어온 것이 위에 쌓여 먼저 나갈 수 있으므로 순서를 바꿀 수 있다. 다만 한 번 아래에 깔린 것들끼리는 순서를 바꿀 수 없어서, 만들 수 있는 순서가 24가지 전부는 아니고 14가지로 제한된다.
서술 · 모범 답안

수는 1, 2, 3, 4의 순서로만 스택에 들어간다. 따라서 3이 가장 먼저 나왔다는 것은, 3을 pop하기 전에 1과 2가 이미 push되어 있었고 아직 한 번도 pop되지 않았다는 뜻이다. (1이나 2가 먼저 나왔다면 3이 가장 먼저 나온 것이 아니기 때문이다.)

push는 1, 2, 3의 순서였으므로 3을 꺼낸 직후 스택은 아래부터 1, 2가 쌓인 상태다.

1
push 1
12
push 2
123
push 3
12
pop → 3

스택은 맨 위에서만 꺼낼 수 있다. 1은 2 아래에 깔려 있으므로, 1을 꺼내려면 그 위의 2를 반드시 먼저 꺼내야 한다. 이후 4를 push하더라도 4는 2보다 위에 쌓일 뿐이어서 1이 2보다 먼저 나올 수는 없다. 따라서 2가 1보다 먼저 나온다.

3, 1, 2, 4가 불가능한 이유 이 순서는 3이 가장 먼저 나온 뒤 1이 2보다 먼저 나오라고 요구한다. 위에서 보인 것과 어긋나므로 이런 출력은 만들 수 없다.

일반화 같은 논리로, 출력 순서에 c … a … b (a < b < c) 꼴이 들어 있으면 언제나 불가능하다. c가 나온 시점에 a와 b가 스택에 남아 있고 b가 a보다 위에 있기 때문이다.

채점 기준 3이 먼저 나오려면 1, 2가 스택에 남아 있어야 함을 밝힘(2점), 1이 2 아래에 깔려 있음을 그림이나 말로 보임(1점), 맨 위에서만 꺼낼 수 있으므로 2가 먼저임을 결론(2점), 3 1 2 4가 불가능하다는 결론(1점).
