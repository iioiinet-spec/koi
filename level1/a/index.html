C
#include <stdio.h>

int main(void) {
    int count = 0;
    printf("p q r | 결과\n");
    for (int p = 1; p >= 0; p--)
        for (int q = 1; q >= 0; q--)
            for (int r = 1; r >= 0; r--) {
                int v = (p && q) || !r;
                printf("%d %d %d |  %d\n", p, q, r, v);
                count += v;
            }
    printf("참인 행: %d\n", count);
    return 0;
}

3. 집합으로 보기: 충분조건과 필요조건

조건 p를 만족하는 것들의 집합을 P, 조건 q를 만족하는 것들의 집합을 Q라 하면 p → q가 참이라는 것은 P의 모든 원소가 Q에 들어 있다, 곧 P ⊂ Q라는 뜻입니다.

정의 · 충분조건, 필요조건
p → q가 참일 때 p는 q이기 위한 충분조건, q는 p이기 위한 필요조건이라고 합니다. p → q와 q → p가 모두 참이면(곧 P = Q) p는 q이기 위한 필요충분조건입니다.

외우는 방법: 작은 집합 P 안에 들기만 하면 Q에 드는 것이 “충분”하고, Q에 들지 못하면 P에도 들 수 없으니 Q는 P에 “필요”합니다. 4의 배수라는 것은 짝수이기에 충분하고, 짝수라는 것은 4의 배수이기 위해 필요합니다.

4. “모든”과 “어떤”이 들어간 문장의 부정

원래 문장부정예

성질 · 반례
“모든 x에 대하여 p(x)”는 p(x)가 아닌 x가 하나만 있어도 거짓입니다. 이런 x를 반례라고 합니다. 반대로 “모든”이 참임을 보이려면 예를 몇 개 드는 것으로는 부족하고, 모든 경우에 성립하는 이유를 보여야 합니다.
자주 하는 실수
“모든 학생이 과제를 냈다”의 부정을 “모든 학생이 과제를 내지 않았다”로 쓰면 틀립니다. 한 명만 안 냈어도 원래 문장은 거짓이 되기 때문입니다.

#include <stdio.h>

int main(void) {
    int sol = 0;
    for (int a = 1; a >= 0; a--)
    for (int b = 1; b >= 0; b--)
    for (int c = 1; c >= 0; c--) {
        int sa = (a + b + c == 1);  /* A의 발언 */
        int sb = (a == 0);          /* B의 발언 */

}
