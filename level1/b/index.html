생각 도구 · 왼쪽부터 “× 진법 + 숫자”

2로 나누어 몫이 0이 될 때까지 반복하고, 나머지를 아래에서 위로 읽습니다. 45를 바꾸어 봅니다.

나머지를 아래에서부터 읽으면 1, 0, 1, 1, 0, 1이므로 45 = 101101(2)입니다. 확인: 32 + 8 + 4 + 1 = 45.

생각 도구 · 큰 자리값부터 빼기
2의 거듭제곱 표(1, 2, 4, 8, 16, 32, 64, …)를 알고 있으면 넣을 수 있는 가장 큰 자리값부터 빼는 방법이 더 빠를 때가 많습니다. 45 − 32 = 13, 13 − 8 = 5, 5 − 4 = 1, 1 − 1 = 0 → 32, 8, 4, 1 자리에 1을 씁니다.

다른 진법도 똑같습니다. 8진법은 8로, 16진법은 16으로 나눈 나머지를 거꾸로 읽습니다.

C는 나머지를 배열에 차례로 저장한 뒤 거꾸로 출력하고, Python은 나머지를 문자열 앞에 붙여 같은 효과를 냅니다. Python 내장 함수 bin, format과 결과가 같은지도 확인합니다.

같은 일을 하는 두 프로그램
C
#include <stdio.h>

/* n을 b진법으로 출력하고 자릿수를 돌려준다 */
int print_base(int n, int b) {
    char digit[] = "0123456789ABCDEF";
    char buf[40];
    int len = 0;
    while (n > 0) {
        buf[len++] = digit[n % b];   /* 나머지 저장 */
        n /= b;
    }
    for (int i = len - 1; i >= 0; i--)
        putchar(buf[i]);             /* 거꾸로 출력 */
    return len;
}

int main(void) {
    int n = 2026, ones = 0;
    printf("2진수: ");
    int len = print_base(n, 2);
    printf("\n16진수: ");
    print_base(n, 16);
    printf("\n8진수: ");
    print_base(n, 8);
    for (int x = n; x > 0; x /= 2)
        ones += x % 2;
    printf("\n자릿수 %d, 1의 개수 %d\n", len, ones);
    return 0;
}

def to_base(n, b):
    digit = "0123456789ABCDEF"
    s = ""
    while n > 0:
        s = digit[n % b] + s   # 나머지를 앞에 붙임
        n //= b
    return s

n = 2026
b2 = to_base(n, 2)
print("2진수: " + b2)
print("16진수: " + to_base(n, 16))
print("8진수: " + to_base(n, 8))

5. 약수는 √N까지만 찾는다

d가 N의 약수이면 N ÷ d도 약수이므로 약수는 짝을 이룹니다. 짝 중 작은 쪽은 항상 √N 이하이므로 1부터 √N까지만 나누어 보면 모든 약수를 찾을 수 있습니다.

생각 도구 · 짝지어 세기

#include <stdio.h>

int main(void) {
    int n = 360, cnt = 0, sum = 0;
    printf("약수 쌍:");
    for (int i = 1; i * i <= n; i++) {
        if (n % i != 0) continue;
        int j = n / i;                /* 짝이 되는 약수 */
        printf(" (%d,%d)", i, j);
        if (i == j) { cnt += 1; sum += i; }
        else        { cnt += 2; sum += i + j; }
    }
    printf("\n약수의 개수 %d, 약수의 합 %d\n", cnt, sum);
    return 0;
}

6. 연속한 합성수 구간 만들기

성질
n! = 1 × 2 × … × n일 때 n! + 2, n! + 3, …, n! + n은 연속한 n − 1개의 합성수입니다. n! + k (2 ≤ k ≤ n)는 k로 나누어떨어지기 때문입니다.

예) 5! = 120이므로 122(÷2), 123(÷3), 124(÷4), 125(÷5)는 연속한 합성수 4개입니다. n을 크게 하면 소수가 하나도 없는 구간을 얼마든지 길게 만들 수 있습니다.

(제곱수이면 홀수) N = m²이면 d = m일 때만 짝이 자기 자신이다(d가 m보다 작으면 N ÷ d는 m보다 크다). m을 뺀 나머지 약수는 서로 다른 쌍으로 묶이므로 짝수 개이고, m 하나를 더하면 홀수 개이다. 예) 36: (1, 36), (2, 18), (3, 12), (4, 9), 그리고 6 → 9개

서술 · 모범 답안

p보다 작은 p의 배수는 k × p (2 ≤ k ≤ p − 1) 꼴이다. k는 1보다 크고 p보다 작으므로 k의 소인수 중 하나를 q라 하면 q < p이고 q는 k × p를 나눈다. 체는 작은 소수부터 차례로 배수를 지우므로 k × p는 q의 차례에서 이미 지워졌다. 따라서 p의 배수는 p × p = p²부터 지우면 충분하다.

1~100에서 p = 7일 때 7의 배수 중 49 이상인 수는 49, 56, 63, 70, 77, 84, 91, 98이다. 이 중 56, 70, 84, 98은 짝수라 2의 차례에서, 63은 3의 차례에서 지워졌다. 49 = 7 × 7, 77 = 7 × 11, 91 = 7 × 13은 7보다 작은 소인수가 없으므로 7의 차례에서 처음 지워진다.
