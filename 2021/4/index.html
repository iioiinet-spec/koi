6. 왜 완전탐색은 사용할 수 없는가?

완전탐색

A의 부분문자열은 최대 약 N²/2개입니다. N=500,000이면 생성 자체가 불가능합니다.

8. 한 A 접미사에서 새 문자열만 세기

common[i]

A[i..]와 B의 어떤 접미사가 공유하는 최대 접두사 길이입니다.

prevLcp[i]

사전순 이전 A 접미사와 이미 겹치는 접두사 길이입니다. 이 길이 이하는 중복입니다.

괄호 높이

끝 높이가 시작 높이와 같고, 중간에 더 낮아지지 않는 끝점만 선택합니다.

새 후보 길이: prevLcp[i]+1 이상, common[i] 이하

10. 코드 작성 단계 핵심

1단계. 높이 배열

height[0] = 0;

for (int i = 0; i < n; i++) {
    height[i + 1] =
        height[i] +
        (A[i] == '(' ? 1 : -1);
}

2단계. 유효 끝 범위

left =
    start + prevLcp[start] + 1;

right =
    start + common[start];

right = min(
    right,
    bad[start] - 1
);

3단계. 같은 높이 개수

count =
    upper_bound(right)
    - lower_bound(left);

4단계. K번째 선택

if (K > count) {
    K -= count;
} else {
    answerEnd =
        positions[first + K - 1];
}
